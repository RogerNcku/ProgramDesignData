Topic 11

Expression 綜合複習與觀念整理

這個主題把 Lesson 7 前半段的核心概念重新整理：Expression 是由 operand 與 operator 組合而成；Infix 是人類最常看到的寫法，但是電腦處理時需要判斷括號與優先順序；Postfix 與 Prefix 則把運算順序藏在符號排列中，因此比較適合用 Stack 或 Tree 進行處理。

Expressions、Infix、Postfix、Prefix 基本定義

（一）這張投影片在說什麼？ 這張投影片正式定義 Expression 是由 operands 與 operators 組成。Operand 是被運算的資料，例如 A、B、5、10；Operator 是負責計算的符號，例如 +、-、*、/。

（二）核心觀念 同一個運算可以有三種常見寫法：Infix 是運算子放中間，例如 A+B；Postfix 是運算子放後面，例如 AB+；Prefix 是運算子放前面，例如 +AB。差別只在符號位置，但會影響程式如何解析。

（三）為什麼重要？ 人類習慣 Infix，因為它接近數學課本的寫法；電腦常用 Postfix 或 Prefix，因為它們可以減少括號與優先順序的判斷。

（四）學習與考試重點 請特別記住：Infix 要考慮括號與優先順序；Postfix 與 Prefix 通常可以直接配合 Stack 或 Tree 處理。

一句話記憶：Infix 給人看，Postfix / Prefix 更方便給電腦算。
投影片說明 Infix 需要運算優先順序與括號。

Infix Expressions 中序表示法

（一）這張投影片在說什麼？ 這張投影片說明 Infix Expression，也就是我們最熟悉的中序寫法。中序的特色是運算子出現在兩個運算元中間，例如 A+B、A*B+C。

（二）核心觀念 Infix 的問題在於它必須依賴 operation hierarchy，也就是運算優先順序。一般規則是括號最優先，接著乘除，最後加減；如果沒有正確處理，計算結果就會錯。

（三）為什麼重要？ 這也是為什麼電腦不能只從左到右盲目計算 Infix。它必須先判斷括號、優先順序與結合方向，才知道真正的計算流程。

（四）學習與考試重點 常見考點是比較 5+2*3 與 (5+2)*3，前者先乘後加，後者先算括號。

一句話記憶：Infix 好讀，但電腦處理時最麻煩。

完整中文講解

Expression 的基本結構是「運算元加上運算子」。例如 A+B*C 中，A、B、C 是運算元，+ 與 * 是運算子。Infix 的優點是容易閱讀，但缺點是程式必須知道優先順序。像 A+B*C 不能從左到右直接算，因為乘法要先做，所以真正順序是 A+(B*C)。Postfix 與 Prefix 則把運算子放在固定位置，使得電腦可以用比較一致的規則處理。

範例說明

以 A+B*C 為例，Infix 是 A+B*C；Postfix 是 ABC*+；Prefix 是 +A*BC。雖然三種寫法不同，但代表同一個運算意義。這也是 Lesson 7 後面要學 Stack 與 Expression Tree 的原因：它們可以幫助程式把人類習慣的 Infix 轉成電腦較容易處理的形式。

程式題目教學內容

一、程式題目講解

這個程式用來複習 Expression 的基本組成，會逐字分析輸入的 Infix expression，判斷每個 token 是運算元、運算子或括號，並顯示運算子的優先順序。

二、完整程式碼

以下保留本頁原本的完整 C 程式碼，並搭配中文註解說明主要功能與流程。

#include <stdio.h>
#include <ctype.h>
#include <string.h>

/*
   Lesson 7 主題 11：Expression 綜合複習工具
   功能：
   1. 逐字分析 expression 裡的 token
   2. 判斷 operand / operator / parenthesis
   3. 顯示運算子的優先順序
   這個程式適合用來複習主題 1 到主題 10 的基本概念。
*/

// 判斷是否為運算子
int isOperator(char ch) {
    return ch == '+' || ch == '-' || ch == '*' || ch == '/' || ch == '^';
}

// 回傳運算子優先順序，數字越大代表越優先
int priority(char op) {
    if (op == '^') return 3;
    if (op == '*' || op == '/') return 2;
    if (op == '+' || op == '-') return 1;
    return 0;
}

int main() {
    char exp[100];

    printf("請輸入一個 Infix expression，例如 A+B*C 或 (A+B)*C：\n");
    scanf("%99s", exp);

    printf("\n逐步分析結果：\n");
    printf("--------------------------------------\n");
    printf("字元\t類型\t\t補充說明\n");
    printf("--------------------------------------\n");

    for (int i = 0; i < strlen(exp); i++) {
        char ch = exp[i];

        if (isalnum(ch)) {
            // isalnum 表示英文字母或數字，這裡視為 operand
            printf("%c\tOperand\t\t運算元，可代表變數或數字\n", ch);
        } else if (isOperator(ch)) {
            // 運算子需要看優先順序
            printf("%c\tOperator\t優先順序 = %d\n", ch, priority(ch));
        } else if (ch == '(') {
            printf("%c\tLeft Paren\t左括號，代表新的計算範圍開始\n", ch);
        } else if (ch == ')') {
            printf("%c\tRight Paren\t右括號，代表括號內要先完成\n", ch);
        } else {
            printf("%c\tUnknown\t\t不是本程式處理的符號\n", ch);
        }
    }

    printf("--------------------------------------\n");
    printf("複習重點：Infix 對人類直覺，但程式需要判斷括號與運算子優先順序。\n");

    return 0;
}

五、重要函數與語法說明
  • isOperator(ch)：判斷字元是否為運算子。

  • isalnum(ch)：判斷是否為字母或數字。
  • scanf("%99s", exp)：讀取 expression 並限制輸入長度。
  • strlen(exp)：取得 expression 長度。
