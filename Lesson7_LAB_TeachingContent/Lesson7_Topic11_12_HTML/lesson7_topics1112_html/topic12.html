整合範例與練習：從 Infix 到 Postfix

這個主題把 Lesson 7 的後半段概念整合起來：先看 Infix expression，再用 Stack 處理運算子，最後輸出 Postfix expression。這個流程也是投影片中 Infix-to-Postfix 程式實作與執行結果的核心。

（二）核心觀念 當讀到數字或變數值時，Stack 會增加一個元素；當讀到 operator 時，Stack 會先減少兩個元素，再放回一個計算結果。

一句話記憶：每遇到一個 operator，Stack 會把兩個值合成一個值。

完整中文講解

Infix-to-Postfix 的核心是：operand 直接輸出，operator 暫存在 Stack。為什麼 operator 不能全部直接輸出？因為 Infix 中有優先順序問題。例如 A+B*C 中，雖然 + 比 * 早出現，但真正要先算的是 B*C，所以 * 必須比 + 更早出現在 Postfix 的運算順序中。Stack 可以幫助程式暫時保存 operator，等到適當時機再輸出。

練習題建議

你可以用程式測試 A+B*C、(A+B)*C、A*(B+C)-D。每一題都觀察 Output 與 Stack 的變化。建議先手算一次，再把式子輸入程式，確認結果是否一致。

程式題目教學內容

一、程式題目講解

這個程式整合 Infix-to-Postfix 的主要觀念，使用 Stack 將輸入的中序表示式轉成後序表示式，並在程式最後補上觀念說明。

二、完整程式碼

以下保留本頁原本的完整 C 程式碼，並搭配中文註解說明主要功能與流程。

#include <stdio.h>
#include <ctype.h>
#include <string.h>

/*
   Lesson 7 主題 12：整合範例
   功能：
   1. 將 Infix expression 轉成 Postfix expression
   2. 用 Stack 顯示轉換概念
   3. 適合輸入單一字元運算元，例如：A+B*C、(A+B)*C、A*(B+C)-D

   注意：
   這份教學範例主要用來理解演算法，所以每個 operand 用單一字元表示。
*/

#define MAX 100

char stack[MAX];
int top = -1;

// 判斷 stack 是否為空
int isEmpty() {
    return top == -1;
}

// push：把字元放入 stack
void push(char ch) {
    if (top < MAX - 1) {
        stack[++top] = ch;
    }
}

// pop：從 stack 取出最上方字元
char pop() {
    if (!isEmpty()) {
        return stack[top--];
    }
    return '\0';
}

// peek：只查看 stack 最上方字元，不移除
char peek() {
    if (!isEmpty()) {
        return stack[top];
    }
    return '\0';
}

// 判斷是否為運算子
int isOperator(char ch) {
    return ch == '+' || ch == '-' || ch == '*' || ch == '/' || ch == '^';
}

// 運算子優先順序
int priority(char op) {
    if (op == '^') return 3;
    if (op == '*' || op == '/') return 2;
    if (op == '+' || op == '-') return 1;
    return 0;
}

// 將 Infix 轉成 Postfix
void infixToPostfix(char infix[], char postfix[]) {
    int j = 0;

    for (int i = 0; i < strlen(infix); i++) {
        char ch = infix[i];

        // 1. 如果是 operand，直接輸出到 postfix
        if (isalnum(ch)) {
            postfix[j++] = ch;
        }
        // 2. 如果是左括號，直接 push 進 stack
        else if (ch == '(') {
            push(ch);
        }
        // 3. 如果是右括號，pop 到遇到左括號為止
        else if (ch == ')') {
            while (!isEmpty() && peek() != '(') {
                postfix[j++] = pop();
            }
            pop(); // 移除左括號 '('，但不輸出
        }
        // 4. 如果是運算子，處理優先順序
        else if (isOperator(ch)) {
            while (!isEmpty() && priority(peek()) >= priority(ch)) {
                postfix[j++] = pop();
            }
            push(ch);
        }
    }

    // 5. 掃描完 infix 後，把 stack 剩下的運算子全部輸出
    while (!isEmpty()) {
        postfix[j++] = pop();
    }

    postfix[j] = '\0';
}

int main() {
    char infix[MAX], postfix[MAX];

    printf("請輸入 Infix expression，例如 A+B*C 或 (A+B)*C：\n");
    scanf("%99s", infix);

    infixToPostfix(infix, postfix);

    printf("\nInfix  : %s\n", infix);
    printf("Postfix: %s\n", postfix);

    printf("\n觀念說明：\n");
    printf("1. Operand 直接輸出。\n");
    printf("2. Operator 先放入 stack，但要比較優先順序。\n");
    printf("3. 右括號出現時，要 pop 到左括號為止。\n");
    printf("4. 最後把 stack 中剩下的運算子全部輸出。\n");

    return 0;
}
三、程式執行結果

範例輸入：A+B*C

請輸入 Infix expression，例如 A+B*C 或 (A+B)*C：

Infix  : A+B*C
Postfix: ABC*+

觀念說明：
1. Operand 直接輸出。
2. Operator 先放入 stack，但要比較優先順序。
3. 右括號出現時，要 pop 到左括號為止。
4. 最後把 stack 中剩下的運算子全部輸出。

A、B、C 是運算元，所以會進入輸出結果；+ 和 * 是運算子，需要放入 Stack 並比較優先順序。因為 * 優先於 +，所以得到 ABC*+。

四、程式流程圖與流程圖說明

流程圖說明：本程式的主要邏輯可以依照下列順序理解：

  1. 輸入 Infix expression
  2. 建立空 Stack 與 postfix 陣列
  3. 運算元直接加入 postfix
  4. 運算子依優先順序處理
  5. 括號控制先算範圍
  6. 掃描結束後清空 Stack
  7. 輸出 Infix 與 Postfix
  8. 列出轉換觀念說明
五、重要函數與語法說明
  • isEmpty()：判斷 Stack 是否為空。
  • push(ch)：將運算子或括號放入 Stack。
  • pop()：取出 Stack 頂端元素。
  • peek()：查看 Stack 頂端但不移除。
  • isOperator(ch)：判斷是否為運算子。
  • priority(op)：回傳運算子優先順序。
六、整體說明

本題重點是整合 Infix-to-Postfix 的完整流程。學生要掌握運算元直接輸出、運算子進 Stack、括號控制範圍，以及最後清空 Stack 的規則。
