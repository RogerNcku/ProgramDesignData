八、Expression Trees 表達式樹

Expression Tree 是用樹狀結構表示運算式的方法。樹的內部節點通常是運算子，例如 +、-、*、/；葉節點通常是運算元，例如 A、B、C、2、3。透過樹的形狀，可以清楚看出哪一個運算先做、哪一個運算後做。

投影片 14：Expression Trees 基本觀念

Expression Trees 表達式樹基本觀念

（一）這張投影片在說什麼？ 這張投影片介紹 Expression Tree。表達式樹把一個運算式用樹狀結構表示，葉節點通常是 operand，內部節點通常是 operator。

（二）核心觀念 樹的根節點代表整個 expression 最後才執行的主要運算；左子樹與右子樹分別代表該運算子的左運算元與右運算元。

（三）為什麼重要？ Expression Tree 可以把運算順序視覺化。越靠近葉節點的運算通常越早完成，越靠近根節點的運算通常越晚完成。

（四）學習與考試重點 請能從一個算式畫出樹，也要能從樹還原出 infix、prefix、postfix。

一句話記憶：Expression Tree 用樹的上下層表示運算先後。

Expression Trees 範例

（一）這張投影片在說什麼？ 這張投影片用實際運算式示範如何形成表達式樹。你可以觀察哪一個 operator 位於根節點，哪些 operand 成為葉節點。

（二）核心觀念 主要運算子會成為整棵樹的 root；每一個子運算又會形成自己的子樹。這種結構和完整括號化的 Infix 其實是一一對應的。

（三）為什麼重要？ 透過範例可以看出，Expression Tree 不只是圖形，它同時包含運算式的結構、優先順序與計算流程。

（四）學習與考試重點 考試常給一棵樹，要求寫出 preorder、inorder、postorder，或反過來由 expression 建樹。

一句話記憶：主運算子在 root，運算元多半在 leaf。
投影片 16：建立表達式樹

建立 Expression Tree：初始步驟

（一）這張投影片在說什麼？ 這張投影片開始示範如何建立 Expression Tree。通常會先讀取 expression，確認運算子與運算元，並依照優先順序決定哪個 operator 是目前子式的 root。

（二）核心觀念 建立樹時不能只看字元順序，而要看整體結構。括號內的內容會先形成子樹，高優先權的運算也會比低優先權的運算更早被組合。

（三）為什麼重要？ 這一步是後面建樹成功與否的基礎。如果 root 選錯，整棵樹的 traversal 結果就會全部錯。

（四）學習與考試重點 建樹時建議先把 expression 分成左子式、主要運算子、右子式，再遞迴處理左右子式。

一句話記憶：建樹第一步是找出目前 expression 的主運算子。

建立 Expression Tree：子樹組合

（一）這張投影片在說什麼？ 這張投影片延續建樹流程，說明如何把左右子式繼續拆成更小的樹。每一個子運算都會成為一棵小樹，再逐步接回到更大的樹上。

（二）核心觀念 Expression Tree 的建立具有遞迴特性：整個 expression 是一棵樹，左子式與右子式也各自是一棵樹。這和資料結構中樹的遞迴定義相同。

（四）學習與考試重點 請注意左右子樹不能顛倒，尤其遇到減法與除法時，左右順序會直接影響結果。

一句話記憶：Expression Tree 是由許多小的子運算樹組合而成。

四、完整中文講解

（一）Expression Tree 是什麼？

Expression Tree 是一種把表達式轉成樹狀結構的方式。它的好處是能清楚呈現運算順序。例如 A+B*C 中，乘法要先算，所以 * 會在 + 的右子樹裡面，而 + 是整棵樹的根。

（二）節點代表什麼？

運算子節點
通常是內部節點，例如 +、-、*、/、^。
運算元節點
通常是葉節點，例如 A、B、C、2、3。
左子樹
代表左運算元或左邊子表達式。
右子樹
代表右運算元或右邊子表達式。

（三）Expression Tree 與三種表示法

走訪方式對應表示法說明
InorderInfix左子樹 → 根 → 右子樹
PreorderPrefix根 → 左子樹 → 右子樹
PostorderPostfix左子樹 → 右子樹 → 根
例子：
表達式 A+B 的樹根是 +，左子節點是 A，右子節點是 B。
Inorder：A+B
Preorder：+AB
Postorder：AB+

程式題目教學內容

一、程式題目講解

這個程式示範如何從 Postfix Expression 建立 Expression Tree，並透過三種走訪方式輸出 Infix、Prefix 與 Postfix。

二、完整程式碼

以下保留本頁原本的完整 C 程式碼，並搭配中文註解說明主要功能與流程。

#include <stdio.h>
#include <stdlib.h>
#include <ctype.h>
#include <string.h>

/*
    主題 8：Expression Tree 表達式樹
    功能：從 Postfix Expression 建立 Expression Tree，並輸出三種走訪結果。

    Expression Tree 的觀念：
    1. 運算元 operand 會成為葉節點，例如 A、B、C、2、3
    2. 運算子 operator 會成為內部節點，例如 +、-、*、/、^
    3. 對樹做 inorder traversal，可以得到 infix
    4. 對樹做 preorder traversal，可以得到 prefix
    5. 對樹做 postorder traversal，可以得到 postfix

    範例 Postfix：ABC23^^*AB+/+
    對應 Infix：A + B * C ^ (2 ^ 3) / (A + B)
*/

#define MAX 300

typedef struct Node {
    char data;
    struct Node *left;
    struct Node *right;
} Node;

Node* stack[MAX];
int top = -1;

int isOperator(char ch) {
    return ch == '+' || ch == '-' || ch == '*' || ch == '/' || ch == '^';
}

Node* createNode(char data) {
    Node* n = (Node*)malloc(sizeof(Node));
    if (n == NULL) {
        printf("記憶體配置失敗。\n");
        exit(1);
    }
    n->data = data;
    n->left = NULL;
    n->right = NULL;
    return n;
}

void push(Node* n) {
    if (top >= MAX - 1) {
        printf("Stack 已滿。\n");
        exit(1);
    }
    stack[++top] = n;
}

Node* pop(void) {
    if (top < 0) {
        printf("Stack 為空，Postfix 可能不正確。\n");
        exit(1);
    }
    return stack[top--];
}

Node* buildExpressionTree(char postfix[]) {
    int i;
    for (i = 0; postfix[i] != '\0'; i++) {
        char x = postfix[i];

        if (isalnum(x)) {
            /* 運算元：建立葉節點後 push */
            Node* operand = createNode(x);
            push(operand);
            printf("讀到 %c：建立運算元節點，push 到 stack。\n", x);
        }
        else if (isOperator(x)) {
            /* 運算子：pop 兩棵子樹，組成新的樹 */
            Node* right = pop();  // 先 pop 的是右子樹
            Node* left = pop();   // 後 pop 的是左子樹
            Node* op = createNode(x);
            op->left = left;
            op->right = right;
            push(op);
            printf("讀到 %c：建立運算子節點，左子樹=%c，右子樹=%c，再 push 回 stack。\n",
                   x, left->data, right->data);
        }
    }
    return pop();
}

void inorder(Node* root) {
    if (root == NULL) return;
    if (isOperator(root->data)) printf("(");
    inorder(root->left);
    printf("%c", root->data);
    inorder(root->right);
    if (isOperator(root->data)) printf(")");
}

void preorder(Node* root) {
    if (root == NULL) return;
    printf("%c", root->data);
    preorder(root->left);
    preorder(root->right);
}

void postorder(Node* root) {
    if (root == NULL) return;
    postorder(root->left);
    postorder(root->right);
    printf("%c", root->data);
}

void freeTree(Node* root) {
    if (root == NULL) return;
    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main(void) {
    char postfix[MAX];
    Node* root;

    printf("請輸入 Postfix，例如 ABC23^^*AB+/+：");
    scanf("%299s", postfix);

    printf("\n建立 Expression Tree 的過程：\n");
    printf("----------------------------------------\n");
    root = buildExpressionTree(postfix);

    printf("\nExpression Tree 建立完成。\n");

    printf("Infix   中序走訪：");
    inorder(root);
    printf("\n");

    printf("Prefix  前序走訪：");
    preorder(root);
    printf("\n");

    printf("Postfix 後序走訪：");
    postorder(root);
    printf("\n");

    freeTree(root);
    return 0;
}
三、程式執行結果

範例輸入：ABC*+

請輸入 Postfix，例如 ABC23^^*AB+/+：
建立 Expression Tree 的過程：
----------------------------------------
讀到 A：建立運算元節點，push 到 stack。
讀到 B：建立運算元節點，push 到 stack。
讀到 C：建立運算元節點，push 到 stack。
讀到 *：建立運算子節點，左子樹=B，右子樹=C，再 push 回 stack。
讀到 +：建立運算子節點，左子樹=A，右子樹=*，再 push 回 stack。

Expression Tree 建立完成。
Infix   中序走訪：(A+(B*C))
Prefix  前序走訪：+A*BC
Postfix 後序走訪：ABC*+

A、B、C 會先建立為運算元節點。讀到 * 時，B 與 C 成為 * 的左右子樹；讀到 + 時，A 與 * 子樹成為 + 的左右子樹。最後中序、前序、後序走訪分別輸出不同表示法。

四、程式流程圖與流程圖說明

流程圖說明：本程式的主要邏輯可以依照下列順序理解：

  1. 輸入 Postfix expression
  2. 遇到運算元就建立節點並 push
  3. 遇到運算子就 pop 右子樹與左子樹
  4. 建立運算子節點並連接左右子樹
  5. 把新子樹 push 回 Stack
  6. 讀完後 Stack 頂端就是整棵樹
  7. 輸出三種 traversal 結果
五、重要函數與語法說明
  • createNode(data)：配置並建立新的樹節點。
  • push(Node*) / pop()：用 Stack 管理尚未組合的子樹。
  • inorder(root)：輸出接近 Infix 的結果。
  • preorder(root)：輸出 Prefix 結果。
  • postorder(root)：輸出 Postfix 結果。
  • malloc()：配置節點需要的記憶體。
六、整體說明

本題重點是 Expression Tree 的建立方式。Postfix 可以由左到右建樹，運算元是葉節點，運算子是內部節點。
