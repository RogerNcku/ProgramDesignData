七、Evaluation of a Postfix Expression 後序表示式求值

Postfix Expression 的特點是運算子出現在運算元之後，所以電腦可以由左到右掃描，並用 Stack 自動完成計算。遇到運算元就 push；遇到運算子就 pop 出需要的運算元進行計算，最後 Stack 只剩一個值，就是答案。

投影片 12：後序表示式求值演算法

Evaluation of a Postfix Expression 後序式求值演算法

（一）這張投影片在說什麼？ 這張投影片說明如何計算 Postfix Expression。因為 operator 已經放在對應 operand 後面，所以可以由左到右掃描，用 Stack 完成計算。

（二）核心觀念 遇到 operand 就 push 進 Stack；遇到 operator 就 pop 出需要的兩個 operand，計算後把結果再 push 回 Stack。最後 Stack 裡剩下的唯一元素就是答案。

（三）為什麼重要？ 這是 Postfix 最重要的優勢：不需要括號，也不需要重新判斷優先順序，只要照順序掃描即可。

（四）學習與考試重點 要特別注意 pop 的順序。若遇到減法或除法，先 pop 出來的通常是右運算元，後 pop 出來的是左運算元。

一句話記憶：Postfix 求值就是 operand push、operator pop-and-calculate。

四、完整中文講解

（一）Postfix 求值的核心

後序表示式的最大優點是不用括號，也不用再判斷運算優先順序。因為運算子已經被放在正確的位置，所以只要由左到右掃描即可。

（二）Stack 的運作方式

遇到運算元
直接 push 到 Stack，等待之後的運算子使用。
遇到運算子
從 Stack pop 出兩個值，進行運算。
運算後
把計算結果再 push 回 Stack，讓後續運算使用。
結束時
Stack 中最後留下的值，就是整個 expression 的答案。
簡單範例：
Postfix：23+
讀 2 → push 2
讀 3 → push 3
讀 + → pop 2 和 3，計算 2 + 3 = 5
答案：5

（三）注意左運算元與右運算元

遇到二元運算子時，先 pop 出來的是右運算元，後 pop 出來的是左運算元。例如 Stack 中有 6、3，遇到 / 時，應該是 6 / 3，而不是 3 / 6。

程式題目教學內容

一、程式題目講解

這個程式示範如何使用 Stack 計算後序表示式。學生需要理解 Postfix 不需要括號，只要從左到右讀取，遇到運算元 push，遇到運算子就 pop 兩個數字來計算。

二、完整程式碼

以下保留本頁原本的完整 C 程式碼，並搭配中文註解說明主要功能與流程。

#include <stdio.h>
#include <ctype.h>
#include <stdlib.h>
#include <string.h>

/*
    主題 7：Evaluation of a Postfix Expression
    功能：使用 Stack 計算後序表示式（Postfix Expression）

    後序表示式規則：
    1. 遇到運算元 operand：push 到 stack
    2. 遇到運算子 operator：pop 出右運算元與左運算元
    3. 計算後，把結果 push 回 stack
    4. 表達式讀完後，stack 最上方就是最後答案

    範例：633^2*81++//
    意思相當於：6 / ((3^3 * 2) / (8 + 1))
*/

#define MAX 200

double stack[MAX];
int top = -1;

void push(double value) {
    if (top >= MAX - 1) {
        printf("Stack 已滿，無法 push。\n");
        exit(1);
    }
    stack[++top] = value;
}

double pop(void) {
    if (top < 0) {
        printf("Stack 為空，無法 pop。請檢查 postfix 是否正確。\n");
        exit(1);
    }
    return stack[top--];
}

void printStack(void) {
    int i;
    printf("Stack：");
    if (top < 0) {
        printf("Empty");
    } else {
        for (i = 0; i <= top; i++) {
            printf("%.2f ", stack[i]);
        }
    }
    printf("\n");
}

int isOperator(char ch) {
    return ch == '+' || ch == '-' || ch == '*' || ch == '/' || ch == '^';
}

double power(double base, double exp) {
    double result = 1;
    int i;
    for (i = 0; i < (int)exp; i++) {
        result *= base;
    }
    return result;
}

double calculate(double left, double right, char op) {
    switch (op) {
        case '+': return left + right;
        case '-': return left - right;
        case '*': return left * right;
        case '/': return left / right;
        case '^': return power(left, right);
        default:
            printf("未知運算子：%c\n", op);
            exit(1);
    }
}

int main(void) {
    char postfix[MAX];
    int i;

    printf("請輸入後序表示式，例如 633^2*81++//：");
    scanf("%199s", postfix);

    printf("\n開始計算 Postfix Expression：%s\n", postfix);
    printf("----------------------------------------\n");

    for (i = 0; postfix[i] != '\0'; i++) {
        char x = postfix[i];

        if (isdigit(x)) {
            /* 字元數字轉成真正數值，例如 '6' - '0' = 6 */
            double value = x - '0';
            printf("讀到 %c：這是運算元，push %.2f\n", x, value);
            push(value);
            printStack();
        }
        else if (isOperator(x)) {
            /* 注意：先 pop 出來的是右運算元，後 pop 出來的是左運算元 */
            double right = pop();
            double left = pop();
            double result = calculate(left, right, x);

            printf("讀到 %c：這是運算子，pop %.2f 和 %.2f，計算 %.2f %c %.2f = %.2f\n",
                   x, right, left, left, x, right, result);

            push(result);
            printStack();
        }
        else {
            printf("忽略無效字元：%c\n", x);
        }

        printf("----------------------------------------\n");
    }

    if (top == 0) {
        printf("最後答案 = %.2f\n", pop());
    } else {
        printf("Postfix 格式可能不正確，Stack 中還有多個值。\n");
    }

    return 0;
}

四、程式流程圖與流程圖說明

流程圖說明：本程式的主要邏輯可以依照下列順序理解：

  1. 輸入 Postfix expression
  2. 從左到右讀取每個字元
  3. 遇到數字就 push 到 Stack
  4. 遇到運算子就 pop 右運算元與左運算元
  5. 完成運算後把結果 push 回 Stack
  6. 讀完後 Stack 最上方就是答案
五、重要函數與語法說明
  • push(value)：把數值放到 Stack 頂端。
  • pop()：取出 Stack 頂端數值，供運算使用。
  • printStack()：顯示目前 Stack 狀態。
  • isOperator(ch)：判斷字元是否為運算子。
  • pow(a,b)：計算次方運算。
六、整體說明

本題重點是 Postfix 求值規則。只要掌握「運算元 push、運算子 pop 兩個再計算」，就能理解後序表示式為何適合電腦處理。
