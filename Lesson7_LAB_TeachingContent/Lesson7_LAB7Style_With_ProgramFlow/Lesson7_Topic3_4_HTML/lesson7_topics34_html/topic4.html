四、Algorithm Infix-to-Postfix 中序轉後序演算法

這個主題說明如何把一般人類容易閱讀的中序式轉換成電腦容易處理的後序式。投影片使用的核心概念是：先依照運算優先順序把 expression 完整括號化，再把每個運算子移到對應右括號的位置，最後移除括號，就得到 postfix expression。

投影片 5：Algorithm Infix-to-Postfix

Algorithm Infix-to-Postfix 中序轉後序演算法

（一）這張投影片在說什麼？ 這張投影片說明一種概念式的 Infix-to-Postfix 轉換方法：先依照優先順序把中序式完整括號化，接著把每個運算子移到它對應的右括號位置，最後移除括號。

（二）核心觀念 重點是「每個運算子都要等它左右兩邊的運算元確定後，才放到後面」。因此 Postfix 的順序其實就是把運算流程從內到外、由先算到後算排列出來。

（三）為什麼重要？ 這種方法雖然不是最有效率的程式做法，但很適合初學者理解為什麼後序式不用括號也能保留正確運算順序。

（四）學習與考試重點 考試常給一個中序式，要求先補括號，再移動 operator，最後寫出 Postfix。

一句話記憶：中序轉後序，就是把 operator 移到對應右括號的位置。
投影片 6：Algorithm Infix-to-Postfix 範例

Algorithm Infix-to-Postfix 範例

（一）這張投影片在說什麼？ 這張投影片用實際例子示範中序轉後序。它讓你看到式子如何先被完整括號化，再一步一步把運算子移到右括號附近，最後刪掉所有括號。

（二）核心觀念 在範例中，乘除通常會比加減先形成較內層的小括號；加減則比較晚處理，所以它們的運算子通常會出現在 Postfix 較後面的位置。

（三）為什麼重要？ 透過這張範例可以理解：Postfix 不是隨便排列，而是根據實際計算先後順序排列。先算的運算子會先出現，最後才做的運算子會放在更後面。

（四）學習與考試重點 練習時建議每一步都寫出括號，不要直接心算，否則複雜式子很容易把 operator 放錯位置。

一句話記憶：Postfix 的 operator 順序，就是實際計算順序。

三、完整中文講解

（一）為什麼要把 Infix 轉成 Postfix？

Infix 很符合人類閱讀習慣，但是對電腦來說比較麻煩，因為需要判斷哪個運算子優先、括號裡面要先算、遇到同優先順序時要如何處理。Postfix 的好處是計算順序已經由排列決定，所以後面可以用 stack 直接求值。

（二）投影片中的概念式方法

投影片 5 的方法可以理解成四個動作：先完整括號化，再把每個運算子移到它所對應的右括號位置，右括號被取代後，再移除剩下的左括號，最後留下的就是 postfix expression。

簡單範例：
Infix：A + B * C
完整括號化：(A + (B * C))
先處理 B * C：B C *
再處理 A + 結果：A B C * +
Postfix：A B C * +

（三）投影片 6 的大型範例

投影片 6 使用的 expression 是 A + B * C ^ (2 ^ 3) / (A + B)。它先把整個 expression 完整括號化，接著依照括號層級把運算子放到右括號位置，最後得到類似 A B C 2 3 ^ ^ * A B + / + 的 postfix 結果。這表示電腦計算時會先處理 2 3 ^，再處理 C 與結果的 ^，接著做乘法、除法，最後做加法。

程式題目教學內容

一、程式題目講解

這個程式示範如何使用 Stack 將中序表示式轉成後序表示式。學生需要理解運算元直接輸出，運算子則必須依照優先順序暫存在 Stack 中。

二、完整程式碼

以下保留本頁原本的完整 C 程式碼，並搭配中文註解說明主要功能與流程。

#include <stdio.h>
#include <ctype.h>
#include <string.h>

/*
    主題 4：Infix-to-Postfix 中序轉後序
    目的：
    使用 stack 將簡單中序式轉成後序式。

    支援：
    1. 單字元運算元，例如 A、B、C、x、y、1、2。
    2. 運算子 + - * / ^。
    3. 括號 ( )。

    範例：
    輸入：A+B*C
    輸出：ABC*+
*/

#define MAX 200

char stack[MAX];
int top = -1;

void push(char ch) {
    if (top < MAX - 1) {
        stack[++top] = ch;
    }
}

char pop(void) {
    if (top >= 0) {
        return stack[top--];
    }
    return '\0';
}

char peek(void) {
    if (top >= 0) {
        return stack[top];
    }
    return '\0';
}

int isEmpty(void) {
    return top == -1;
}

int priority(char op) {
    if (op == '^') return 3;              // 次方最高
    if (op == '*' || op == '/') return 2; // 乘除第二
    if (op == '+' || op == '-') return 1; // 加減第三
    return 0;
}

int isOperator(char ch) {
    return ch == '+' || ch == '-' || ch == '*' || ch == '/' || ch == '^';
}

int main(void) {
    char infix[MAX];
    char postfix[MAX];
    int i, j = 0;

    printf("請輸入中序式，例如 A+B*C 或 (A+B)*C：");
    scanf("%199s", infix);

    printf("\n===== 轉換過程 =====\n");

    for (i = 0; infix[i] != '\0'; i++) {
        char ch = infix[i];

        if (isalnum(ch)) {
            /* 遇到運算元：直接加入 postfix */
            postfix[j++] = ch;
            printf("讀到運算元 %c：直接輸出到 postfix\n", ch);
        }
        else if (ch == '(') {
            /* 遇到左括號：放入 stack */
            push(ch);
            printf("讀到左括號 (：push 到 stack\n");
        }
        else if (ch == ')') {
            /* 遇到右括號：pop 到遇到左括號為止 */
            printf("讀到右括號 )：開始 pop 直到遇到 (\n");
            while (!isEmpty() && peek() != '(') {
                postfix[j++] = pop();
            }
            pop(); // 把左括號丟掉，不輸出
        }
        else if (isOperator(ch)) {
            /* 遇到運算子：先處理 stack 中優先順序較高或相同的運算子 */
            printf("讀到運算子 %c：比較 stack 頂端運算子優先順序\n", ch);
            while (!isEmpty() && peek() != '(' && priority(peek()) >= priority(ch)) {
                postfix[j++] = pop();
            }
            push(ch);
        }
    }

    /* 把 stack 中剩下的運算子全部輸出 */
    while (!isEmpty()) {
        postfix[j++] = pop();
    }

    postfix[j] = '\0';

    printf("\n===== 結果 =====\n");
    printf("Infix   ：%s\n", infix);
    printf("Postfix ：%s\n", postfix);

    return 0;
}
三、程式執行結果

範例輸入：A+B*C

請輸入中序式，例如 A+B*C 或 (A+B)*C：
===== 轉換過程 =====
讀到運算元 A：直接輸出到 postfix
讀到運算子 +：比較 stack 頂端運算子優先順序
讀到運算元 B：直接輸出到 postfix
讀到運算子 *：比較 stack 頂端運算子優先順序
讀到運算元 C：直接輸出到 postfix

===== 結果 =====
Infix   ：A+B*C
Postfix ：ABC*+

A 直接輸出，+ 先放入 Stack，B 直接輸出，* 的優先順序比 + 高所以先放入 Stack，C 直接輸出。掃描結束後依序彈出 Stack，得到 ABC*+。

四、程式流程圖與流程圖說明

流程圖說明：本程式的主要邏輯可以依照下列順序理解：

  1. 輸入中序表示式
  2. 從左到右讀取每個字元
  3. 運算元直接加入 postfix
  4. 左括號 push 進 Stack
  5. 右括號出現時 pop 到左括號
  6. 運算子依優先順序 push 或 pop
  7. 掃描結束後清空 Stack
  8. 輸出 postfix 結果
五、重要函數與語法說明
  • push(ch)：把運算子或左括號放入 Stack。
  • pop()：取出 Stack 最上方的運算子。
  • peek()：查看 Stack 最上方元素但不移除。
  • priority(op)：比較運算子優先順序。
  • isOperator(ch)：判斷字元是否為運算子。
六、整體說明

本題重點是 Infix-to-Postfix 的核心規則。Stack 可以暫存尚未輸出的運算子，讓程式依照正確優先順序產生後序式。
