五、Algorithm Infix-to-Prefix 中序轉前序演算法

這個主題延續前面的 Infix-to-Postfix，不同的是 Prefix 的運算子會放在兩個運算元前面。投影片的概念是：先把中序式依照優先順序完整括號化，再把每個運算子移到它對應的左括號位置，最後移除所有括號，就會得到 prefix expression。

投影片 7：Algorithm Infix-to-Prefix

Algorithm Infix-to-Prefix 中序轉前序演算法

（一）這張投影片在說什麼？ 這張投影片說明 Infix-to-Prefix 的基本方法。和後序不同，Prefix 是把運算子移到它對應的左括號位置，因此運算子會出現在相關運算元之前。

（二）核心觀念 轉 Prefix 時，仍然要先確認運算優先順序與括號結構。只有先知道哪一組運算要先做，才能知道哪一個 operator 要放到哪個位置。

（三）為什麼重要？ Prefix 可以把運算規則放在前面，對遞迴解析和樹狀結構特別直觀，因為根節點或主要運算子會先被看到。

（四）學習與考試重點 請注意 Prefix 和 Postfix 的差異：Postfix 是 operator 移到右括號位置，Prefix 是 operator 移到左括號位置。

一句話記憶：中序轉前序，就是把 operator 移到對應左括號的位置。

（二）核心觀念 Prefix 的排列順序通常會先出現整個式子的主運算子，接著才是左子式與右子式。這和 Expression Tree 的 Preorder Traversal 概念非常接近。

一句話記憶：Prefix 先看到主要運算子，再看到左右運算內容。

三、完整中文講解

（一）Prefix 是什麼？

Prefix 中文可稱為「前序表示法」。它的特徵是運算子出現在運算元前面。例如 A + B 的 prefix 形式是 + A B。如果是 A + B * C，因為 B * C 要先處理，所以 prefix 會寫成 + A * B C。

（二）與 Postfix 的差異

表示法形式例子 A + B * C運算子位置
Infix中序A + B * C運算子在中間
Postfix後序A B C * +運算子在後面
Prefix前序+ A * B C運算子在前面

（三）投影片的概念式方法

投影片 7 說明的做法是：先把 expression 完整括號化，然後把每一個 operation 移到它對應的左括號位置。當所有左括號都被運算子取代後，再刪除右括號，最後結果就是 prefix。

簡單範例：
Infix：A + B * C
完整括號化：(A + (B * C))
B * C 的 prefix：* B C
A + 結果的 prefix：+ A * B C
Prefix：+ A * B C

（四）程式常用方法

程式實作時，可以利用已經會寫的 infix-to-postfix 來完成 prefix。常見步驟是：反轉 infix，交換左右括號，轉成 postfix，再反轉 postfix，就會得到 prefix。這個方法的好處是可以重複使用 postfix 的 stack 邏輯。

程式題目教學內容

一、程式題目講解

這個程式示範將中序表示式轉成前序表示式。學生需要理解 Prefix 的運算子放在運算元前方，而且常見做法會先反轉字串，再利用 Infix-to-Postfix 的概念完成轉換。

二、完整程式碼

以下保留本頁原本的完整 C 程式碼，並搭配中文註解說明主要功能與流程。

#include <stdio.h>
#include <string.h>
#include <ctype.h>

/*
    主題 5：Infix-to-Prefix 中序轉前序
    說明：
    Prefix 的運算子放在運算元前面，例如：+ A B。

    常見做法：
    1. 將 infix 字串反轉。
    2. 反轉時把 '(' 和 ')' 對調。
    3. 對反轉後的式子做 infix-to-postfix。
    4. 再把得到的 postfix 反轉，就得到 prefix。

    範例：
    Infix : A+B*C
    Prefix: +A*BC
*/

#define MAX 200

char stack[MAX];
int top = -1;

void push(char ch) {
    if (top < MAX - 1) stack[++top] = ch;
}

char pop(void) {
    if (top >= 0) return stack[top--];
    return '\0';
}

char peek(void) {
    if (top >= 0) return stack[top];
    return '\0';
}

int isEmpty(void) {
    return top == -1;
}

int priority(char op) {
    if (op == '^') return 3;
    if (op == '*' || op == '/') return 2;
    if (op == '+' || op == '-') return 1;
    return 0;
}

int isOperator(char ch) {
    return ch == '+' || ch == '-' || ch == '*' || ch == '/' || ch == '^';
}

void reverseString(char s[]) {
    int i, j;
    char temp;
    for (i = 0, j = strlen(s) - 1; i < j; i++, j--) {
        temp = s[i];
        s[i] = s[j];
        s[j] = temp;
    }
}

void swapParentheses(char s[]) {
    int i;
    for (i = 0; s[i] != '\0'; i++) {
        if (s[i] == '(') s[i] = ')';
        else if (s[i] == ')') s[i] = '(';
    }
}

void infixToPostfix(char infix[], char postfix[]) {
    int i, j = 0;
    top = -1; // 每次轉換前先清空 stack

    for (i = 0; infix[i] != '\0'; i++) {
        char ch = infix[i];

        if (isalnum(ch)) {
            // 運算元直接輸出
            postfix[j++] = ch;
        }
        else if (ch == '(') {
            // 左括號先進 stack
            push(ch);
        }
        else if (ch == ')') {
            // 右括號：一直 pop 到左括號
            while (!isEmpty() && peek() != '(') {
                postfix[j++] = pop();
            }
            pop(); // 丟掉左括號
        }
        else if (isOperator(ch)) {
            // 若 stack 頂端運算子優先順序較高或相同，就先輸出
            while (!isEmpty() && peek() != '(' && priority(peek()) >= priority(ch)) {
                postfix[j++] = pop();
            }
            push(ch);
        }
    }

    while (!isEmpty()) {
        postfix[j++] = pop();
    }

    postfix[j] = '\0';
}

void infixToPrefix(char infix[], char prefix[]) {
    char temp[MAX];
    char postfix[MAX];

    strcpy(temp, infix);

    // 第 1 步：反轉 infix
    reverseString(temp);

    // 第 2 步：左右括號互換
    swapParentheses(temp);

    // 第 3 步：轉成 postfix
    infixToPostfix(temp, postfix);

    // 第 4 步：反轉 postfix，得到 prefix
    reverseString(postfix);
    strcpy(prefix, postfix);
}

int main(void) {
    char infix[MAX];
    char prefix[MAX];

    printf("請輸入中序式，例如 A+B*C 或 (A+B)*C：");
    scanf("%199s", infix);

    infixToPrefix(infix, prefix);

    printf("\n===== 結果 =====\n");
    printf("Infix  ：%s\n", infix);
    printf("Prefix ：%s\n", prefix);

    return 0;
}
三、程式執行結果

範例輸入：A+B*C

請輸入中序式，例如 A+B*C 或 (A+B)*C：
===== 結果 =====
Infix  ：A+B*C
Prefix ：+A*BC

原式 A+B*C 中，乘法 B*C 優先，最後才與 A 相加。因此 Prefix 會把最後執行的 + 放在最前面，得到 +A*BC。

流程圖說明：本程式的主要邏輯可以依照下列順序理解：

  1. 輸入中序表示式
  2. 反轉整個字串
  3. 反轉時交換左右括號

五、重要函數與語法說明
  • reverseString(s)：反轉字串順序。
  • swapParentheses(s)：反轉後修正括號方向。
  • infixToPostfix()：利用 Stack 轉換成 postfix。
  • priority(op)：判斷運算子優先順序。
  • push() / pop() / peek()：管理 Stack。
