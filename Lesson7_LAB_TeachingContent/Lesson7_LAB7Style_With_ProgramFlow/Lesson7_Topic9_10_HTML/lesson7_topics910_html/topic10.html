投影片 22：加減號與括號處理

加減號與括號處理

（一）這張投影片在說什麼？ 這張投影片進一步展示加減號與括號在程式中的處理。加減優先權較低，所以遇到它們時，Stack 中較高優先權的乘除通常要先被輸出。

（二）核心觀念 左括號通常直接 push，表示括號內形成一個暫時區域；右括號則會一直 pop，直到遇到左括號，最後把左括號丟掉但不輸出。

（三）為什麼重要？ 括號處理是 Infix-to-Postfix 程式最容易出錯的部分。它決定哪些 operator 只能在括號範圍內比較，不能跨越括號亂 pop。

（四）學習與考試重點 遇到右括號時，記得 pop 到左括號為止；左括號本身不能出現在 postfix output。

一句話記憶：右括號負責把括號內的 operator 全部結算出來。

二、完整中文講解

主題 10 是整個 Lesson 7 的程式實作重點。前面已經學過中序轉後序的規則，這裡把規則寫成 C 程式。程式的核心想法是：從左到右讀取 infix expression，運算元直接輸出，運算子先放進 Stack，等到遇到較低優先順序的運算子、右括號或輸入結束時，再把 Stack 裡的運算子 pop 出來。

程式通常會包含幾個重要函式：push() 把運算子放入 Stack，pop() 取出 Stack 最上方的運算子，priority() 判斷運算子優先順序，infixToPostfix() 執行轉換演算法。

範例：輸入 A+B*C。因為 * 比 + 優先，所以後序結果是 ABC*+。如果輸入 (A+B)*C，括號會讓 A+B 先處理，所以結果是 AB+C*。

程式題目教學內容

一、程式題目講解

這個程式是 Infix-to-Postfix 的完整實作版，使用 Stack 結構管理運算子與括號，將使用者輸入的中序表示式轉成後序表示式。

二、完整程式碼

以下保留本頁原本的完整 C 程式碼，並搭配中文註解說明主要功能與流程。

#include <stdio.h>
#include <ctype.h>
#include <string.h>

#define MAX 100

// Stack 用來暫存運算子與括號
typedef struct {
    char data[MAX];
    int top;
} Stack;

// 初始化 Stack
void init(Stack *s) {
    s->top = -1;
}

// 判斷 Stack 是否為空
int isEmpty(Stack *s) {
    return s->top == -1;
}

// push：把元素放入 Stack
void push(Stack *s, char ch) {
    if (s->top >= MAX - 1) {
        printf("Stack overflow!\n");
        return;
    }
    s->data[++(s->top)] = ch;
}

// pop：從 Stack 取出最上面的元素
char pop(Stack *s) {
    if (isEmpty(s)) {
        return '\0';
    }
    return s->data[(s->top)--];
}

// peek：只查看 Stack 最上面的元素，不取出
char peek(Stack *s) {
    if (isEmpty(s)) {
        return '\0';
    }
    return s->data[s->top];
}

// 回傳運算子的優先順序
// 數字越大，代表越優先
int priority(char op) {
    if (op == '^') return 3;
    if (op == '*' || op == '/') return 2;
    if (op == '+' || op == '-') return 1;
    return 0;
}

// 判斷是否為運算子
int isOperator(char ch) {
    return ch == '+' || ch == '-' || ch == '*' || ch == '/' || ch == '^';
}

// 中序轉後序：核心函式
void infixToPostfix(char infix[], char postfix[]) {
    Stack s;
    init(&s);

    int i = 0; // 掃描 infix 的位置
    int j = 0; // 寫入 postfix 的位置

    while (infix[i] != '\0') {
        char ch = infix[i];

        // 忽略空白
        if (ch == ' ') {
            i++;
            continue;
        }

        // 情況 1：如果是運算元，直接輸出到 postfix
        if (isalnum(ch)) {
            postfix[j++] = ch;
        }
        // 情況 2：如果是左括號，直接 push 到 Stack
        else if (ch == '(') {
            push(&s, ch);
        }
        // 情況 3：如果是右括號，pop 到遇到左括號為止
        else if (ch == ')') {
            while (!isEmpty(&s) && peek(&s) != '(') {
                postfix[j++] = pop(&s);
            }
            pop(&s); // 把左括號 pop 掉，但不輸出
        }
        // 情況 4：如果是運算子
        else if (isOperator(ch)) {
            // Stack 上方若有優先順序大於或等於目前運算子的運算子，就先輸出
            // 注意：此簡化版本把 ^ 也當成左結合；若要完整處理右結合可再調整
            while (!isEmpty(&s) && peek(&s) != '(' && priority(peek(&s)) >= priority(ch)) {
                postfix[j++] = pop(&s);
            }
            push(&s, ch);
        }

        i++;
    }

    // 掃描結束後，把 Stack 裡剩下的運算子全部輸出
    while (!isEmpty(&s)) {
        postfix[j++] = pop(&s);
    }

    postfix[j] = '\0';
}

int main() {
    char infix[MAX];
    char postfix[MAX];

    printf("請輸入中序表示式，例如 A+B*C 或 (A+B)*(C-D)：\n");
    fgets(infix, MAX, stdin);

    // 去除 fgets 讀到的換行符號
    infix[strcspn(infix, "\n")] = '\0';

    infixToPostfix(infix, postfix);

    printf("\nInfix   Expression：%s\n", infix);
    printf("Postfix Expression：%s\n", postfix);

    return 0;
}
三、程式執行結果

範例輸入：A+B*C

請輸入中序表示式，例如 A+B*C 或 (A+B)*(C-D)：

Infix   Expression：A+B*C
Postfix Expression：ABC*+

A 與 B、C 都是運算元，所以直接輸出。+ 與 * 是運算子，需要根據優先順序處理。因為 * 比 + 優先，所以最後輸出結果為 ABC*+。

四、程式流程圖與流程圖說明

流程圖說明：本程式的主要邏輯可以依照下列順序理解：

  1. 讀取使用者輸入的中序表示式
  2. 初始化 Stack
  3. 掃描 expression 中每個字元
  4. 運算元直接加入 postfix
  5. 括號控制局部運算範圍
  6. 運算子依照 priority 比較並處理
  7. 清空 Stack
  8. 印出 Infix 與 Postfix
五、重要函數與語法說明
  • typedef struct Stack：把陣列與 top 包成 Stack 結構。
  • init(Stack *s)：初始化 Stack。
  • isEmpty(Stack *s)：判斷 Stack 是否為空。
  • push() / pop() / peek()：Stack 的基本操作。
  • fgets()：讀取含空白也可處理的輸入字串。
  • strcspn()：移除 fgets 讀到的換行符號。
