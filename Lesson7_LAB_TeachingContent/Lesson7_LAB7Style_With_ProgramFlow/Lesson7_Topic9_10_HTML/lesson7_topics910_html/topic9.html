Expression Tree 的 Postorder 與 Preorder Traversal

（一）這張投影片在說什麼？ 這張投影片重點在表達式樹走訪。不同走訪順序會產生不同 expression：Preorder 是 Root、Left、Right；Postorder 是 Left、Right、Root。

（二）核心觀念 Preorder 會先拜訪 operator，因此結果是 Prefix；Postorder 會最後拜訪 operator，因此結果是 Postfix。Inorder 則是 Left、Root、Right，對應 Infix。

（三）為什麼重要？ 這張投影片是把 Tree 與 Expression 表示法連接起來的關鍵。只要懂 traversal，就不必死背 prefix/postfix 的轉換結果。

（四）學習與考試重點 請熟記三個順序：Preorder = VLR，Inorder = LVR，Postorder = LRV。

一句話記憶：前序得 Prefix，後序得 Postfix，中序得 Infix。
二、完整中文講解

Expression Tree 是把運算式轉成樹狀結構的一種方式。樹中的葉節點通常是運算元，例如 A、B、C、D；內部節點通常是運算子，例如 +、-、*、/。這種結構的好處是：運算順序可以直接從樹的上下層關係看出來。

在 Expression Tree 中，如果我們使用不同的 traversal，就會得到不同的 expression 表示法。Preorder 是 Root → Left → Right，會得到 Prefix expression。Inorder 是 Left → Root → Right，會得到 Infix expression。Postorder 是 Left → Right → Root，會得到 Postfix expression。

範例：表達式 (A + B) * (C - D) 可以表示成一棵樹，根節點是 *，左子樹是 A+B，右子樹是 C-D。
Preorder：* + A B - C D
Inorder：((A+B)*(C-D))
Postorder：A B + C D - *
走訪方式順序得到的表示法意義
PreorderRoot → Left → RightPrefix運算子先出現
InorderLeft → Root → RightInfix接近一般數學寫法
PostorderLeft → Right → RootPostfix運算子最後出現，適合 Stack 計算

五、可編輯 C 程式範例：Expression Tree Traversal

你可以直接在下面編輯程式碼，或按「複製程式碼」後貼到線上 C 編輯器執行。

expression_tree_traversal.c

程式題目教學內容

一、程式題目講解

這個程式手動建立一棵 Expression Tree，並示範前序、中序、後序三種走訪結果。學生需要理解不同走訪順序會產生不同 expression 表示法。

二、完整程式碼

以下保留本頁原本的完整 C 程式碼，並搭配中文註解說明主要功能與流程。

#include <stdio.h>
#include <stdlib.h>

// 節點結構：可以存放運算子，也可以存放運算元
// 在 Expression Tree 中：
// 1. 葉節點通常是運算元，例如 A、B、C、D
// 2. 內部節點通常是運算子，例如 +、-、*、/
typedef struct Node {
    char data;
    struct Node *left;
    struct Node *right;
} Node;

// 建立新節點
Node* createNode(char data) {
    Node* node = (Node*)malloc(sizeof(Node));
    node->data = data;
    node->left = NULL;
    node->right = NULL;
    return node;
}

// Preorder 前序走訪：Root -> Left -> Right
// 對 Expression Tree 來說，前序走訪會得到 Prefix Expression
void preorder(Node* root) {
    if (root == NULL) return;
    printf("%c ", root->data);   // 先印根節點
    preorder(root->left);         // 再走左子樹
    preorder(root->right);        // 最後走右子樹
}

// Inorder 中序走訪：Left -> Root -> Right
// 對 Expression Tree 來說，中序走訪會接近 Infix Expression
// 為了讓括號清楚，這裡每個子樹都加上括號
void inorder(Node* root) {
    if (root == NULL) return;
    printf("(");
    inorder(root->left);          // 先走左子樹
    printf("%c", root->data);     // 再印根節點
    inorder(root->right);         // 最後走右子樹
    printf(")");
}

// Postorder 後序走訪：Left -> Right -> Root
// 對 Expression Tree 來說，後序走訪會得到 Postfix Expression
void postorder(Node* root) {
    if (root == NULL) return;
    postorder(root->left);        // 先走左子樹
    postorder(root->right);       // 再走右子樹
    printf("%c ", root->data);   // 最後印根節點
}

// 釋放樹的記憶體
void freeTree(Node* root) {
    if (root == NULL) return;
    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main() {
    // 建立表達式樹：(A + B) * (C - D)
    //
    //             *
    //           /   \
    //          +     -
    //         / \   / \
    //        A   B C   D
    //
    // Prefix  : * + A B - C D
    // Infix   : ((A+B)*(C-D))
    // Postfix : A B + C D - *

    Node* root = createNode('*');
    root->left = createNode('+');
    root->right = createNode('-');

    root->left->left = createNode('A');
    root->left->right = createNode('B');

    root->right->left = createNode('C');
    root->right->right = createNode('D');

    printf("Expression Tree Traversal 範例\n\n");

    printf("Prefix  Expression：");
    preorder(root);
    printf("\n");

    printf("Infix   Expression：");
    inorder(root);
    printf("\n");

    printf("Postfix Expression：");
    postorder(root);
    printf("\n");

    freeTree(root);
    return 0;
}
三、程式執行結果

程式內建樹狀結構：(A+B)*(C-D)

Expression Tree Traversal 範例

Prefix  Expression：* + A B - C D 
Infix   Expression：(((A)+(B))*((C)-(D)))
Postfix Expression：A B + C D - *

同一棵樹用前序走訪會得到 Prefix，用中序走訪會接近 Infix，用後序走訪會得到 Postfix。輸出結果顯示樹的走訪順序會直接對應到 expression 的表示法。

四、程式流程圖與流程圖說明

流程圖說明：本程式的主要邏輯可以依照下列順序理解：

  1. 手動建立每一個節點
  2. 用指標連接左子樹與右子樹
  3. 形成完整 Expression Tree
  4. 執行 preorder 走訪
  5. 執行 inorder 走訪
  6. 執行 postorder 走訪
  7. 比較三種輸出結果
五、重要函數與語法說明
  • createNode(data)：建立新的樹節點並初始化左右指標。
  • preorder(root)：Root → Left → Right，會得到 Prefix。
  • inorder(root)：Left → Root → Right，會得到 Infix。
  • postorder(root)：Left → Right → Root，會得到 Postfix。
  • malloc()：配置節點記憶體。
六、整體說明

本題重點是樹的走訪與 expression 表示法的關係。Prefix、Infix、Postfix 可以視為同一棵 Expression Tree 的不同走訪結果。
