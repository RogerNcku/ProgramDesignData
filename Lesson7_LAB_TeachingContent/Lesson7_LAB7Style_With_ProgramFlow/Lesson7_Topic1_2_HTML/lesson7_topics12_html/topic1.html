投影片 2：Expressions definitions

Expressions、Infix、Postfix、Prefix 基本定義

（一）這張投影片在說什麼？ 這張投影片正式定義 Expression 是由 operands 與 operators 組成。Operand 是被運算的資料，例如 A、B、5、10；Operator 是負責計算的符號，例如 +、-、*、/。

（二）核心觀念 同一個運算可以有三種常見寫法：Infix 是運算子放中間，例如 A+B；Postfix 是運算子放後面，例如 AB+；Prefix 是運算子放前面，例如 +AB。差別只在符號位置，但會影響程式如何解析。

（三）為什麼重要？ 人類習慣 Infix，因為它接近數學課本的寫法；電腦常用 Postfix 或 Prefix，因為它們可以減少括號與優先順序的判斷。

（四）學習與考試重點 請特別記住：Infix 要考慮括號與優先順序；Postfix 與 Prefix 通常可以直接配合 Stack 或 Tree 處理。

一句話記憶：Infix 給人看，Postfix / Prefix 更方便給電腦算。
一、完整中文講解

核心定義

Expression 可以翻成「表達式」或「運算式」。它是由 operands（運算元）與 operators（運算子）組合而成，用來完成計算。例如 5 / 3 * 8 * 6 + 1 裡面，5、3、8、6、1 是運算元，/、*、*、+ 是運算子。

投影片 2 進一步說明三種表示法：Infix、Postfix、Prefix。它們表示的是同一個計算概念，但運算子擺放的位置不同。

  • Infix 中序：運算子放在兩個運算元中間，例如 A + B。
  • Postfix 後序：運算子放在兩個運算元後面，例如 A B +。
  • Prefix 前序：運算子放在兩個運算元前面，例如 + A B。

人類通常習慣 Infix，因為它符合一般數學書寫方式；但是電腦在計算時，Postfix 與 Prefix 比較容易處理，因為它們不太需要額外判斷括號與優先順序。

三、範例說明

以 A + B 為例：

  • A + B：Infix，因為 + 在 A 和 B 中間。
  • A B +：Postfix，因為 + 放在 A 和 B 後面。
  • + A B：Prefix，因為 + 放在 A 和 B 前面。

再以投影片中的 5 / 3 * 8 * 6 + 1 為例，它可以轉換成 Postfix 或 Prefix。這也是後續課程會學到的「中序轉後序」與「中序轉前序」。

程式題目教學內容

一、程式題目講解

這個程式的目的不是計算數學答案，而是讓學生理解「表達式」是由運算元、運算子與其他符號組成。學生需要先學會辨認每個字元的角色，後面才能理解中序、後序、前序與運算式樹。

二、完整程式碼

以下保留本頁原本的完整 C 程式碼，並搭配中文註解說明主要功能與流程。

#include <stdio.h>
#include <ctype.h>
#include <string.h>

/*
    主題一：Expressions 表達式基本概念
    目的：讀取一個 expression，判斷每一個字元是：
          1. 運算元 operand，例如 A、B、5、3
          2. 運算子 operator，例如 +、-、*、/
          3. 括號或其他符號

    這個程式不是為了計算答案，而是先讓電腦能夠「看懂」表達式的組成。
*/

// 判斷字元是不是運算子
int isOperator(char ch) {
    return ch == '+' || ch == '-' || ch == '*' || ch == '/' || ch == '^';
}

int main() {
    // 你可以修改這一行，換成自己的 expression
    char exp[] = "5/3*8*6+1";

    int operandCount = 0;
    int operatorCount = 0;

    printf("原始 Expression：%s\n\n", exp);
    printf("逐一分析 expression 裡面的元素：\n");

    for (int i = 0; i < strlen(exp); i++) {
        char ch = exp[i];

        // 如果是空白，就跳過
        if (ch == ' ') {
            continue;
        }

        // isalnum() 可以判斷是否為英文字母或數字
        if (isalnum(ch)) {
            printf("%c  是 Operand（運算元）\n", ch);
            operandCount++;
        }
        else if (isOperator(ch)) {
            printf("%c  是 Operator（運算子）\n", ch);
            operatorCount++;
        }
        else if (ch == '(' || ch == ')') {
            printf("%c  是 Parenthesis（括號）\n", ch);
        }
        else {
            printf("%c  是其他符號\n", ch);
        }
    }

    printf("\n統計結果：\n");
    printf("Operand 數量：%d\n", operandCount);
    printf("Operator 數量：%d\n", operatorCount);

    printf("\n三種表示法的概念：\n");
    printf("Infix   ：A + B  （運算子在中間）\n");
    printf("Postfix ：A B +  （運算子在後面）\n");
    printf("Prefix  ：+ A B  （運算子在前面）\n");

    return 0;
}

四、程式流程圖與流程圖說明

流程圖說明：本程式的主要邏輯可以依照下列順序理解：

  1. 設定一個 expression 字串
  2. 從左到右讀取每個字元
  3. 遇到空白就略過
  4. 用 isalnum() 判斷是否為運算元
  5. 用 isOperator() 判斷是否為運算子
  6. 統計並輸出分析結果
五、重要函數與語法說明
  • isOperator(ch)：自訂函數，用來判斷字元是否為 +、-、*、/、^ 等運算子。
  • isalnum(ch)：C 標準函數，用來判斷字元是否為英文字母或數字，本程式用它來判斷 Operand。
  • strlen(exp)：取得字串長度，讓 for 迴圈知道要掃描幾個字元。
  • printf()：輸出分析結果與統計數量。
六、整體說明
