三、Postfix and Prefix Representations 後序與前序表示法

這個主題的核心是：Infix 把運算子放在中間；Postfix 把運算子放在後面；Prefix 把運算子放在前面。Postfix 與 Prefix 的好處是可以減少括號與優先順序判斷，因此很適合電腦用 stack 或遞迴方式處理。

Postfix and Prefix Representations 後序與前序表示法

（一）這張投影片在說什麼？ 這張投影片比較 Postfix 與 Prefix。Postfix 把運算子放在運算元後面，Prefix 把運算子放在運算元前面，兩者都能明確表達運算順序。

（二）核心觀念 Postfix 的典型例子是 AB+，代表 A+B；Prefix 的典型例子是 +AB，也代表 A+B。當式子變複雜時，這兩種表示法可以避免中序式中括號與優先順序造成的歧義。

（三）為什麼重要？ Postfix 特別適合 Stack 求值：遇到 operand 就推入 Stack，遇到 operator 就取出運算元計算。Prefix 則常用於由右往左掃描，或和遞迴、樹狀結構一起理解。

（四）學習與考試重點 請會把簡單 Infix 轉成 Postfix 或 Prefix，也要能看懂運算子位置如何決定計算順序。

一句話記憶：Postfix 運算子在後，Prefix 運算子在前。

三、完整中文講解

（一）Infix、Postfix、Prefix 的差別

Infix 是人類最熟悉的寫法，例如 A + B。運算子 + 放在 A 與 B 的中間，所以叫做中序表示法。Postfix 則是把運算子放在後面，因此 A + B 會寫成 A B +。Prefix 則把運算子放在前面，所以會寫成 + A B。

表示法形式運算子位置例子
Infix 中序A + B中間A + B
Postfix 後序A B +後面A B +
Prefix 前序+ A B前面+ A B

（二）為什麼 Postfix / Prefix 適合電腦？

中序式雖然容易閱讀，但是電腦需要額外判斷括號與優先順序。例如 A + B * C 必須知道乘法要先做，所以不能單純從左到右計算。Postfix 可以寫成 A B C * +，Prefix 可以寫成 + A * B C，這兩種形式都把計算順序藏在符號排列中，因此比較適合演算法處理。

範例：
Infix：A + B * C
Postfix：A B C * +
Prefix：+ A * B C

原因：B * C 要先算，所以在 postfix 中會先出現 B C *，再和 A 做 +。

程式題目教學內容

一、程式題目講解

這個程式讓學生輸入簡單的二元中序式，例如 A+B，並觀察同一個 expression 如何改寫成 Infix、Postfix 與 Prefix 三種形式。

二、完整程式碼

以下保留本頁原本的完整 C 程式碼，並搭配中文註解說明主要功能與流程。

#include <stdio.h>
#include <ctype.h>
#include <string.h>

/*
    主題 3：Postfix 與 Prefix 表示法示範
    目的：
    1. 讓使用者輸入一個簡單的二元運算式，例如 A+B。
    2. 程式將它改寫成 Infix、Postfix、Prefix 三種形式。

    注意：
    這份程式是「觀念示範版」，主要處理形如 A+B、x*y 這種
    一個運算子、兩個運算元的簡單 expression。
*/

int isOperator(char ch) {
    return ch == '+' || ch == '-' || ch == '*' || ch == '/' || ch == '^';
}

int main(void) {
    char exp[100];
    char left = '\0', right = '\0', op = '\0';
    int i;

    printf("請輸入簡單中序式，例如 A+B 或 x*y：");
    scanf("%99s", exp);

    /* 從輸入字串中找出：左運算元、運算子、右運算元 */
    for (i = 0; i < strlen(exp); i++) {
        if (isOperator(exp[i])) {
            op = exp[i];
            left = exp[i - 1];
            right = exp[i + 1];
            break;
        }
    }

    if (op == '\0') {
        printf("沒有找到運算子，請輸入例如 A+B 的格式。\n");
        return 0;
    }

    printf("\n===== 三種 expression 表示法 =====\n");
    printf("Infix   中序：%c %c %c\n", left, op, right);
    printf("Postfix 後序：%c %c %c\n", left, right, op);
    printf("Prefix  前序：%c %c %c\n", op, left, right);

    printf("\n說明：\n");
    printf("Infix   ：運算子放在兩個運算元中間。\n");
    printf("Postfix ：運算子放在兩個運算元後面。\n");
    printf("Prefix  ：運算子放在兩個運算元前面。\n");

    return 0;
}

範例輸入：A+B

請輸入簡單中序式，例如 A+B 或 x*y：
===== 三種 expression 表示法 =====
Infix   中序：A + B
Postfix 後序：A B +
Prefix  前序：+ A B

說明：
Infix   ：運算子放在兩個運算元中間。
Postfix ：運算子放在兩個運算元後面。
Prefix  ：運算子放在兩個運算元前面。

A+B 的運算子是 +，左右運算元是 A 與 B。Infix 把 + 放中間，Postfix 把 + 放後面，Prefix 把 + 放前面，因此輸出分別是 A+B、AB+、+AB。

五、重要函數與語法說明
  • isOperator(ch)：判斷目前字元是否為運算子。
  • scanf("%99s", exp)：讀取使用者輸入的 expression，並限制長度避免超出陣列。
  • strlen(exp)：讓迴圈可以掃描完整字串。
  • printf()：顯示三種表示法。
