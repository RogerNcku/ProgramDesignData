Infix Expressions 中序表示法

（一）這張投影片在說什麼？ 這張投影片說明 Infix Expression，也就是我們最熟悉的中序寫法。中序的特色是運算子出現在兩個運算元中間，例如 A+B、A*B+C。

（二）核心觀念 Infix 的問題在於它必須依賴 operation hierarchy，也就是運算優先順序。一般規則是括號最優先，接著乘除，最後加減；如果沒有正確處理，計算結果就會錯。

（三）為什麼重要？ 這也是為什麼電腦不能只從左到右盲目計算 Infix。它必須先判斷括號、優先順序與結合方向，才知道真正的計算流程。

（四）學習與考試重點 常見考點是比較 5+2*3 與 (5+2)*3，前者先乘後加，後者先算括號。

一、完整中文講解

核心觀念

Infix Expression 是一般數學中最常見的寫法，也就是運算子放在兩個運算元中間。例如 A + B、5 + 2 * 3 都是 Infix。

投影片 3 強調兩個重點。第一，Infix 需要 operation hierarchy，也就是運算優先順序。第二，有些時候必須使用括號 ( )，因為括號可以改變原本的計算順序。

例如 5 + 2 * 3 不能單純從左到右算。因為乘法優先於加法，所以要先算 2 * 3，結果是 11。但是 (5 + 2) * 3 因為括號最優先，所以要先算 5 + 2，結果是 21。

三、範例比較

5 + 2 * 3

結果：11

範例 B：有括號

(5 + 2) * 3

結果：21

這表示 Infix 雖然容易閱讀，但它需要額外規則才能正確計算。這也是為什麼資料結構會介紹 stack、postfix 與 expression tree。

程式題目教學內容

一、程式題目講解

這個程式示範中序表示式為什麼需要「運算子優先順序」與「括號」。學生需要理解同樣是數字與運算子，不同括號位置會改變計算順序與結果。

二、完整程式碼

以下保留本頁原本的完整 C 程式碼，並搭配中文註解說明主要功能與流程。

#include <stdio.h>
#include <ctype.h>
#include <string.h>

/*
    主題二：Infix Expressions 中序表示法
    目的：示範中序表示式為什麼需要「運算優先順序」與「括號」。

    範例：
        5 + 2 * 3      結果是 11，因為 * 比 + 優先
        (5 + 2) * 3    結果是 21，因為括號最優先

    程式方法：
        使用兩個 stack：
        1. values[] 儲存數字
        2. ops[] 儲存運算子
*/

#define MAX 100

// 數字 stack
int values[MAX];
int vTop = -1;

// 運算子 stack
char ops[MAX];
int oTop = -1;

// push 數字
void pushValue(int v) {
    values[++vTop] = v;
}

// pop 數字
int popValue() {
    return values[vTop--];
}

// push 運算子
void pushOp(char op) {
    ops[++oTop] = op;
}

// pop 運算子
char popOp() {
    return ops[oTop--];
}

// 查看最上面的運算子，但不移除
char peekOp() {
    return ops[oTop];
}

// 判斷運算子優先順序
int priority(char op) {
    if (op == '*' || op == '/') return 2;
    if (op == '+' || op == '-') return 1;
    return 0;
}

// 實際做一次運算
int applyOp(int a, int b, char op) {
    if (op == '+') return a + b;
    if (op == '-') return a - b;
    if (op == '*') return a * b;
    if (op == '/') return a / b;
    return 0;
}

// 從 stack 取出兩個數字與一個運算子，完成一次計算
void computeOnce() {
    int b = popValue();       // 注意：第二個運算元先被 pop 出來
    int a = popValue();       // 第一個運算元後被 pop 出來
    char op = popOp();
    int result = applyOp(a, b, op);

    printf("計算：%d %c %d = %d\n", a, op, b, result);
    pushValue(result);
}

// 計算 infix expression，這裡假設數字都是一位數，方便教學
int evaluateInfix(char exp[]) {
    for (int i = 0; i < strlen(exp); i++) {
        char ch = exp[i];

        if (ch == ' ') continue;

        // 遇到數字：放入 values stack
        if (isdigit(ch)) {
            pushValue(ch - '0');
        }
        // 遇到左括號：放入 ops stack
        else if (ch == '(') {
            pushOp(ch);
        }
        // 遇到右括號：一直計算到遇到左括號為止
        else if (ch == ')') {
            while (oTop >= 0 && peekOp() != '(') {
                computeOnce();
            }
            popOp(); // 移除左括號 '('
        }
        // 遇到運算子：根據優先順序處理
        else if (ch == '+' || ch == '-' || ch == '*' || ch == '/') {
            while (oTop >= 0 && priority(peekOp()) >= priority(ch)) {
                computeOnce();
            }
            pushOp(ch);
        }
    }

    // 把剩下的運算子全部算完
    while (oTop >= 0) {
        computeOnce();
    }

    return popValue();
}

int main() {
    char exp1[] = "5+2*3";
    char exp2[] = "(5+2)*3";

    printf("範例一：%s\n", exp1);
    int ans1 = evaluateInfix(exp1);
    printf("結果：%d\n\n", ans1);

    // 重設 stack，準備算第二題
    vTop = -1;
    oTop = -1;

    printf("範例二：%s\n", exp2);
    int ans2 = evaluateInfix(exp2);
    printf("結果：%d\n", ans2);

    return 0;
}
三、程式執行結果

程式內建兩個範例：5+2*3 與 (5+2)*3

範例一：5+2*3
計算：2 * 3 = 6
計算：5 + 6 = 11
結果：11

範例二：(5+2)*3
計算：5 + 2 = 7
計算：7 * 3 = 21
結果：21

第一個範例會先算 2*3 得到 6，再算 5+6 得到 11。第二個範例因為括號最優先，所以先算 5+2 得到 7，再乘以 3 得到 21。

四、程式流程圖與流程圖說明

流程圖說明：本程式的主要邏輯可以依照下列順序理解：

  1. 準備數字 Stack 與運算子 Stack
  2. 讀取中序表示式中的每個字元
  3. 數字放入 values Stack
  4. 運算子依照優先順序放入或先計算
  5. 遇到括號時優先處理括號內運算
  6. 輸出最後計算結果
五、重要函數與語法說明
  • pushValue(v)：把數字放入 values Stack。
  • popValue()：從 values Stack 取出要計算的數字。
  • pushOp(op) / popOp()：管理運算子 Stack。
  • priority(op)：回傳 +、-、*、/ 的優先順序。
  • applyOp(a,b,op)：依照運算子對兩個數字做加減乘除。
六、整體說明

本題重點是中序表示法雖然符合人類閱讀習慣，但程式必須額外處理優先順序與括號。Stack 是處理這類問題的重要資料結構。
