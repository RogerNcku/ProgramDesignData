三、首頁使用方式

建議投影教學或學生自學時使用
1、如何使用這個首頁？
先從「建議學習順序」進入主題 1–2，再依序進入 3–4、5–6、7–8、9–10，最後使用 11–12 做總複習。每一組教學頁都有下拉式章節、流程圖動畫、投影片圖片與可編輯程式碼。
2、如何使用動畫流程圖與動畫表格？
進入各主題頁後，可按「下一步」逐格顯示流程；也可按「自動播放」讓系統自動示範。Stack、Output、Expression Tree 等內容會用表格或節點逐步呈現，適合講解演算法的執行順序。
3、如何練習 C 程式範例？
每章的程式碼區可以直接編輯。若要實際執行，按頁面中的 OnlineGDB、Programiz 或 OneCompiler 按鈕，把程式碼複製到線上編輯器即可測試。
4、這份教材適合怎麼教？
  • 第一階段：先理解 Infix、Postfix、Prefix 的差異。
  • 第二階段：用流程圖理解轉換演算法。
  • 第三階段：用動畫表格觀察 Stack 的 push/pop。
  • 第四階段：用 Expression Tree 串接 preorder、inorder、postorder。
  • 第五階段：閱讀完整 C 程式，把觀念轉成實作。
