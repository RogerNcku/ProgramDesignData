題目原文

Define a tree. Please explain the meaning of root and subtree.

中文翻譯

請定義什麼是樹，並說明 root（根節點）與 subtree（子樹）的意思。

核心觀念

treerootsubtreerecursive definition

圖解說明

動態說明

解題步驟

  1. 先說 tree 是一種階層式資料結構。
  2. 整棵樹只有一個 root。
  3. root 底下每個分支本身也可以視為一棵 tree，稱為 subtree。
完整答案：Tree 是由一個或多個 node 組成的有限集合，其中有一個特殊節點稱為 root，其餘節點可以分成若干個互不相交的集合，每一個集合本身也是一棵 tree，稱為 root 的 subtree。
考試容易錯：不要把 root 說成「第一個輸入的節點」；root 是樹狀結構最上層的節點。

題目原文

Given the following tree, answer the questions below.

        A
      / | \
     B  C  D
    / \    |
   E   F   G
          / \
         H   I

a. What is the root?
b. What are the leaves?
c. What is the degree of node A?
d. What is the parent of node G?
e. What are the children of node D?
f. What is the depth of the tree?

中文翻譯

請根據圖中的一般樹，回答根節點、葉節點、節點 degree、parent、children 與 depth。

核心觀念

rootleafdegreeparentchildrendepth

圖解與動畫

解題步驟

  1. root 是最上方節點，所以是 A。
  2. leaf 是沒有 child 的節點：C、E、F、H、I。
  3. degree 是 children 數量，A 有 B、C、D 三個 child，所以 degree(A)=3。
  4. G 是 D 的 child，所以 parent(G)=D。
  5. D 的 children 是 G。
  6. 若 root 算第 1 層，最深為 A→D→G→H/I，共 4 層，因此 depth=4。
完整答案：a. A　b. C, E, F, H, I　c. 3　d. D　e. G　f. 4。
考試容易錯：leaf 是「沒有小孩」的節點，不是最下面畫得最靠下才算；C 雖然在第 2 層，但它沒有小孩，也是 leaf。

題目原文

Convert the following general tree into a left-child right-sibling representation.

        A
      / | \
     B  C  D
    / \    |
   E   F   G

Please draw the resulting binary-tree-like structure.

中文翻譯

請把一般樹轉成 left-child right-sibling 表示法，並畫出轉換後像二元樹的結構。

核心觀念

left-childright-siblingtree representation

動態圖解

解題步驟

  1. 每個節點的 left child 指向它的第一個小孩。
  2. 每個節點的 right sibling 指向它右邊最近的兄弟。
  3. A 的 left child 是 B；B 的 right sibling 是 C；C 的 right sibling 是 D。
  4. B 的 left child 是 E；E 的 right sibling 是 F；D 的 left child 是 G。
完整答案：A.left=B，B.right=C，C.right=D，B.left=E，E.right=F，D.left=G。圖中斜下是 left child，水平向右是 right sibling。
考試容易錯：不要把所有孩子都畫成 left child；只有第一個 child 是 left child，其餘孩子靠 right sibling 串起來。

題目原文

For a binary tree with height h, what is the maximum number of nodes? If h = 4, what is the maximum number of nodes?

中文翻譯

一棵高度為 h 的二元樹，最多有幾個節點？如果 h=4，最多有幾個節點？

核心觀念

binary treeheightmaximum nodes

圖解說明

解題步驟

  1. 高度 h 的滿二元樹最多節點。
  2. 第 1 層最多 1 個，第 2 層最多 2 個，第 3 層最多 4 個。
  3. 總和是 1+2+4+...+2^(h-1)=2^h-1。
  4. h=4，最多節點數=2^4-1=15。
完整答案：Maximum number of nodes = 2h − 1；h=4 時為 15。
考試容易錯：有些教材 root level 從 0 算，有些從 1 算；本題依投影片高度 h 對應最多 2^h−1。

題目原文

A complete binary tree is stored in an array starting from index 1. For the node at index i, write the array index of its parent, left child, and right child. Then answer the same questions for i = 5.

中文翻譯

完全二元樹從 index 1 開始存入陣列。請寫出 index i 的 parent、left child、right child 位置，並計算 i=5 的情況。

核心觀念

array representationparent indexleft childright child

圖解說明

解題步驟

  1. 從 1 開始存 complete binary tree。
  2. parent(i)=⌊i/2⌋。
  3. left child(i)=2i。
  4. right child(i)=2i+1。
  5. i=5 時：parent=2，left child=10，right child=11。
完整答案：Parent=⌊i/2⌋，Left child=2i，Right child=2i+1。當 i=5 時，parent=2，left child=10，right child=11。
考試容易錯：這組公式是 index 從 1 開始；如果 index 從 0 開始，公式會不同。

題目原文

Given the following binary tree, write its inorder, preorder, and postorder traversal.

        A
       / \
      B   C
     / \   \
    D   E   F

中文翻譯

請寫出這棵二元樹的 inorder、preorder、postorder 走訪結果。

核心觀念

inorder LVRpreorder VLRpostorder LRVrecursive traversal

走訪動畫

解題步驟

  1. Inorder：左 → 根 → 右，所以 D B E A C F。
  2. Preorder：根 → 左 → 右，所以 A B D E C F。
  3. Postorder：左 → 右 → 根，所以 D E B F C A。
完整答案：Inorder：D B E A C F；Preorder：A B D E C F；Postorder：D E B F C A。
考試容易錯：Traversal 是針對每一棵子樹遞迴套用規則，不是只看整棵樹第一層。

題目原文

Build a binary search tree based on the following array: 7, 14, 10, 8, 16, 3, 2, 4, 1. Please draw the final binary search tree.

中文翻譯

依照給定順序建立二元搜尋樹，並畫出最後的 BST。

核心觀念

BSTinsertionleft smallerright larger

BST 插入動畫

解題步驟

  1. 7 是第一個數字，成為 root。
  2. 14 > 7，放在 7 的右邊。
  3. 10 > 7 且 10 < 14，放在 14 的左邊。
  4. 8 > 7，<14，<10，放在 10 的左邊。
  5. 16 > 7，>14，放在 14 的右邊。
  6. 3 < 7，放左邊；2 <7 <3? 實際是 2<7 且 2<3，放在 3 左邊；4 放在 3 右邊；1 放在 2 左邊。
完整答案：Root=7；左子樹為 3，其左為 2、右為 4，2 的左為 1；右子樹為 14，其左為 10、右為 16，10 的左為 8。
考試容易錯：BST 必須依照「輸入順序」一個一個插入，不能先排序後畫平衡樹。

題目原文

Given the following binary search tree, trace the searching path for finding 9 and 15.
        7
       / \
      3   14
     / \  / \
    2  4 10 16
   /     /
  1     8
         \
          9

中文翻譯

請追蹤在 BST 中搜尋 9 和 15 的比較路徑。

核心觀念

BST searchcomparisonfound / not found

搜尋動畫

解題步驟

  1. 搜尋 9：9>7 往右；9<14 往左；9<10 往左；9>8 往右；找到 9。
  2. 搜尋 15：15>7 往右；15>14 往右；15<16 往左；左子樹為 null，所以找不到。
完整答案：Search 9 path：7 → 14 → 10 → 8 → 9，found。Search 15 path：7 → 14 → 16 → null，not found。
考試容易錯：每一步都要寫比較方向；只寫路徑通常不夠完整。

題目原文

Build a max heap based on the following array: 4, 1, 3, 2, 16, 9, 10, 14, 8, 7. Please show the final heap as a tree and as an array.

中文翻譯

根據陣列建立 max heap，並用樹狀圖與陣列表示最後結果。

核心觀念

max heapcomplete binary treeheapifyarray representation

Heap 建立動畫

解題步驟

  1. 先把陣列視為 complete binary tree。
  2. 從最後一個非葉節點開始往前做 heapify。
  3. 每個 parent 要大於等於左右 child。
  4. 若 child 比 parent 大，就交換並繼續往下檢查。
完整答案：使用 bottom-up heapify 後，max heap array = [16, 14, 10, 8, 7, 9, 3, 2, 4, 1]。
考試容易錯：Max heap 不是 BST，左邊不一定小於右邊；只要 parent 大於 children 即可。

題目原文

Use heap sort to sort the following numbers in ascending order: 4, 1, 3, 2, 16, 9, 10, 14, 8, 7. Please show the major steps of removing the root and rebuilding the heap.

中文翻譯

請使用 heap sort 將數字由小到大排序，並顯示移除 root 與重建 heap 的主要步驟。

核心觀念

heap sortremove rootswapheapifyO(n log n)

Heap Sort 動畫

解題步驟

  1. 先建立 max heap。
  2. 將 root 最大值與 heap 最後一個元素交換。
  3. 縮小 heap 範圍，固定右側已排序區。
  4. 對新的 root 做 heapify。
  5. 重複直到排序完成。
完整答案：排序結果為 [1, 2, 3, 4, 7, 8, 9, 10, 14, 16]。時間複雜度：O(n log n)。
考試容易錯：升冪 heap sort 通常先建立 max heap；每次取出的最大值會放到陣列右側。

題目原文

Write the output of the following tree traversal program.
Tree structure:
        A
       / \
      B   C
     / \   \
    D   E   F

The program calls:
inOrder(root);
postOrder(root);

中文翻譯

請根據這棵二元樹，寫出呼叫 inOrder(root) 與 postOrder(root) 的輸出結果，並補充 C 程式。

核心觀念

C structrecursive traversalinOrderpreOrderpostOrder

走訪動畫

完整 C 程式碼

#include <stdio.h>
#include <stdlib.h>

/* 定義二元樹節點 */
typedef struct Node {
    char data;              // 節點資料
    struct Node *left;      // 左子樹指標
    struct Node *right;     // 右子樹指標
} Node;

/* 建立新節點 */
Node* createNode(char data) {
    Node* node = (Node*)malloc(sizeof(Node));
    node->data = data;
    node->left = NULL;
    node->right = NULL;
    return node;
}

/* 中序走訪：Left → Root → Right */
void inOrder(Node* root) {
    if (root != NULL) {
        inOrder(root->left);           // 先走訪左子樹
        printf("%c ", root->data);     // 再輸出目前節點
        inOrder(root->right);          // 最後走訪右子樹
    }
}

/* 前序走訪：Root → Left → Right */
void preOrder(Node* root) {
    if (root != NULL) {
        printf("%c ", root->data);     // 先輸出目前節點
        preOrder(root->left);          // 再走訪左子樹
        preOrder(root->right);         // 最後走訪右子樹
    }
}

/* 後序走訪：Left → Right → Root */
void postOrder(Node* root) {
    if (root != NULL) {
        postOrder(root->left);         // 先走訪左子樹
        postOrder(root->right);        // 再走訪右子樹
        printf("%c ", root->data);     // 最後輸出目前節點
    }
}

int main(void) {
    Node* root = createNode('A');
    root->left = createNode('B');
    root->right = createNode('C');
    root->left->left = createNode('D');
    root->left->right = createNode('E');
    root->right->right = createNode('F');

    printf("Inorder traversal: ");
    inOrder(root);
    printf("\n");

    printf("Preorder traversal: ");
    preOrder(root);
    printf("\n");

    printf("Postorder traversal: ");
    postOrder(root);
    printf("\n");

    return 0;
}

程式流程圖

程式流程說明

  1. 若 root 為 NULL，代表空子樹，直接 return。
  2. inOrder 先遞迴左子樹，再輸出目前節點，再遞迴右子樹。
  3. preOrder 先輸出目前節點，再處理左、右子樹。
  4. postOrder 先處理左、右子樹，最後輸出目前節點。

函式與語法說明

struct Node
定義樹節點資料型態。
char data
存放節點字元資料。
left / right
分別指向左子節點與右子節點。
malloc
動態配置節點記憶體。
NULL
表示沒有子節點。
recursive call
函式呼叫自己，適合處理遞迴定義的 tree。
完整答案：Inorder traversal: D B E A C F。Postorder traversal: D E B F C A。補充 Preorder：A B D E C F。
考試容易錯：Postorder 是 left-right-root，不是 root-right-left；遞迴程式題要逐行追蹤呼叫順序。
