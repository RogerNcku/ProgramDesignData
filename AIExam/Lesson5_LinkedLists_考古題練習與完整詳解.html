1Array 的缺點與 Linked List 的需求

1、題目原文

Just for the factor of insertion and deletion, explain why a linked list is better than an array. Please provide your reason.

2、題目中文翻譯

只考慮「插入」與「刪除」這個因素，請解釋為什麼 linked list 比 array 更好，並說明理由。

3、題目核心觀念

這題在考 array 與 linked list 在資料移動成本上的差異。array 是連續記憶體，插入或刪除中間元素時，常需要搬移後方元素；linked list 則透過修改 link/pointer 完成，不需要搬動所有資料。

4、解題步驟

  1. 先說明 array 的資料是連續放在記憶體中。
  2. 如果要在中間插入資料，array 後面的元素要往後移。
  3. 如果要刪除中間資料，array 後面的元素要往前移。
  4. linked list 的節點不一定連續，只要改變前後節點的 pointer。
  5. 因此在頻繁插入、刪除的情況下，linked list 較方便。

5、圖解說明

6、動畫說明

7、完整答案

Linked list 在插入與刪除上通常比 array 更方便，因為 array 需要搬動元素來維持連續位置，而 linked list 只要修改節點的 pointer/link 即可完成插入或刪除。若資料經常插入或刪除，linked list 較適合。

8、考試容易錯的地方

不要寫成「linked list 一定比 array 快」。若是隨機存取第 i 個元素，array 是 O(1)，linked list 通常是 O(n)。本題限定 insertion and deletion，所以才強調 linked list 優勢。
2List 的基本概念

1、題目原文

Define the following terms in a linked list: node, head pointer, data field, link field, and null pointer.

2、題目中文翻譯

請定義 linked list 中的以下名詞：node、head pointer、data field、link field、null pointer。

3、題目核心觀念

這題考 linked list 最基本的組成。要能把「節點」、「資料欄位」、「鏈結欄位」、「串列開頭」、「串列結尾」說清楚。

4、解題步驟

  1. 先說明 linked list 是由多個 node 串接而成。
  2. 每個 node 通常包含 data field 與 link field。
  3. head pointer 指向第一個 node。
  4. 最後一個 node 的 link 指向 null，表示串列結束。

5、圖解說明

6、完整答案

名詞定義
nodelinked list 中的一個節點，通常包含資料與指標。
head pointer指向串列第一個節點的指標。
data field節點中存放資料的欄位。
link field節點中存放下一個節點位址的欄位，也常稱為 next。
null pointer表示沒有下一個節點，常用於串列結尾。

7、考試容易錯的地方

head 不是第一個節點本身，而是「指向第一個節點的指標」。null 也不是一個普通節點，而是表示沒有下一個節點。
3Singly Linked List 單向鏈結串列

1、題目原文

Draw a singly linked list based on the following data sequence:
A, D, U, X, Y
Please show the head pointer and the null pointer.

2、題目中文翻譯

請根據資料順序 A、D、U、X、Y 畫出一個單向鏈結串列，並標示 head pointer 與 null pointer。

3、題目核心觀念

這題考單向鏈結串列的基本畫法：每個節點只會指向下一個節點，最後一個節點指向 null。

4、解題步驟

  1. 依照資料順序建立節點 A、D、U、X、Y。
  2. 讓 head 指向第一個節點 A。
  3. 讓 A.next 指向 D，D.next 指向 U，依此類推。
  4. 讓 Y.next 指向 null。

5、圖解說明

6、動畫說明

7、完整答案

Head → A → D → U → X → Y → null

8、考試容易錯的地方

最後一個節點 Y 一定要畫出指向 null，不可以讓最後節點空白不標示。
4Singly Linked List 的插入與刪除

1、題目原文

Given a singly linked list:
A → D → U → X → Y → null
a. Insert T between D and U.
b. Delete X from the list.
Please draw the linked list after each operation.

2、題目中文翻譯

給定單向鏈結串列 A → D → U → X → Y → null。請先將 T 插入 D 與 U 之間，再從串列中刪除 X，並畫出每一步操作後的串列。

3、題目核心觀念

這題考 linked list 最重要的 pointer 修改。插入時要讓新節點先接到後方節點，再讓前方節點接到新節點。刪除時要讓前一個節點跳過被刪除節點。

4、解題步驟

  1. 原串列：A → D → U → X → Y → null。
  2. 插入 T：令 T.next = U，再令 D.next = T。
  3. 插入後：A → D → T → U → X → Y → null。
  4. 刪除 X：令 U.next = Y，X 不再被串列連到。
  5. 刪除後：A → D → T → U → Y → null。

5、圖解說明

6、動畫說明

7、完整答案

插入 T 後：A → D → T → U → X → Y → null
刪除 X 後：A → D → T → U → Y → null

8、考試容易錯的地方

插入時 pointer 順序不能反。若先寫 D.next = T，再沒有保存 U 的位置，就可能遺失後半段串列。刪除時也不能只把 X 擦掉，要畫出 U.next 改指向 Y。
5Singly Linked List 的 Java 實作

1、題目原文

Write a Java method to insert an integer x into a sorted singly linked list. The method has a parameter indicating the head of the linked list.

2、題目中文翻譯

請寫一個 Java 方法，將整數 x 插入已排序的單向鏈結串列中。方法需要有一個參數表示 linked list 的 head。

3、題目核心觀念

這題考 sorted linked list 的插入。要處理三種情況：空串列、插入最前面、插入中間或最後。

4、解題步驟

  1. 先建立新節點 node。
  2. 如果 head 是 null，或 x 比 head.data 小，代表要插在最前面。
  3. 否則用 current 從 head 開始往後找。
  4. 找到第一個 current.next.data 不小於 x 的位置。
  5. 把新節點接在 current 與 current.next 之間。
  6. 回傳 head。

5、圖解說明

6、完整 Java 程式碼

public class SortedLinkedListDemo {

    // Node 類別：代表 linked list 裡的一個節點
    static class Node {
        int data;       // 存放節點資料
        Node next;      // 指向下一個節點

        Node(int data) {
            this.data = data;
            this.next = null;
        }
    }

    // 將 x 插入「已排序」的單向鏈結串列，並回傳新的 head
    public static Node insert(Node head, int x) {
        Node node = new Node(x); // 建立新節點

        // 情況一：空串列，或 x 應該插在最前面
        if (head == null || x < head.data) {
            node.next = head; // 新節點指向原本的第一個節點
            return node;      // 新節點成為新的 head
        }

        // 情況二：尋找插入位置
        Node current = head;

        // 只要下一個節點存在，而且下一個節點的資料仍小於 x，就繼續往後走
        while (current.next != null && current.next.data < x) {
            current = current.next;
        }

        // 插入 node 到 current 與 current.next 中間
        node.next = current.next;
        current.next = node;

        return head; // head 沒有改變
    }

    // 印出 linked list
    public static void printList(Node head) {
        Node current = head;
        while (current != null) {
            System.out.print(current.data + " -> ");
            current = current.next;
        }
        System.out.println("null");
    }

    public static void main(String[] args) {
        Node head = null;

        head = insert(head, 5);
        head = insert(head, 2);
        head = insert(head, 8);
        head = insert(head, 4);

        printList(head); // 2 -> 4 -> 5 -> 8 -> null
    }
}

7、程式流程圖

8、程式流程說明與函式說明

insert(Node head, int x)：head 是原本串列開頭，x 是要插入的數字，回傳值是插入後的 head。若插在最前面，head 會改變；若插在中間或最後，head 不變。

時間複雜度：最壞情況要走完整個串列，所以是 O(n)。

9、執行結果

2 -> 4 -> 5 -> 8 -> null

10、考試容易錯的地方

忘記處理插入 head 前面的情況，是這題最常見錯誤。另外，指標順序要先設 node.next，再改 current.next。
6Polynomial 多項式表示法

1、題目原文

Represent the following polynomial by using a linked list:
A(x) = 9x^20 - x^10 + 12
Each node should contain coefficient, exponent, and link field.

2、題目中文翻譯

請使用 linked list 表示多項式 A(x) = 9x²⁰ - x¹⁰ + 12。每個節點必須包含係數 coefficient、指數 exponent 與 link 欄位。

3、題目核心觀念

這題考多項式的 linked list 表示法。每一個非零項是一個節點，節點中存放 coef 與 exp，再用 link 串起來。

4、解題步驟

  1. 找出所有非零項：9x²⁰、-x¹⁰、12。
  2. 把 -x¹⁰ 寫成 -1x¹⁰，因此 coefficient 是 -1。
  3. 常數 12 可視為 12x⁰，因此 exponent 是 0。
  4. 依指數由大到小串接節點。

5、圖解說明

6、完整答案

Head → [coef=9, exp=20] → [coef=-1, exp=10] → [coef=12, exp=0] → null

7、考試容易錯的地方

常數項 12 的 exponent 是 0，不是空白。-x¹⁰ 的 coefficient 是 -1，不是只寫 x。
7Polynomial Addition 多項式相加

1、題目原文

Given two polynomials represented by linked lists:
A(x) = 9x^20 - x^10 + 12
B(x) = 3x^10 - 7x^2 + 2x - 1
Add A(x) and B(x), and show the resulting linked list.

2、題目中文翻譯

給定兩個用 linked list 表示的多項式，請計算 A(x) + B(x)，並畫出結果 linked list。

3、題目核心觀念

這題考多項式相加。若兩個節點 exponent 相同，coefficient 相加；若 exponent 不同，就把較高次方的項目先放入結果。

4、解題步驟

  1. A 的項：9x²⁰、-1x¹⁰、12x⁰。
  2. B 的項：3x¹⁰、-7x²、2x¹、-1x⁰。
  3. 9x²⁰ 沒有同類項，保留。
  4. -1x¹⁰ + 3x¹⁰ = 2x¹⁰。
  5. -7x² 沒有同類項，保留。
  6. 2x¹ 沒有同類項，保留。
  7. 12x⁰ + (-1x⁰) = 11x⁰。

5、圖解說明

6、動畫說明

7、完整答案

A(x)+B(x)=9x²⁰+2x¹⁰-7x²+2x+11
結果 linked list：Head → [9,20] → [2,10] → [-7,2] → [2,1] → [11,0] → null

8、考試容易錯的地方

只有 exponent 相同的項目才能合併，不能把 coefficient 相同或相近的項目亂合併。常數項也是 exponent 0，必須和另一個常數項相加。
8Circularly Linked List 環狀鏈結串列

1、題目原文

What is the difference between a singly linked list and a circularly linked list? Draw an example with nodes A, D, U, X, Y.

2、題目中文翻譯

請說明單向鏈結串列與環狀鏈結串列的差異，並用 A、D、U、X、Y 畫出例子。

3、題目核心觀念

這題考最後一個節點的 link 指向哪裡。singly linked list 的最後節點指向 null；circularly linked list 的最後節點指回第一個節點或 head。

4、解題步驟

  1. 畫出一般單向串列，最後 Y.next = null。
  2. 畫出環狀串列，最後 Y.next 指回 A。
  3. 比較兩者的結束條件：一個遇到 null 停止，一個需要回到 head 才停止。

5、圖解說明

6、完整答案

Singly linked list：A → D → U → X → Y → null。Circularly linked list：A → D → U → X → Y，且 Y.next 指回 A。

7、考試容易錯的地方

環狀串列不能用 current != null 當唯一停止條件，否則可能無限迴圈。通常要檢查是否回到 head。
9Doubly Linked List 雙向鏈結串列

1、題目原文

Explain why deletion is more efficient in a doubly linked list than in a singly linked list. Please draw a doubly linked list with nodes A, C, E.

2、題目中文翻譯

請解釋為什麼在 doubly linked list 中刪除節點比 singly linked list 更有效率，並畫出包含 A、C、E 的雙向鏈結串列。

3、題目核心觀念

雙向鏈結串列每個節點有 left link 與 right link，所以可以往前也可以往後。刪除某個已知節點時，可以直接透過 node.llink 找到前一個節點，不必從 head 重新找。

4、解題步驟

  1. 畫出 null ← A ⇄ C ⇄ E → null。
  2. 說明 singly linked list 只有 next，要刪除 C 時常需要找到 C 的前一個節點 A。
  3. doubly linked list 的 C 有 llink 指向 A、rlink 指向 E。
  4. 刪除 C 時，只要 A.rlink = E，E.llink = A。

5、圖解說明

6、完整答案

Doubly linked list 的每個節點有前後兩個連結，因此刪除某個節點時，可以直接透過該節點的 llink 找到前一個節點，透過 rlink 找到下一個節點，再把兩者接起來。若刪除 C，則 A.rlink = E，E.llink = A。

7、考試容易錯的地方

不要只改右邊的 link。雙向鏈結串列刪除時通常要改兩個方向：前一個節點的 rlink，以及下一個節點的 llink。
10Linked List 的 C 語言實作

1、題目原文

Write a C function to delete an integer delData from a sorted singly linked list. The function has a parameter indicating the head of the linked list.

2、題目中文翻譯

請寫一個 C 函式，從已排序的單向鏈結串列中刪除整數 delData。函式需要有一個參數表示 linked list 的 head。

3、題目核心觀念

這題考 C 語言 linked list 刪除節點，包含 struct Node、指標、二級指標、prev/curr 搜尋、刪除 head、刪除中間節點與 free 記憶體。

4、解題步驟

  1. 先檢查串列是否為空。
  2. 用 curr 指向目前節點，prev 記錄前一個節點。
  3. 一路尋找 curr->data 是否等於 delData。
  4. 如果找不到，印出不在串列中。
  5. 如果刪除的是 head，更新 *head = curr->next。
  6. 如果刪除的是中間或最後節點，令 prev->next = curr->next。
  7. 最後 free(curr) 釋放記憶體。

5、圖解說明

6、完整 C 程式碼

#include <stdio.h>
#include <stdlib.h>

// Node 結構：代表 linked list 的一個節點
struct Node {
    int data;           // 節點資料
    struct Node *next;  // 指向下一個節點
};

// 建立新節點
struct Node* createNode(int data) {
    struct Node *node = (struct Node*)malloc(sizeof(struct Node));
    node->data = data;
    node->next = NULL;
    return node;
}

// 將資料插入串列最後，方便測試
void pushBack(struct Node **head, int data) {
    struct Node *node = createNode(data);

    if (*head == NULL) {
        *head = node;
        return;
    }

    struct Node *curr = *head;
    while (curr->next != NULL) {
        curr = curr->next;
    }
    curr->next = node;
}

// 從 linked list 中刪除 delData
void deleteNode(struct Node **head, int delData) {
    struct Node *curr = *head;  // curr 指向目前檢查的節點
    struct Node *prev = NULL;   // prev 指向 curr 的前一個節點

    // 情況一：空串列
    if (*head == NULL) {
        printf("Empty\\n");
        return;
    }

    // 尋找要刪除的節點
    while (curr != NULL && curr->data != delData) {
        prev = curr;
        curr = curr->next;
    }

    // 情況二：找不到 delData
    if (curr == NULL) {
        printf("%d is not in the list!\\n", delData);
        return;
    }

    // 情況三：要刪除的是第一個節點 head
    if (prev == NULL) {
        *head = curr->next;
    }
    // 情況四：刪除中間或最後節點
    else {
        prev->next = curr->next;
    }

    // 釋放被刪除節點的記憶體
    free(curr);
}

// 印出 linked list
void printList(struct Node *head) {
    struct Node *curr = head;
    while (curr != NULL) {
        printf("%d -> ", curr->data);
        curr = curr->next;
    }
    printf("NULL\\n");
}

int main(void) {
    struct Node *head = NULL;

    pushBack(&head, 1);
    pushBack(&head, 3);
    pushBack(&head, 5);
    pushBack(&head, 7);

    printList(head);

    deleteNode(&head, 5);
    printList(head);

    deleteNode(&head, 1);
    printList(head);

    deleteNode(&head, 9);

    return 0;
}

7、程式流程圖

8、程式流程說明與函式說明

deleteNode(struct Node **head, int delData)：使用二級指標是為了可以修改原本的 head。如果刪除的是第一個節點，必須讓外部的 head 也跟著改變。

主要變數：curr 是目前檢查的節點；prev 是 curr 的前一個節點；delData 是要刪除的資料。

時間複雜度：最壞情況需要走完整個串列，為 O(n)。

重要語法：malloc 配置記憶體，free 釋放記憶體，-> 用於透過指標存取 struct 成員。

9、執行結果

1 -> 3 -> 5 -> 7 -> NULL
1 -> 3 -> 7 -> NULL
3 -> 7 -> NULL
9 is not in the list!

10、考試容易錯的地方

最容易錯的是刪除 head 時沒有更新 head。另外，C 語言刪除節點後要 free(curr)，否則會造成 memory leak。
