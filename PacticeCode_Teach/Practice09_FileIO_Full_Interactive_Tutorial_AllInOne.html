一、學習總覽

本章 File I/O 的核心是：C 程式透過 FILE * 取得檔案操作通道，再用不同函式讀寫資料。Practice 09 主要訓練三件事：讀檔並處理字元、讀入整份檔案再覆寫、以及使用 rename() 改檔名。

讀檔fopen(...,"r")、fgetc、fscanf、fread
寫檔fopen(...,"w")、fprintf、fputs、fwrite
檔案控制fseek、ftell、fflush、rename

注意："w" 模式會清空原本檔案；"a" 模式會附加在檔案最後；fclose() 會關閉檔案並把緩衝區資料寫入磁碟。

二、完整投影片式教學

Slide 1

File I/O 是什麼？

File I/O 就是讓 C 程式能讀取與寫入硬碟上的檔案。最基本流程是：

fopen 開檔→讀取或寫入→fclose 關檔

例如用 fprintf(fp,"Hello") 寫入文字，用 fscanf(fp,"%s",str) 讀出文字。

Slide 2

FILE *fp 是什麼？

FILE *fp 是檔案指標，不是一般 int 指標。它代表目前開啟檔案的狀態，例如檔案位置、讀寫模式、緩衝區等。

FILE *fp;
fp = fopen("data.txt", "r");
if (fp == NULL) {
    printf("Cannot open file.
");
}

只要 fopen() 失敗，通常會回傳 NULL，所以一定要檢查。

Slide 3

開檔模式 Mode String

模式意思是否清空原檔
r讀取，檔案必須存在否
w寫入，檔案不存在會建立會
a附加，寫到檔案尾端否
rb / wb二進位讀取 / 寫入wb 會
Slide 4

文字檔常用函式

函式用途範例
fprintf格式化寫入檔案fprintf(fp,"num=%d",num);
fscanf格式化讀取fscanf(fp,"%d",&num);
fputs寫入字串fputs("Hello",fp);
fgets讀取一行或指定長度fgets(str,60,fp);
fgetc讀一個字元ch=fgetc(fp);
Slide 5

二進位檔：fwrite / fread

若要儲存 int、struct 等原始記憶體資料，可使用二進位模式。

int x = 7, y;
FILE *fp = fopen("num.bin", "wb");
fwrite(&x, sizeof(x), 1, fp);
fclose(fp);

fp = fopen("num.bin", "rb");
fread(&y, sizeof(y), 1, fp);
fclose(fp);
Slide 6

檔案位置：fseek 與 ftell

fseek() 可以移動目前讀寫位置，ftell() 可以告訴你目前位置。

基準意思範例
SEEK_SET從檔案開頭算fseek(fp, 0L, SEEK_SET)
SEEK_CUR從目前位置算fseek(fp, 1L, SEEK_CUR)
SEEK_END從檔案結尾算fseek(fp, -2L, SEEK_END)
Slide 7

fflush 與 fclose 的差異

fflush(fp) 是強制把緩衝區資料寫進檔案，但檔案仍然開著；fclose(fp) 除了會 flush，也會關閉檔案、釋放資源。

如果寫完資料後馬上用另一個 FILE 指標讀同一檔案，最好先 fflush() 或 fclose()。

Slide 8

Practice 09 的三題重點

  1. 第 1 題：用 fgetc() 逐字元讀檔，判斷每個單字開頭並大寫。
  2. 第 2 題：用 fseek()、ftell()、fread() 讀整個檔案，再用 fputs() 寫回三次。
  3. 第 3 題：用 rename() 將檔案改名。

Practice 09 - Question 1

1、將文字檔每個單字的第一個字母轉大寫

題目

Write a program that converts all the characters which are the first ones of all words in p9_1.txt to upper cases. A word is any sequence of non-white-space characters.

解題觀念

本題重點是「逐字元讀取」與「判斷單字開頭」。程式用 fgetc() 每次讀一個字元，遇到空白、換行、tab 時把 newWord 設為 1，表示下一個非空白字元就是新單字開頭。若 newWord 為 1，就用 toupper() 轉成大寫並輸出；其他字元則原樣輸出。

完整程式：practice9_1_annotated.c
/*
 * 檔名：practice9_1_annotated.c
 * 主題：檔案讀取與單字首字母大寫
 * 功能：從命令列指定檔案，逐字元讀取內容，將每個單字第一個字母轉成大寫後輸出到螢幕。
 */
#include <stdio.h>  /* 提供 FILE、fopen()、fgetc()、putchar()、fclose()、printf()。 */
#include <ctype.h>  /* 提供 isspace() 與 toupper()。 */

int main(int argc, char *argv[]) /* argc 是參數數量；argv 是參數字串陣列。 */
{
    FILE *fp;     /* 檔案指標，用來代表開啟的檔案。 */
    int ch;       /* 儲存 fgetc 讀到的字元；用 int 才能正確存 EOF。 */
    int newWord = 1; /* 旗標：1 表示下一個非空白字元是新單字開頭。 */

    if (argc != 2) /* 程式名稱算一個參數，所以需要剛好 2 個：程式名 + 檔名。 */
    {
        printf("Usage: %s filename\n", argv[0]); /* 顯示正確使用方式。 */
        return 1; /* 參數錯誤，非正常結束。 */
    }

    fp = fopen(argv[1], "r"); /* 以讀取模式開啟使用者指定的檔案。 */

    if (fp == NULL) /* 若檔案不存在或無法開啟，fopen 會回傳 NULL。 */
    {
        printf("Cannot open file.\n"); /* 顯示錯誤訊息。 */
        return 1; /* 非正常結束。 */
    }

    while ((ch = fgetc(fp)) != EOF) /* 每次讀取一個字元，直到檔案結尾 EOF。 */
    {
        if (isspace(ch)) /* 若目前字元是空白、換行、tab 等空白字元。 */
        {
            newWord = 1; /* 下一個非空白字元會是新單字開頭。 */
            putchar(ch); /* 原樣輸出空白字元，保留原本文字格式。 */
        }
        else
        {
            if (newWord) /* 若目前是單字第一個字元。 */
            {
                putchar(toupper(ch)); /* 轉成大寫後輸出。 */
                newWord = 0;          /* 之後同一個單字的其他字元不再轉大寫。 */
            }
            else
            {
                putchar(ch); /* 非單字開頭，原樣輸出。 */
            }
        }
    }

    fclose(fp); /* 關閉檔案，釋放系統資源。 */
    return 0;   /* 正常結束。 */
}
程式執行結果
假設 p9_1.txt 內容為： once upon the time, there’s a big gray wolf. 執行： ./practice9_1 p9_1.txt 螢幕輸出： Once Upon The Time, There’s A Big Gray Wolf.
程式說明：逐段流程
  1. 本題重點是「逐字元讀取」與「判斷單字開頭」
  2. 程式用 fgetc() 每次讀一個字元，遇到空白、換行、tab 時把 newWord 設為 1，表示下一個非空白字元就是新單字開頭
  3. 若 newWord 為 1，就用 toupper() 轉成大寫並輸出；其他字元則原樣輸出

./practice9_1 p9_1.txt

Practice 09 - Question 2

2、將檔案原內容複製三次並寫回同一檔案

題目

Write a program that copies the original contents for three times and writes back to the file. The file name is obtained from command line.

解題觀念

本題重點是「先完整讀入，再用 w 模式覆寫」。程式先用 fseek(fp,0L,SEEK_END) 移到檔尾，再用 ftell() 得到檔案大小，接著配置 buffer，把檔案內容讀進來。之後用 fopen(argv[1], "w") 重新開啟同一檔案，原內容會被清空，再用 fputs(buffer, fp) 寫入三次。

完整程式：practice9_2_annotated.c
/*
 * 檔名：practice9_2_annotated.c
 * 主題：檔案讀取、動態記憶體、覆寫檔案
 * 功能：讀入整個檔案內容，再把原內容重複寫入同一檔案 3 次。
 */
#include <stdio.h>   /* 提供 FILE、fopen()、fseek()、ftell()、fread()、fputs()、fclose()。 */
#include <stdlib.h>  /* 提供 malloc() 與 free()。 */

int main(int argc, char *argv[]) /* 使用命令列參數取得檔名。 */
{
    FILE *fp;      /* 檔案指標。 */
    long size;     /* 儲存檔案大小，單位通常是 byte。 */
    char *buffer;  /* 動態配置的字元陣列，用來存整個檔案內容。 */
    int i;         /* 迴圈索引。 */

    if (argc != 2) /* 需要一個檔名參數。 */
    {
        printf("Usage: %s filename\n", argv[0]); /* 顯示使用方式。 */
        return 1; /* 參數錯誤。 */
    }

    fp = fopen(argv[1], "r"); /* 以讀取模式開啟檔案。 */

    if (fp == NULL) /* 檢查檔案是否成功開啟。 */
    {
        printf("Cannot open file.\n"); /* 顯示錯誤。 */
        return 1; /* 非正常結束。 */
    }

    fseek(fp, 0L, SEEK_END); /* 將檔案位置移到檔案結尾。 */
    size = ftell(fp);        /* 取得目前位置，也就是檔案大小。 */
    fseek(fp, 0L, SEEK_SET); /* 將檔案位置移回檔案開頭，準備讀取。 */

    buffer = (char *)malloc(size + 1); /* 多配置 1 byte 給字串結尾 '\0'。 */

    if (buffer == NULL) /* 檢查 malloc 是否成功。 */
    {
        printf("Memory allocation failed.\n"); /* 顯示記憶體不足。 */
        fclose(fp); /* 已開啟的檔案要先關閉。 */
        return 1; /* 非正常結束。 */
    }

    fread(buffer, sizeof(char), size, fp); /* 一次讀入 size 個字元到 buffer。 */
    buffer[size] = '\0'; /* 補上字串結尾，讓 buffer 可被 fputs 當字串處理。 */

    fclose(fp); /* 讀完後先關閉檔案。 */

    fp = fopen(argv[1], "w"); /* 以寫入模式重新開啟；注意會清空原檔案內容。 */

    if (fp == NULL) /* 檢查是否能寫入。 */
    {
        printf("Cannot write file.\n"); /* 顯示錯誤。 */
        free(buffer); /* 發生錯誤也要釋放記憶體。 */
        return 1; /* 非正常結束。 */
    }

    for (i = 0; i < 3; i++) /* 重複 3 次。 */
    {
        fputs(buffer, fp); /* 將原本檔案內容寫入檔案。 */
    }

    fclose(fp);   /* 關閉寫入中的檔案，確保緩衝區內容被寫入磁碟。 */
    free(buffer); /* 釋放動態記憶體。 */

    return 0; /* 正常結束。 */
}
程式執行結果
假設 copy.txt 原本內容為： Ha! I am a genius. 執行： ./practice9_2 copy.txt 執行後 copy.txt 內容變成： Ha! I am a genius. Ha! I am a genius. Ha! I am a genius.
程式說明：逐段流程
  1. 本題重點是「先完整讀入，再用 w 模式覆寫」
  2. 程式先用 fseek(fp,0L,SEEK_END) 移到檔尾，再用 ftell() 得到檔案大小，接著配置 buffer，把檔案內容讀進來
  3. 之後用 fopen(argv[1], "w") 重新開啟同一檔案，原內容會被清空，再用 fputs(buffer, fp) 寫入三次

Practice 09 - Question 3

3、將檔案重新命名

題目

Write a program that renames a file in the same directory. The old file name and new file name are obtained from command line.

解題觀念

本題重點是命令列參數與 rename()。argc 必須等於 3，argv[1] 是舊檔名，argv[2] 是新檔名。rename(argv[1], argv[2]) 成功會回傳 0；如果舊檔不存在、沒有權限、或目標檔名不合法，就會失敗。

完整程式：practice9_3_annotated.c
/*
 * 檔名：practice9_3_annotated.c
 * 主題：檔案重新命名 rename()
 * 功能：從命令列輸入舊檔名與新檔名，將檔案改名。
 */
#include <stdio.h> /* 提供 printf() 與 rename()。 */

int main(int argc, char *argv[]) /* argc/argv 用來讀取命令列參數。 */
{
    if (argc != 3) /* 需要三個參數：程式名、舊檔名、新檔名。 */
    {
        printf("Usage: %s old_filename new_filename\n", argv[0]); /* 顯示正確用法。 */
        return 1; /* 參數不足或過多，非正常結束。 */
    }

    if (rename(argv[1], argv[2]) != 0) /* rename 成功回傳 0；失敗回傳非 0。 */
    {
        printf("Rename failed.\n"); /* 改名失敗，例如舊檔不存在或權限不足。 */
        return 1; /* 非正常結束。 */
    }

    printf("Rename success.\n"); /* 改名成功。 */

    return 0; /* 正常結束。 */
}
程式執行結果
假設目前資料夾有 test.txt。 執行： ./practice9_3 test.txt test2.txt 螢幕輸出： Rename success. 執行後： test.txt 會改名為 test2.txt
程式說明：逐段流程
  1. 本題重點是命令列參數與 rename()
  2. argc 必須等於 3，argv[1] 是舊檔名，argv[2] 是新檔名
  3. rename(argv[1], argv[2]) 成功會回傳 0；如果舊檔不存在、沒有權限、或目標檔名不合法，就會失敗

./practice9_3 test.txt test2.txt
