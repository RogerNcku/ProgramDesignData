一、完整投影片教學

本章從指標存取記憶體開始，接著介紹動態記憶體配置。講義指出 fixed-size data structures 的問題是大小在寫程式時就固定，動態配置可在執行期間配置儲存空間；常見函式包含 malloc、calloc、realloc。

1. 動態記憶體配置是什麼？

固定大小陣列必須在寫程式時決定容量；動態配置讓程式在執行期間依需求向系統要記憶體。常見函式有 malloc、calloc、realloc。

2. malloc：只配置，不初始化

malloc(size) 會配置 size bytes，但內容是未初始化的垃圾值。使用前要自行賦值，並檢查是否回傳 NULL。

3. calloc：配置並清為 0

calloc(n, sizeof(type)) 會配置 n 個元素，並把每個 bit 設為 0，適合需要初始為 0 的陣列。

4. realloc：調整已配置空間大小

realloc(ptr, new_size) 可放大或縮小已配置記憶體。成功後舊指標可能失效，應使用新指標接收。

5. free：釋放不用的記憶體

malloc/calloc/realloc 得到的記憶體用完後要 free(ptr)，避免 memory leak。free 後不要再使用該指標。

6. NULL pointer 與錯誤處理

配置失敗會回傳 NULL。安全寫法是 if (p == NULL) 處理錯誤，避免後續 *p 或 p[i] 造成 crash。

7. Practice 10 三題核心

第 1 題包裝 malloc，第 2 題建立初始化動態陣列，第 3 題用 const 指標計算 double 陣列內積。

二、核心觀念整理

函式 / 觀念用途重要提醒
malloc(size)配置 size bytes 的記憶體。內容未初始化，可能是垃圾值；要檢查 NULL。
calloc(n, sizeof(type))配置 n 個元素並初始化為 0。適合一開始需要 0 的陣列。
realloc(ptr, new_size)調整已配置空間大小。成功後位址可能改變，應使用新指標接收。
free(ptr)釋放動態配置的記憶體。free 後不要再 dereference；可把指標設成 NULL。
NULL代表指標沒有指向有效物件。配置失敗常回傳 NULL，應避免使用 *NULL。
最重要規則：只要使用 malloc、calloc、realloc 取得記憶體，就要思考「什麼時候 free？」。

Practice 10-1

第 1 題：my_malloc 安全包裝函式

題目

Having to check the return value of malloc each time we call it is an annoyance. Write a wrapper function my_malloc for malloc. When we call my_malloc and ask it to allocate n bytes, it calls malloc, makes sure that malloc does not return a null pointer, and then returns the pointer from malloc. Have my_malloc print an error message and terminate the program if malloc returns a null pointer.

解題觀念與程式說明

本題重點是把 malloc 的錯誤檢查集中到 my_malloc()。主程式只要呼叫 my_malloc(n)，就能保證成功時得到有效位址；若失敗，my_malloc 會印出錯誤並 exit(1)，避免每次配置都重複寫 NULL 檢查。程式中配置 5 個 int，填入 1 到 5，最後用 free(arr) 釋放。

本題使用到的觀念
  • malloc()
  • NULL 檢查
  • free()
編譯執行指令
gcc practice10_1.c -o practice10_1
./practice10_1
完整程式碼
/*
 * 檔名：practice10_1.c
 * 主題：自訂安全版 malloc 函式，並建立整數動態陣列
 * 說明：此程式示範如何使用 malloc() 配置記憶體、檢查配置是否成功、使用完後以 free() 釋放。
 */

#include <stdio.h>   /* 引入標準輸入輸出函式庫，提供 printf() 等函式 */
#include <stdlib.h>  /* 引入標準函式庫，提供 malloc()、free()、exit()、size_t 等功能 */

/*
 * 函式名稱：my_malloc
 * 函式功能：包裝 malloc()，讓配置記憶體時可以自動檢查是否失敗。
 * 參數 n：想要配置的記憶體大小，單位是 byte。
 * 回傳值：成功時回傳配置到的記憶體位址；失敗時印出錯誤訊息並結束程式。
 */
void *my_malloc(size_t n)
{
    void *p;  /* 宣告 void 指標 p，用來接收 malloc() 回傳的記憶體位址 */

    p = malloc(n);  /* 向系統要求 n bytes 的動態記憶體空間 */

    if (p == NULL)  /* 如果 malloc() 回傳 NULL，代表記憶體配置失敗 */
    {
        printf("Error: malloc failed.\n");  /* 印出記憶體配置失敗的錯誤訊息 */
        exit(1);  /* 以狀態碼 1 強制結束程式，表示程式非正常結束 */
    }

    return p;  /* 回傳成功配置到的記憶體起始位址 */
}

int main(void)
{
    int *arr;  /* 宣告整數指標 arr，之後會指向動態配置的整數陣列 */
    int i;     /* 宣告迴圈變數 i，用來控制 for 迴圈 */

    arr = (int *)my_malloc(5 * sizeof(int));  /* 配置可存放 5 個 int 的記憶體空間，並轉型成 int 指標 */

    for (i = 0; i < 5; i++)  /* 從索引 0 到 4，依序處理陣列中的 5 個元素 */
    {
        arr[i] = i + 1;  /* 將陣列元素設定為 1、2、3、4、5 */
    }

    for (i = 0; i < 5; i++)  /* 再次走訪陣列中的每一個元素 */
    {
        printf("arr[%d] = %d\n", i, arr[i]);  /* 印出目前索引與對應的陣列值 */
    }

    free(arr);  /* 釋放先前使用 my_malloc() / malloc() 配置的動態記憶體，避免記憶體洩漏 */

    return 0;  /* 回傳 0，表示程式正常結束 */
}
程式執行結果
arr[0] = 1 arr[1] = 2 arr[2] = 3 arr[3] = 4 arr[4] = 5
執行結果說明

本題重點是把 malloc 的錯誤檢查集中到 my_malloc()。主程式只要呼叫 my_malloc(n)，就能保證成功時得到有效位址；若失敗，my_malloc 會印出錯誤並 exit(1)，避免每次配置都重複寫 NULL 檢查。程式中配置 5 個 int，填入 1 到 5，最後用 free(arr) 釋放。

Practice 10-2

第 2 題：create_array 建立並初始化動態陣列

題目

Write the following function: int *create_array( int n, int initial_value); The function should return a pointer to a dynamically allocated int array with n elements, each of which is initialized to initial_value. The return value should be NULL if the array cannot be allocated.

解題觀念與程式說明

本題重點是函式要回傳動態陣列的起始位址。create_array(n, initial_value) 先用 malloc(n * sizeof(int)) 配置 n 個 int 的空間，再用 for 迴圈把每格設成 initial_value。若 malloc 失敗，就回傳 NULL 讓 main 判斷。範例輸入 n=4、initial_value=7，所以印出四個 7。

本題使用到的觀念
  • malloc()
  • 動態陣列初始化
  • NULL 回傳

./practice10_2

4
7
完整程式碼
/*
 * 檔名：practice10_2.c
 * 主題：使用函式建立動態整數陣列，並設定初始值
 * 說明：使用者輸入陣列大小與初始值，程式會配置動態陣列並把每個元素設成相同初始值。
 */

#include <stdio.h>   /* 引入標準輸入輸出函式庫，提供 printf()、scanf() */
#include <stdlib.h>  /* 引入標準函式庫，提供 malloc()、free() */

/*
 * 函式名稱：create_array
 * 函式功能：建立一個長度為 n 的整數動態陣列，並將每個元素初始化為 initial_value。
 * 參數 n：陣列元素個數。
 * 參數 initial_value：每個陣列元素要設定的初始值。
 * 回傳值：成功時回傳陣列起始位址；失敗時回傳 NULL。
 */
int *create_array(int n, int initial_value)
{
    int *arr;  /* 宣告整數指標 arr，用來指向動態配置出的整數陣列 */
    int i;     /* 宣告迴圈變數 i */

    arr = (int *)malloc(n * sizeof(int));  /* 配置可存放 n 個 int 的記憶體空間 */

    if (arr == NULL)  /* 檢查 malloc() 是否配置失敗 */
    {
        return NULL;  /* 若配置失敗，回傳 NULL 給呼叫端判斷 */
    }

    for (i = 0; i < n; i++)  /* 逐一走訪陣列的每一個元素 */
    {
        arr[i] = initial_value;  /* 將目前元素設定為使用者指定的初始值 */
    }

    return arr;  /* 回傳配置完成並初始化好的陣列位址 */
}

int main(void)
{
    int *arr;   /* 宣告整數指標 arr，用來接收 create_array() 建立的動態陣列 */
    int n;      /* 宣告 n，用來儲存使用者輸入的陣列大小 */
    int value;  /* 宣告 value，用來儲存使用者輸入的初始值 */
    int i;      /* 宣告迴圈變數 i */

    printf("Enter array size: ");  /* 提示使用者輸入陣列大小 */
    scanf("%d", &n);  /* 讀取使用者輸入的整數，存入 n */

    printf("Enter initial value: ");  /* 提示使用者輸入每個元素的初始值 */
    scanf("%d", &value);  /* 讀取使用者輸入的整數，存入 value */

    arr = create_array(n, value);  /* 呼叫函式建立動態陣列，並把所有元素初始化為 value */

    if (arr == NULL)  /* 判斷 create_array() 是否配置失敗 */
    {
        printf("Array allocation failed.\n");  /* 印出配置失敗訊息 */
        return 1;  /* 回傳 1，表示程式發生錯誤後結束 */
    }

    for (i = 0; i < n; i++)  /* 逐一印出陣列中的每一個元素 */
    {
        printf("arr[%d] = %d\n", i, arr[i]);  /* 顯示索引 i 與 arr[i] 的值 */
    }

    free(arr);  /* 釋放動態配置的陣列記憶體 */

    return 0;  /* 程式正常結束 */
}
程式執行結果
Enter array size: 4 Enter initial value: 7 arr[0] = 7 arr[1] = 7 arr[2] = 7 arr[3] = 7
執行結果說明

本題重點是函式要回傳動態陣列的起始位址。create_array(n, initial_value) 先用 malloc(n * sizeof(int)) 配置 n 個 int 的空間，再用 for 迴圈把每格設成 initial_value。若 malloc 失敗，就回傳 NULL 讓 main 判斷。範例輸入 n=4、initial_value=7，所以印出四個 7。

Practice 10-3

第 3 題：inner_product 計算兩個 double 陣列內積

題目

Write the following function: double inner_product(const double *a, const double *b, int n); a and b both point to array of length n respectively. The function should return the value of a[0]*b[0] + a[1]*b[1] + … +a[n-1]*b[n-1].

解題觀念與程式說明

本題重點是 const double *a 與 const double *b 代表函式只讀取陣列，不修改陣列內容。內積公式是逐項相乘再累加：1.0*4.0 + 2.0*5.0 + 3.0*6.0 = 4 + 10 + 18 = 32，所以輸出 32.00。

本題使用到的觀念
  • const pointer
  • 陣列走訪
  • 累加計算

gcc practice10_3.c -o practice10_3
./practice10_3
完整程式碼
/*
 * 檔名：practice10_3.c
 * 主題：計算兩個 double 陣列的 inner product（內積）
 * 說明：內積公式為 a[0]*b[0] + a[1]*b[1] + ... + a[n-1]*b[n-1]。
 */

#include <stdio.h>  /* 引入標準輸入輸出函式庫，提供 printf() */

/*
 * 函式名稱：inner_product
 * 函式功能：計算兩個 double 陣列前 n 個元素的內積。
 * 參數 a：第一個 double 陣列的起始位址，使用 const 表示函式不會修改陣列內容。
 * 參數 b：第二個 double 陣列的起始位址，使用 const 表示函式不會修改陣列內容。
 * 參數 n：要參與內積計算的元素個數。
 * 回傳值：兩個陣列的內積結果。
 */
double inner_product(const double *a, const double *b, int n)
{
    int i;              /* 宣告迴圈變數 i */
    double sum = 0.0;   /* 宣告 sum 並初始化為 0.0，用來累加內積結果 */

    for (i = 0; i < n; i++)  /* 從第 0 個元素計算到第 n-1 個元素 */
    {
        sum += a[i] * b[i];  /* 將 a[i] 與 b[i] 相乘後加入 sum */
    }

    return sum;  /* 回傳最後累加完成的內積值 */
}

int main(void)
{
    double a[] = {1.0, 2.0, 3.0};  /* 宣告並初始化第一個 double 陣列 */
    double b[] = {4.0, 5.0, 6.0};  /* 宣告並初始化第二個 double 陣列 */
    double result;                 /* 宣告 result，用來儲存內積計算結果 */

    result = inner_product(a, b, 3);  /* 呼叫 inner_product()，計算兩個長度為 3 的陣列內積 */

    printf("Inner product = %.2f\n", result);  /* 以小數點後兩位格式印出內積結果 */

    return 0;  /* 程式正常結束 */
}
程式執行結果
Inner product = 32.00
執行結果說明

本題重點是 const double *a 與 const double *b 代表函式只讀取陣列，不修改陣列內容。內積公式是逐項相乘再累加：1.0*4.0 + 2.0*5.0 + 3.0*6.0 = 4 + 10 + 18 = 32，所以輸出 32.00。
