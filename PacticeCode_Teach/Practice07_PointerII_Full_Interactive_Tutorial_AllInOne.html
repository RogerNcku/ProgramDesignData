一、學習目標

本教學對應 Pointer II 與 Practice 07。你會從最基本的「指標存位址」開始，逐步理解為什麼函式需要指標才能修改原變數，以及陣列名稱、指標運算、二維陣列在 C 語言中的實際意義。

  • 會判斷 p、&p、*p 的差異。
  • 會用 swap(&i,&j) 交換原變數。
  • 會寫回傳指標的函式。
  • 會用指標走訪一維與二維陣列。
  • 會解釋 p+2、q-p、*p<*q。

一句話記憶

指標不是魔法，它只是「存位址的變數」。只要你知道它存的是誰的位址，就能知道 *p 改的是誰。

Slide 3｜Pointer Review

指標變數儲存的是記憶體位址。若 int i=5; int *p=&i;，則 p 的內容是 i 的位址，*p 代表該位址中的值，也就是 5。

04

Slide 4｜swap 失敗版本

swap(int x, int y) 只收到 main 變數的副本。函式內 x、y 的位址與 main 裡 x、y 的位址不同，所以函式內交換後 main 裡的值不會改變。

05

Slide 5｜swap 成功版本

swap(int *px, int *py) 收到 main 裡 x、y 的位址，透過 *px 與 *py 修改原記憶體位置，因此 main 的變數真的被交換。

06

Slide 6｜scanf 與指標

scanf 需要知道輸入值要存到哪個記憶體位置，所以 scanf("%d", &number)。若 p=&number，則 scanf("%d", p) 也等價。

07

Slide 7｜Pointers as Return Values

函式可以回傳指標，例如 max(&num1,&num2) 回傳較大值所在的位址。主程式可用 p 接住位址，再用 *p 取得值。

08

Slide 8｜Array element pointer

陣列元素也有位址。int *p=&a[0]; 代表 p 指向陣列第一格。

09

Slide 9｜Array name as pointer

在多數運算式中，陣列名稱 a 會轉換成 &a[0]，所以 int *p=a; 常用來讓 p 指向陣列開頭。

10

Slide 10｜Pointer addition

若 p 指向 a[i]，則 p+j 指向 a[i+j]。注意不是加 j 個 byte，而是加 j 個元素大小。

11

Slide 11｜Pointer subtraction

同一陣列中的兩個指標相減，得到的是元素距離。例如 q 指向 a[4]、p 指向 a[0]，q-p 得 4。

12

Slide 12｜Multidimensional Arrays

二維陣列在記憶體中仍是連續存放，C 採 row-major order：先放完 row 0，再放 row 1。

13

Slide 13｜Nested loops for 2D array

最直覺的二維陣列走訪方式是雙層 for：外層 row，內層 column。

14

Slide 14｜Pointer scan 2D array

因為二維陣列在記憶體中連續，可用 int *p 從 &a[0][0] 一路走到最後一格，但要小心範圍。

15

Slide 15｜Array and Pointer Sizes

sizeof(a) 是整個陣列大小；sizeof(p) 是指標變數大小。這證明陣列名稱與指標變數不完全相同。

16

Slide 16｜Array name cannot be changed

p++ 合法，因為 p 是指標變數；a++ 不合法，因為 a 代表陣列起始位址，不是可被改變的變數。

17

Slide 17｜String traversal by pointer

字元陣列也可用 char *p 走訪，while(*p != 0) 印出字元後 p++。

Slide 18｜Next：String

下一章會進入 String，字串其實就是以 null character 結尾的 char 陣列，會大量用到指標觀念。

三、核心觀念總整理

1. 傳值 vs 傳位址

傳值只會複製資料；傳位址會讓函式知道原變數在哪裡，因此可以修改原變數。

2. 指標回傳值

函式可以回傳某個變數或陣列元素的位址，但不能回傳區域變數的位址。

3. 陣列名稱

多數情況下 a 會轉成 &a[0]，但 a 不是可以被 ++ 的指標變數。

4. 指標加法

p+1 不是加 1 byte，而是移動到下一個元素，實際位址增加 sizeof(*p)。

5. 指標相減

同一陣列內指標相減，得到兩者間相隔幾個元素。

6. 二維陣列

C 的二維陣列是 row-major，宣告 int (*p)[column] 可讓 p 指向一整列。

第 1 題｜swap(int *p, int *q)

題目

Write the following function: void swap(int *p, int *q); When passed the addresses of two variables, swap should exchange the values of the variables: swap(&i, &j);

對應投影片觀念

本題對應投影片 Slide 4、Slide 5。核心是「傳值」與「傳位址」的差異：若只傳入 i、j 的值，函式內交換的是副本；若傳入 &i、&j，函式透過 *p、*q 可以直接改 main 裡的 i、j。

解題重點與觀念說明

temp = *p 先保存第一個變數的值；*p = *q 將第二個變數寫到第一個變數位置；*q = temp 將原第一個值寫到第二個變數位置。整個過程修改的是原變數，不是副本。

  • p 與 q 是 int 指標，內容分別是兩個整數變數的位址。
  • *p 代表 p 指到的那個整數變數。
  • swap(&i,&j) 才能真正改變 main 裡的 i 和 j。
完整程式與中文註解
/*
 * 檔名：practice07_1_annotated.c
 * 主題：使用指標進行 swap 交換
 * 功能：透過傳入兩個變數的位址，讓函式可以直接修改 main 裡的 i 與 j。
 */
#include <stdio.h>  /* 匯入標準輸入輸出函式庫，提供 printf()。 */

void swap(int *p, int *q)  /* swap 接收兩個 int 指標，也就是兩個整數變數的位址。 */
{
    int temp;  /* 暫存變數，用來保存其中一個值，避免交換過程資料遺失。 */

    temp = *p; /* 先把 p 指向的值，也就是第一個變數的值，存到 temp。 */
    *p = *q;   /* 把 q 指向的值放到 p 指向的位置。 */
    *q = temp; /* 把原本 p 指向的舊值放到 q 指向的位置，完成交換。 */
}

int main(void)  /* 主程式進入點。 */
{
    int i = 10; /* 宣告整數 i 並初始化為 10。 */
    int j = 5;  /* 宣告整數 j 並初始化為 5。 */

    printf("Before swap: i = %d, j = %d\n", i, j); /* 顯示交換前的 i、j。 */

    swap(&i, &j); /* 傳入 i 與 j 的位址，讓 swap 可以修改原本的變數。 */

    printf("After swap: i = %d, j = %d\n", i, j);  /* 顯示交換後的 i、j。 */

    return 0; /* 正常結束程式。 */
}
程式執行後結果
Before swap: i = 10, j = 5
After swap: i = 5, j = 10

實際記憶體位址每台電腦可能不同；本題輸出結果以上方數值與文字為主。

第 2 題｜int *find_largest(int a[], int n)

題目

When passed an array a of length n, the function will return a pointer to the largest element of the array.

對應投影片觀念

本題對應 Slide 7、Slide 8、Slide 9。函式不是回傳最大值，而是回傳「最大值所在的位置」。因此回傳型態是 int *。

解題重點與觀念說明

largest 一開始指向 a[0]。每次看到更大的 a[i]，就讓 largest 改指向 &a[i]。最後 return largest，main 可用 *p 印出最大值，也可以用 p-a 算出最大元素索引。

  • 回傳 int * 表示回傳整數元素的位址。
  • largest = &a[i] 是改變指標指向的位置。
  • *largest 是目前指標指到位置裡的值。
完整程式與中文註解
/*
 * 檔名：practice07_2_annotated.c
 * 主題：函式回傳指標
 * 功能：find_largest 回傳「最大元素的位址」，main 再透過 *p 印出最大值。
 */
#include <stdio.h>  /* 提供 printf()。 */

int *find_largest(int a[], int n) /* 回傳 int 指標，指向陣列中最大元素。 */
{
    int i;                 /* 迴圈索引。 */
    int *largest = &a[0];  /* 先假設第一個元素最大，largest 儲存其位址。 */

    for (i = 1; i < n; i++) /* 從第二個元素開始比較。 */
    {
        if (a[i] > *largest) /* *largest 是目前最大值；若 a[i] 更大就更新位址。 */
        {
            largest = &a[i]; /* largest 改成指向新的最大元素。 */
        }
    }

    return largest; /* 回傳最大元素的位址。 */
}

int main(void) /* 主程式。 */
{
    int a[] = {10, 80, 30, 50, 20}; /* 測試陣列。 */
    int n = sizeof(a) / sizeof(a[0]); /* 計算陣列長度。 */
    int *p; /* 用來接收最大元素位址的指標。 */

    p = find_largest(a, n); /* 呼叫函式，取得最大元素的位址。 */

    printf("Largest value = %d\n", *p); /* *p 取出該位址上的值，也就是最大值。 */

    return 0; /* 正常結束。 */
}
程式執行後結果
Largest value = 80

第 3 題｜用 p 印出二維陣列所有元素

題目

Given int a[row][column] and int (*p)[column]; p = a; add statements that use p to print all elements in a.

對應投影片觀念

本題對應 Slide 12、Slide 13、Slide 14。二維陣列可以用 row-major 觀念理解，int (*p)[column] 代表 p 指向「一列有 column 個 int 的陣列」。

解題重點與觀念說明

p+i 會移到第 i 列；*(p+i) 取得第 i 列的開頭；*(p+i)+j 移到第 j 欄；*(*(p+i)+j) 取得第 i 列第 j 欄的值。也可以寫 p[i][j]。

  • int (*p)[column] 的括號不能省略。
  • p 指向的是一整列，不是單一 int。
  • *(*(p+i)+j) 與 p[i][j] 取到同一個元素。
完整程式與中文註解
/*
 * 檔名：practice07_3_annotated.c
 * 主題：二維陣列與指向一列陣列的指標
 * 功能：使用 int (*p)[column] 走訪 3x5 二維陣列。
 */
#include <stdio.h>  /* 提供 printf()。 */

#define row 3       /* 定義二維陣列列數為 3。 */
#define column 5    /* 定義二維陣列欄數為 5。 */

int main(void) /* 主程式。 */
{
    int a[row][column] = /* 宣告 3x5 二維整數陣列。 */
    {
        {1, 2, 3, 4, 5},       /* 第 1 列資料。 */
        {1, 4, 9, 16, 25},     /* 第 2 列資料。 */
        {1, 8, 27, 64, 125}    /* 第 3 列資料。 */
    };

    int (*p)[column]; /* p 是指標，指向「含有 column 個 int 的一整列」。 */
    int i, j;         /* i 控制列，j 控制欄。 */

    p = a; /* 二維陣列名稱 a 會轉成第一列的位址，因此 p 指向第 0 列。 */

    for (i = 0; i < row; i++) /* 逐列走訪。 */
    {
        for (j = 0; j < column; j++) /* 逐欄走訪。 */
        {
            printf("%d ", *(*(p + i) + j)); /* p+i 到第 i 列；*(p+i)+j 到第 j 欄；最外層 * 取值。 */
        }
        printf("\n"); /* 每印完一列就換行。 */
    }

    return 0; /* 正常結束。 */
}
程式執行後結果
1 2 3 4 5 
1 4 9 16 25 
1 8 27 64 125

第 4 題｜指標運算與比較

題目

Suppose int a[5]={5,4,3,2,1}; int *p=a,*q=&a[4]; Find *(p+2), *(q-3), q-p, p<q, *p<*q.

對應投影片觀念

本題對應 Slide 10、Slide 11。指標加減是以「元素」為單位，不是以 byte 為單位。

解題重點與觀念說明

p 指向 a[0]，q 指向 a[4]。所以 p+2 指到 a[2]，值是 3；q-3 指到 a[1]，值是 4；q-p 是 4 個元素距離；p<q 比位址為 true；*p<*q 比內容 5<1 為 false。

  • 指標相減結果是元素距離。
  • p<q 比的是記憶體位置前後。
  • *p<*q 比的是兩個元素內容。
完整程式與中文註解
/*
 * 檔名：practice07_4_annotated.c
 * 主題：指標算術與指標比較
 * 功能：示範 p+2、q-3、q-p、p<q，以及指標所指向值的比較。
 */
#include <stdio.h> /* 提供 printf()。 */

int main(void) /* 主程式。 */
{
    int a[5] = {5, 4, 3, 2, 1}; /* 宣告長度為 5 的陣列。 */
    int *p = a;                 /* p 指向陣列第一個元素 a[0]。 */
    int *q = &a[4];             /* q 指向陣列最後一個元素 a[4]。 */

    printf("*(p + 2) = %d\n", *(p + 2)); /* p+2 指向 a[2]，值為 3。 */
    printf("*(q - 3) = %d\n", *(q - 3)); /* q-3 從 a[4] 往前 3 格到 a[1]，值為 4。 */
    printf("q - p = %ld\n", q - p);     /* 兩指標相減得到元素距離，不是位元組距離，結果為 4。 */
    printf("p < q is %s\n", (p < q) ? "true" : "false");   /* 比較位址順序，p 在 q 前面所以 true。 */
    printf("*p < *q is %s\n", (*p < *q) ? "true" : "false"); /* 比較值：a[0]=5，a[4]=1，所以 false。 */

    return 0; /* 正常結束。 */
}
程式執行後結果
*(p + 2) = 3
*(q - 3) = 4
q - p = 4
p < q is true
*p < *q is false

第 5 題｜絕對值與平方陣列

題目

Write int* func(int a[], int size); Modify each value in a to its absolute value, and return an array where each corresponding element is squared.

對應投影片觀念

本題整合 Slide 8、Slide 9 與動態記憶體。函式會直接修改原陣列 a，並另外 malloc 一個新陣列 r 回傳平方值。

解題重點與觀念說明

陣列傳入函式時會退化成指標，所以修改 a[i] 會改到原陣列。平方結果需要回傳一個陣列，因此使用 malloc 配置新記憶體，main 使用完後必須 free(r)。

  • a[i] = -a[i] 會直接修改原陣列元素。
  • r[i] = a[i] * a[i] 儲存平方結果。
  • malloc 配置的記憶體要由呼叫端 free。
完整程式與中文註解
/*
 * 檔名：practice07_5_annotated.c
 * 主題：動態記憶體 malloc、陣列修改、free
 * 功能：把原陣列改成絕對值，並另外建立一個平方陣列回傳。
 */
#include <stdio.h>   /* 提供 printf()。 */
#include <stdlib.h>  /* 提供 malloc() 與 free()。 */

int *func(int a[], int size) /* 接收陣列與大小，回傳新配置的平方陣列位址。 */
{
    int *r; /* r 指向動態配置的新陣列。 */
    int i;  /* 迴圈索引。 */

    r = (int *)malloc(size * sizeof(int)); /* 配置可存放 size 個 int 的記憶體空間。 */

    if (r == NULL) /* 若 malloc 失敗，會回傳 NULL。 */
    {
        return NULL; /* 通知呼叫端記憶體配置失敗。 */
    }

    for (i = 0; i < size; i++) /* 逐一處理陣列元素。 */
    {
        if (a[i] < 0) /* 若原陣列元素為負數。 */
        {
            a[i] = -a[i]; /* 改成正數，也就是取絕對值。 */
        }

        r[i] = a[i] * a[i]; /* 將絕對值平方後存到新陣列 r。 */
    }

    return r; /* 回傳新陣列的起始位址。 */
}

int main(void) /* 主程式。 */
{
    int a[] = {-1, 2, -3, 4, -5}; /* 原始陣列，包含正數與負數。 */
    int size = sizeof(a) / sizeof(a[0]); /* 計算陣列元素數量。 */
    int *r; /* 接收 func 回傳的新陣列。 */
    int i;  /* 迴圈索引。 */

    r = func(a, size); /* 呼叫函式，a 會被改成絕對值，r 會指向平方結果。 */

    if (r == NULL) /* 檢查記憶體配置是否失敗。 */
    {
        printf("Memory allocation failed.\n"); /* 顯示錯誤訊息。 */
        return 1; /* 非正常結束。 */
    }

    printf("Absolute array:\n"); /* 準備輸出改成絕對值後的原陣列。 */
    for (i = 0; i < size; i++)
    {
        printf("%d ", a[i]); /* 輸出 a[i]。 */
    }

    printf("\nSquare array:\n"); /* 準備輸出平方陣列。 */
    for (i = 0; i < size; i++)
    {
        printf("%d ", r[i]); /* 輸出 r[i]。 */
    }

    printf("\n"); /* 最後換行。 */

    free(r); /* 釋放 malloc 配置的記憶體，避免 memory leak。 */

    return 0; /* 正常結束。 */
}
