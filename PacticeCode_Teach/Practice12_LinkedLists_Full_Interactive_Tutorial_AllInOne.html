一、完整投影片式教學

這一節把課堂投影片內容整理成可切換的教學卡。Linked list 的基本定義是由一串 struct node 組成，每個 node 內含資料與指向下一個 node 的指標；投影片也強調 linked list 容易插入刪除，但失去 array 的 random access 能力。

二、核心觀念總整理

1. struct node

value 放資料，next 放下一個節點位址。最後一個節點的 next 必須是 NULL。

2. head / first / list

這些名稱通常代表 linked list 的第一個節點。只要 head 遺失，整串 list 就可能無法再存取。

3. malloc

linked list 節點通常用 malloc(sizeof(struct node)) 動態配置。正式程式應檢查是否回傳 NULL。

4. -> 運算子

p->value 等同 (*p).value。當 p 是 struct 指標時，通常使用 -> 讀寫成員。

5. 搜尋

用 for(p=list; p!=NULL; p=p->next) 逐一走訪。找到節點可回傳指標，找不到通常回傳 NULL。

6. 有序插入

用 prev 與 cur 找到插入位置，再改兩條 link：new_node->next=cur、prev->next=new_node。

第 1 題：find_last

題目

Write the following function: struct node *find_last(struct node *list, int n); list 指向一個 linked list。函式應回傳最後一個 value 等於 n 的節點；若 n 不存在，回傳 NULL。

解題觀念

  1. 核心想法是從頭走到尾，不要一找到就 return，因為題目要的是最後一次出現。
  2. 使用 last 指標記錄目前最後一次找到的位置。每遇到 p->value == n，就更新 last = p。
  3. 走訪完成後，last 若仍為 NULL，表示沒找到；否則 last 指向最後一次出現的節點。

執行流程追蹤

  1. 建立串列：1 -> 5 -> 3 -> 5 -> NULL
  2. 從 1 開始檢查，不符合 5。
  3. 遇到第一個 5，last 指向這個節點。
  4. 遇到 3，不更新。
  5. 遇到第二個 5，再更新 last。
  6. 到 NULL 後回傳 last，因此輸出 5。

程式執行結果

Last node value: 5

建議測試方式

先複製本題程式碼，貼到下方任一線上 C 編譯器執行。若使用本機，請用 gcc practice12_1.c -o practice12_1 編譯。

完整程式：practice12_1.c

/*
 * 檔名：practice12_1.c
 * 主題：單向鏈結串列，尋找最後一次出現的節點
 * 說明：建立一個 linked list，並找出值為指定數字的最後一個節點。
 */

#include <stdio.h>   /* 引入標準輸入輸出函式庫，提供 printf() */
#include <stdlib.h>  /* 引入標準函式庫，提供 malloc() */

/* 定義單向鏈結串列節點 */
struct node
{
    int value;          /* 節點中儲存的整數資料 */
    struct node *next;  /* 指向下一個節點的指標；若為 NULL 代表串列結尾 */
};

/*
 * 函式名稱：add_to_list
 * 函式功能：建立新節點，並插入到串列最前面。
 * 參數 list：原本串列的第一個節點位址。
 * 參數 n：要放入新節點的值。
 * 回傳值：新的串列開頭位址。
 */
struct node *add_to_list(struct node *list, int n)
{
    struct node *new_node;  /* 宣告新節點指標 */

    new_node = (struct node *)malloc(sizeof(struct node));  /* 配置一個 struct node 大小的記憶體空間 */

    new_node->value = n;     /* 將新節點的 value 設定為 n */
    new_node->next = list;   /* 讓新節點指向原本的串列開頭，完成前端插入 */

    return new_node;  /* 回傳新節點，因為它現在是新的串列開頭 */
}

/*
 * 函式名稱：find_last
 * 函式功能：在串列中尋找最後一次出現數值 n 的節點。
 * 作法：從頭走到尾，每次遇到 n 就更新 last，因此最後留下的就是最後一次出現的位置。
 */
struct node *find_last(struct node *list, int n)
{
    struct node *p;            /* p 用來走訪整個串列 */
    struct node *last = NULL;  /* last 用來記錄目前找到的最後一個符合節點；初始為 NULL 表示尚未找到 */

    for (p = list; p != NULL; p = p->next)  /* 從串列開頭一路走到 NULL 結尾 */
    {
        if (p->value == n)  /* 如果目前節點的值等於要找的 n */
        {
            last = p;  /* 更新 last，記錄目前這個符合條件的節點 */
        }
    }

    return last;  /* 回傳最後一次出現 n 的節點；若找不到則回傳 NULL */
}

int main(void)
{
    struct node *list = NULL;  /* 宣告串列開頭指標，初始為 NULL 表示空串列 */
    struct node *result;       /* result 用來接收 find_last() 的搜尋結果 */

    list = add_to_list(list, 5);  /* 插入 5 到串列前端，目前串列：5 */
    list = add_to_list(list, 3);  /* 插入 3 到串列前端，目前串列：3 -> 5 */
    list = add_to_list(list, 5);  /* 插入 5 到串列前端，目前串列：5 -> 3 -> 5 */
    list = add_to_list(list, 1);  /* 插入 1 到串列前端，目前串列：1 -> 5 -> 3 -> 5 */

    result = find_last(list, 5);  /* 尋找串列中最後一次出現值 5 的節點 */

    if (result != NULL)  /* 如果 result 不是 NULL，代表有找到值為 5 的節點 */
    {
        printf("Last node value: %d\n", result->value);  /* 印出找到的節點值 */
    }
    else  /* 如果 result 是 NULL，代表串列中沒有值為 5 的節點 */
    {
        printf("Value not found.\n");  /* 印出找不到資料的訊息 */
    }

    return 0;  /* 程式正常結束；注意：原程式未釋放 linked list 節點，正式程式可再補 free */
}

第 2 題：count_occurrences

題目

Write the following function: int count_occurrences(struct node *list, int n); list 指向 linked list。函式回傳 n 在此串列中出現幾次。

解題觀念

  1. 核心想法是完整走訪整個串列，使用 count 計數。
  2. 每一個節點都檢查 p->value 是否等於 n。若相等，count++。
  3. 走到 NULL 後回傳 count。若完全沒有出現，count 會維持 0。

執行流程追蹤

  1. 建立串列：1 -> 5 -> 5 -> 3 -> 5 -> NULL
  2. 檢查 1，不計數。
  3. 檢查第一個 5，count=1。
  4. 檢查第二個 5，count=2。
  5. 檢查 3，不計數。
  6. 檢查第三個 5，count=3。
  7. 回傳 3。

程式執行結果

Occurrences of 5: 3

建議測試方式

先複製本題程式碼，貼到下方任一線上 C 編譯器執行。若使用本機，請用 gcc practice12_2.c -o practice12_2 編譯。

完整程式：practice12_2.c

/*
 * 檔名：practice12_2.c
 * 主題：單向鏈結串列，計算指定數值出現次數
 * 說明：建立 linked list 後，走訪整個串列並統計某個值出現幾次。
 */

#include <stdio.h>   /* 引入標準輸入輸出函式庫，提供 printf() */
#include <stdlib.h>  /* 引入標準函式庫，提供 malloc() */

/* 定義單向鏈結串列節點 */
struct node
{
    int value;          /* 節點儲存的整數值 */
    struct node *next;  /* 指向下一個節點的指標 */
};

/* 建立新節點並插入串列最前面 */
struct node *add_to_list(struct node *list, int n)
{
    struct node *new_node;  /* 宣告新節點指標 */

    new_node = (struct node *)malloc(sizeof(struct node));  /* 配置一個節點所需的記憶體 */

    new_node->value = n;    /* 將新節點的資料設定為 n */
    new_node->next = list;  /* 新節點接到原本串列前面 */

    return new_node;  /* 回傳新的串列開頭 */
}

/*
 * 函式名稱：count_occurrences
 * 函式功能：計算串列中有多少節點的 value 等於 n。
 */
int count_occurrences(struct node *list, int n)
{
    int count = 0;   /* count 用來累計 n 出現的次數 */
    struct node *p;  /* p 用來走訪 linked list */

    for (p = list; p != NULL; p = p->next)  /* 從串列開頭走到結尾 */
    {
        if (p->value == n)  /* 若目前節點的值等於要統計的 n */
        {
            count++;  /* 出現次數加 1 */
        }
    }

    return count;  /* 回傳統計結果 */
}

int main(void)
{
    struct node *list = NULL;  /* 建立空串列，開頭指標先設為 NULL */

    list = add_to_list(list, 5);  /* 插入 5，目前串列：5 */
    list = add_to_list(list, 3);  /* 插入 3，目前串列：3 -> 5 */
    list = add_to_list(list, 5);  /* 插入 5，目前串列：5 -> 3 -> 5 */
    list = add_to_list(list, 5);  /* 插入 5，目前串列：5 -> 5 -> 3 -> 5 */
    list = add_to_list(list, 1);  /* 插入 1，目前串列：1 -> 5 -> 5 -> 3 -> 5 */

    printf("Occurrences of 5: %d\n", count_occurrences(list, 5));  /* 印出數值 5 在串列中出現的次數 */

    return 0;  /* 程式正常結束；注意：原程式未釋放 linked list 節點，正式程式可再補 free */
}

第 3 題：insert_into_ordered_list

題目

Write the following function: struct node *insert_into_ordered_list(struct node *list, struct node *new_node); list 指向一個已排序 linked list。函式要把 new_node 插入正確位置，並回傳修改後串列的第一個節點。

解題觀念

  1. 核心想法是用 cur 找到第一個不小於 new_node->value 的位置，用 prev 記住 cur 前面的節點。
  2. 若 prev == NULL，代表新節點要插入開頭，直接 return new_node。
  3. 否則讓 prev->next = new_node，且 new_node->next = cur，完成中間或尾端插入。

執行流程追蹤

  1. 先插入 10：10 -> NULL
  2. 插入 30：10 -> 30 -> NULL
  3. 插入 20 時，cur 從 10 走到 30，因為 30 不小於 20，所以停下。
  4. 此時 prev 是 10，cur 是 30。
  5. new_node->next = cur，讓 20 指向 30。
  6. prev->next = new_node，讓 10 指向 20。
  7. 結果：10 -> 20 -> 30 -> NULL。

程式執行結果

10 -> 20 -> 30 -> NULL

建議測試方式

先複製本題程式碼，貼到下方任一線上 C 編譯器執行。若使用本機，請用 gcc practice12_3.c -o practice12_3 編譯。

完整程式：practice12_3.c

/*
 * 檔名：practice12_3.c
 * 主題：有序 linked list 插入
 * 說明：將新節點插入已排序的單向鏈結串列，使串列仍保持由小到大的順序。
 */

#include <stdio.h>   /* 引入標準輸入輸出函式庫，提供 printf() */
#include <stdlib.h>  /* 引入標準函式庫，提供 malloc() */

/* 定義單向鏈結串列節點 */
struct node
{
    int value;          /* 節點中儲存的整數值 */
    struct node *next;  /* 指向下一個節點的指標 */
};

/*
 * 函式名稱：insert_into_ordered_list
 * 函式功能：把 new_node 插入到已由小到大排序的 linked list 中。
 * 參數 list：目前有序串列的開頭。
 * 參數 new_node：準備插入的新節點。
 * 回傳值：插入後的串列開頭。
 */
struct node *insert_into_ordered_list(struct node *list, struct node *new_node)
{
    struct node *cur;        /* cur 指向目前檢查的節點 */
    struct node *prev = NULL;/* prev 指向 cur 前一個節點，初始為 NULL 表示還在串列開頭前 */

    for (cur = list; cur != NULL && cur->value < new_node->value; cur = cur->next)  /* 找到第一個不小於 new_node 的位置 */
    {
        prev = cur;  /* 每往後走一步，就把 prev 更新成目前的 cur */
    }

    new_node->next = cur;  /* 讓新節點接到 cur 前面；cur 可能是中間節點，也可能是 NULL */

    if (prev == NULL)  /* 如果 prev 仍是 NULL，代表新節點應插入在串列最前面 */
    {
        return new_node;  /* 新節點成為新的串列開頭 */
    }
    else  /* 否則代表新節點插入在 prev 和 cur 中間 */
    {
        prev->next = new_node;  /* 讓前一個節點 prev 指向新節點 */
        return list;            /* 串列開頭沒有改變，回傳原本的 list */
    }
}

/* 印出整個 linked list 的內容 */
void print_list(struct node *list)
{
    struct node *p;  /* p 用來從頭到尾走訪串列 */

    for (p = list; p != NULL; p = p->next)  /* 逐一走訪每個節點直到 NULL */
    {
        printf("%d -> ", p->value);  /* 印出目前節點的值，並用箭頭表示下一個節點 */
    }

    printf("NULL\n");  /* 串列結尾以 NULL 表示 */
}

int main(void)
{
    struct node *list = NULL;  /* 宣告串列開頭，初始為 NULL，表示空串列 */
    struct node *n1;           /* 宣告第一個節點指標 */
    struct node *n2;           /* 宣告第二個節點指標 */
    struct node *n3;           /* 宣告第三個節點指標 */

    n1 = (struct node *)malloc(sizeof(struct node));  /* 配置第一個節點的記憶體 */
    n2 = (struct node *)malloc(sizeof(struct node));  /* 配置第二個節點的記憶體 */
    n3 = (struct node *)malloc(sizeof(struct node));  /* 配置第三個節點的記憶體 */

    n1->value = 10;  /* 設定第一個節點的值為 10 */
    n1->next = NULL; /* 先將 next 設為 NULL，表示尚未接到其他節點 */

    n2->value = 30;  /* 設定第二個節點的值為 30 */
    n2->next = NULL; /* 先將 next 設為 NULL */

    n3->value = 20;  /* 設定第三個節點的值為 20 */
    n3->next = NULL; /* 先將 next 設為 NULL */

    list = insert_into_ordered_list(list, n1);  /* 將 10 插入有序串列，目前：10 */
    list = insert_into_ordered_list(list, n2);  /* 將 30 插入有序串列，目前：10 -> 30 */
    list = insert_into_ordered_list(list, n3);  /* 將 20 插入有序串列，目前：10 -> 20 -> 30 */

    print_list(list);  /* 印出完整串列，應顯示 10 -> 20 -> 30 -> NULL */

    return 0;  /* 程式正常結束；注意：原程式未釋放 n1、n2、n3，正式程式可再補 free */
}

常見錯誤提醒

  • struct node *next; 後面記得分號。
  • malloc() 需要 #include <stdlib.h>。
  • 走訪 linked list 時，條件通常是 p != NULL，不要先取 p->value 才檢查 p 是否為 NULL。
  • 刪除節點時要先接回串列，再 free(cur)，避免串列斷掉。
