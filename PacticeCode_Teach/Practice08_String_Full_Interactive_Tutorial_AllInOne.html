一 課程總覽

String 在 C 語言中不是獨立型別，而是以 char 陣列加上結尾字元 '\0' 表示。理解字串時，要同時掌握「字元陣列」、「字串常值」、「指標」、「陣列空間大小」與 string.h 函式。

最重要觀念：C 字串能不能被修改，取決於它放在哪裡。char str[] = "Hello"; 是可修改陣列；char *str = "Hello"; 通常指向唯讀字串常值，不應修改。

本教學對應主題

  • String literal 與 \0
  • char str[] 與 char *str 差異
  • strlen、strcpy、strncpy、strcat、strcmp
  • scanf、fgets、puts
  • Command line arguments：argc、argv

二 完整投影片教學

Slide 1：什麼是 C 字串？

C 語言的字串是由一串 char 組成，最後一定要有 '\0' 表示字串結束。

a0
b1
c2
\03

沒有 '\0'，printf("%s", str) 就不知道要印到哪裡才停。

Slide 2：String literal

"abc" 是 string literal，實際上會儲存成 a b c \0。呼叫 printf("abc") 時，傳入的是字串起始位置。

printf("abc");  // 正確
printf('a');    // 錯誤，'a' 是 char，不是 char*
Slide 3：宣告字串變數
char str[] = "Hello World!";
char str[14] = "Hello World!";
char str[10] = "Hello World!"; // 空間不足，危險或警告

字串長度要包含最後的 \0。例如 "Hello" 需要 6 格。

Slide 4：char array vs char pointer

可修改

char str[] = "Hello";
str[0] = 'B'; // OK

不建議修改

char *str = "Hello";
str[0] = 'B'; // 可能 Segmentation fault
Slide 5：字串陣列
char animals[][7] = {"cat", "rabbit", "horse"};
char *animals[] = {"cat", "rabbit", "horse"};

第一種是固定每列 7 格；第二種是指標陣列，每個指標指向不同字串。

Slide 6：string.h 常用函式
函式用途
strlen(s)回傳字串長度，不包含 \0
strcpy(dst, src)複製整個字串
strncpy(dst, src, n)最多複製 n 個字元
strcat(dst, src)把 src 接到 dst 後面
strcmp(s1, s2)比較兩個字串
Slide 7：讀寫字串
scanf("%s", sen);     // 讀到空白停止
fgets(sen, 20, stdin); // 可讀入空白，較安全
puts(sen);             // 輸出字串並自動換行

不建議使用 gets，因為容易造成 buffer overflow。

Slide 8：命令列參數 argc / argv
int main(int argc, char *argv[]) {
    for (int i = 1; i < argc; i++)
        printf("%s\n", argv[i]);
}

argc 是參數個數；argv 是字串指標陣列。

Practice 08 Question 1

第 1 題：strncpy、strcpy 後字串內容變化

線上編譯器

一 題目

What will be the value of the string str after every string copy function in the following example are executed?

char str[25] = "This is a long string";
strncpy(str, "123456", 4);
strcpy(str, "New string");
strcpy(&str[5], "contents");

二 本題觀念投影片

本題重點是 C 字串是以字元陣列儲存，並以 \0 作為結尾。strncpy(str, "123456", 4) 只複製前 4 個字元，因此只會把原本字串前四格改成 1、2、3、4，後面的內容仍保留。

三 解答

Original:
This is a long string

After strncpy(str, "123456", 4):
1234 is a long string

After strcpy(str, "New string"):
New string

After strcpy(&str[5], "contents"):
New contents

四 完整程式與中文註解

/*
 * Practice 08-1
 * 主題：strncpy、strcpy 與字串內容變化
 */
#include <stdio.h>
#include <string.h>

int main(void)
{
    char str[25] = "This is a long string";

    printf("Original: %s\n", str);

    strncpy(str, "123456", 4);
    printf("After strncpy(str, \"123456\", 4): %s\n", str);

    strcpy(str, "New string");
    printf("After strcpy(str, \"New string\"): %s\n", str);

    strcpy(&str[5], "contents");
    printf("After strcpy(&str[5], \"contents\"): %s\n", str);

    return 0;
}

五 程式執行結果

Original: This is a long string After strncpy(str, "123456", 4): 1234 is a long string After strcpy(str, "New string"): New string After strcpy(&str[5], "contents"): New contents

六 程式說明

  1. 一開始 str 內容是 This is a long string。
  2. strncpy 只複製 4 個字元，所以 T h i s 被 1 2 3 4 取代；後面仍是空白與 is a long string。
  3. strcpy(str, "New string") 從 str[0] 開始完整複製 New string 與結尾字元 \0。
  4. strcpy(&str[5], "contents") 從 str[5] 的位置開始覆蓋，所以 New string 變成 New contents。

Practice 08 Question 2

第 2 題：函式 f(s,t) 回傳什麼？

線上編譯器

一 題目

Let f be the following function:
int f(char *s, char *t){
    char *p1, *p2;
    for(p1 = s; *p1 != '\0'; p1++){
        for(p2 = t; *p2; p2++)
            if(*p1 == *p2) break;
        if(*p2 == '\0') break;
    }
    return p1 - s;
}

(a) f("abcd", "babc") = ?
(b) f("abcd", "bcd") = ?
(c) In general, what value does f return?

二 本題觀念投影片

這題是字串指標走訪。外層 p1 逐一檢查 s 的每個字元；內層 p2 檢查該字元是否出現在 t 中。只要找到 s 中第一個不在 t 裡的字元，就停止並回傳該字元在 s 中的索引。

三 解答

(a) f("abcd", "babc") = 3
原因：a、b、c 都在 "babc" 中，d 不在，因此 d 的索引是 3。

(b) f("abcd", "bcd") = 0
原因：a 不在 "bcd" 中，因此第一個字元就停止，回傳索引 0。

(c) 一般而言，f(s,t) 會回傳 s 中第一個「不屬於 t 內任一字元」的位置索引。
若 s 的所有字元都在 t 中，則 p1 會走到 '\0'，回傳 strlen(s)。

四 完整程式與中文註解

/*
 * 檔名：practice08_2_annotated.c
 * 主題：字串、指標與字元搜尋
 * 功能：找出字串 s 中第一個「不屬於字串 t 內任一字元」的位置索引。
 */
#include <stdio.h> /* 提供 printf()。 */

int f(char *s, char *t) /* s 是被檢查字串，t 是允許出現的字元集合。 */
{
    char *p1, *p2; /* p1 走訪 s；p2 走訪 t。 */

    for (p1 = s; *p1 != '\0'; p1++) /* 從 s 第一個字元開始，直到字串結尾。 */
    {
        for (p2 = t; *p2; p2++) /* 對每個 s 的字元，到 t 裡面逐一比對。 */
        {
            if (*p1 == *p2) /* 若 s 目前字元有出現在 t 裡。 */
            {
                break; /* 找到了，跳出內層迴圈。 */
            }
        }

        if (*p2 == '\0') /* 若 p2 走到 t 結尾，表示沒有找到相同字元。 */
        {
            break; /* 找到第一個不屬於 t 的字元，跳出外層迴圈。 */
        }
    }

    return p1 - s; /* 回傳 p1 與 s 起始位址的距離，也就是索引值。 */
}

int main(void) /* 主程式。 */
{
    printf("f(\"abcd\", \"babc\") = %d\n", f("abcd", "babc")); /* d 不在 babc 中，回傳 3。 */
    printf("f(\"abcd\", \"bcd\") = %d\n", f("abcd", "bcd"));   /* a 不在 bcd 中，回傳 0。 */

    return 0; /* 正常結束。 */
}

五 程式執行結果

f("abcd", "babc") = 3 f("abcd", "bcd") = 0

六 程式說明

  1. p1 從 s[0] 開始往後走。
  2. 每一輪都用 p2 從 t[0] 開始找是否有相同字元。
  3. 如果 p2 走到字串結尾 \0，表示沒有找到該字元。
  4. return p1 - s 代表目前 p1 與 s 起點差幾格，也就是索引值。

Practice 08 Question 3

第 3 題：create_txt_extension(char *file_name)

線上編譯器

一 題目

Write the following function:
void create_txt_extension(char *file_name)

file_name points to a string containing a file name. This function will append ".txt" to the end of the file name string if it does not have an extension. However, if the file name string has an extension, e.g. "output.txt", its content will not be modified.

二 本題觀念投影片

本題重點是使用 char * 修改原本字元陣列。函式要掃描檔名中是否有 '.'。如果沒有 '.'，就用 strcat(file_name, ".txt") 把副檔名接到後面。注意：file_name 指向的陣列空間必須足夠放下新增的 .txt。

三 解答

範例：
file1 = "output"      → output.txt
file2 = "result.txt"  → result.txt

因為 output 沒有句點，所以補上 .txt。
因為 result.txt 已經有副檔名，所以不修改。

四 完整程式與中文註解

/*
 * 檔名：practice08_3_annotated.c
 * 主題：字串處理與 strcat
 * 功能：若檔名沒有副檔名，就自動在後面加上 .txt。
 */
#include <stdio.h>  /* 提供 printf()。 */
#include <string.h> /* 提供 strcat() 字串串接函式。 */

void create_txt_extension(char *file_name) /* 檢查檔名是否需要補上 .txt。 */
{
    int i; /* 迴圈索引。 */
    int has_extension = 0; /* 旗標：0 表示目前尚未發現句點，1 表示有副檔名。 */

    for (i = 0; file_name[i] != '\0'; i++) /* 從字串開頭掃到結尾。 */
    {
        if (file_name[i] == '.') /* 若檔名中出現句點，視為已有副檔名。 */
        {
            has_extension = 1; /* 標記已有副檔名。 */
            break; /* 不需要繼續檢查。 */
        }
    }

    if (!has_extension) /* 若沒有副檔名。 */
    {
        strcat(file_name, ".txt"); /* 將 .txt 接到原字串後面；陣列空間必須足夠。 */
    }
}

int main(void) /* 主程式。 */
{
    char file1[50] = "output";     /* 沒有副檔名，空間 50 足夠加上 .txt。 */
    char file2[50] = "result.txt"; /* 已經有副檔名，不會再加一次。 */

    create_txt_extension(file1); /* file1 會變成 output.txt。 */
    create_txt_extension(file2); /* file2 保持 result.txt。 */

    printf("file1 = %s\n", file1); /* 輸出 file1。 */
    printf("file2 = %s\n", file2); /* 輸出 file2。 */

    return 0; /* 正常結束。 */
}

五 程式執行結果

file1 = output.txt file2 = result.txt

六 程式說明

  1. has_extension 初始為 0，代表尚未發現副檔名。
  2. for 迴圈逐字檢查 file_name[i] 是否為 '.'。
  3. 如果找到 '.'，就把 has_extension 設為 1，代表已有副檔名。
  4. 如果掃完都沒有 '.'，才用 strcat 接上 .txt。

Practice 08 Question 4

第 4 題：scanf("%d%s%d") 的讀取結果

線上編譯器

一 題目

Suppose that we call scanf as follows:
scanf("%d%s%d", &i, s, &j);

If the user enters:
12abc34 56def78

What will be the values of i, s, and j after the call?

二 本題觀念投影片

scanf 會依照格式逐段讀取。%d 讀整數，遇到非數字停止；%s 讀字串，遇到空白停止；下一個 %d 會跳過空白後讀下一段整數。

三 解答

i = 12
s = abc34
j = 56

說明：
%d 先讀到 12，遇到 a 停止。
%s 從 a 開始讀到空白前，所以讀到 abc34。
%d 跳過空白後讀 56，遇到 d 停止。

四 完整程式與中文註解

/*
 * Practice 08-4
 * 主題：scanf("%d%s%d", &i, s, &j) 的讀取規則
 */
#include <stdio.h>

int main(void)
{
    int i, j;
    char s[100];

    printf("Please input: ");
    scanf("%d%s%d", &i, s, &j);

    printf("i = %d\n", i);
    printf("s = %s\n", s);
    printf("j = %d\n", j);

    return 0;
}

五 程式執行結果

Please input: 12abc34 56def78 i = 12 s = abc34 j = 56

六 程式說明

  1. %d 會讀取可形成整數的部分，所以從 12abc34 讀到 12 後停止。
  2. %s 會讀到空白為止，所以接著讀入 abc34。
  3. 下一個 %d 會略過空白，讀取 56def78 的開頭整數 56。
  4. def78 會留在輸入緩衝區中，這次 scanf 不再處理它。

Practice 08 Question 5

第 5 題：字元 ASCII 減 1 後輸出

線上編譯器

一 題目

What does the following program print?

#include<stdio.h>
int main(void){
    char s[] = "Hsjodi", *p;
    for ( p = s; *p != '\0'; p++)
        --*p;
    puts(s);
    return 0;
}

二 本題觀念投影片

本題重點是 char s[] 是可修改的字元陣列，p 逐一指向每個字元。--*p 代表把 p 指向的那個字元 ASCII 值減 1。

三 解答

輸出：
Grinch

原因：
H → G
s → r
j → i
o → n
d → c
i → h

四 完整程式與中文註解

/*
 * 檔名：practice08_5_annotated.c
 * 主題：字元陣列與指標走訪
 * 功能：把字串中每個字元的 ASCII 值減 1，形成新的字串。
 */
#include <stdio.h> /* 提供 puts()。 */

int main(void) /* 主程式。 */
{
    char s[] = "Hsjodi"; /* 宣告可修改的字元陣列；內容包含結尾字元 '\0'。 */
    char *p;             /* p 用來逐一指向字串中的每個字元。 */

    for (p = s; *p != '\0'; p++) /* 從第一個字元開始，直到遇到字串結尾。 */
    {
        --*p; /* 先取出 p 指向的字元，再將該字元 ASCII 值減 1；例如 H 變 G。 */
    }

    puts(s); /* 輸出修改後的字串，並自動換行。 */

    return 0; /* 正常結束。 */
}

五 程式執行結果

Grinch

六 程式說明

  1. p = s，表示 p 指向 s[0]。
  2. for 迴圈每次 p++，讓 p 指向下一個字元。
  3. --*p 會把目前字元減 1。
  4. Hsjodi 每個字元都減 1 後變成 Grinch。
