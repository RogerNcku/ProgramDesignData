一、主頁引言

C 語言的學習最容易卡住的地方，通常不是語法本身，而是「記憶體、位址、資料結構與編譯流程」之間的關係。這份主頁把 Practice 06–13 依照學習順序串起來，從指標開始，接著進入字串、檔案、動態記憶體、結構、鏈結串列，最後用 Preprocessor 整合多檔案程式。

建議學習方式：先看每章的投影片教學，再看題目區；每一題都把題目、程式碼、執行結果和中文說明放在同一區塊，適合複習、教學展示，也適合拿來做課程網站。

「會寫 C 程式，不只是會打語法；真正重要的是知道資料在記憶體裡如何被存取、修改、傳遞與釋放。」

二、Practice 06–13 互動式 HTML 入口

以下連結皆使用同一路徑的相對連結，請把本主頁 HTML 與 Practice06–Practice13 的 HTML 放在同一個資料夾中，即可直接點擊開啟。

三、建議學習路線

06

先建立位址觀念

Pointer I 先理解 &、*、p=&i、*p，這是後面所有章節的基礎。

07

把指標用在函式與陣列

Pointer II 會把指標帶入函式參數、回傳值、一維陣列、二維陣列與指標運算。

08

理解 C 字串其實是 char 陣列

String 章節把指標與陣列用在字串處理，包含 strcpy、strncpy、scanf、fgets。

09

讓程式能讀寫檔案

File I/O 介紹 FILE *、fopen、fscanf、fgets、fseek、rename 等實用工具。

10–12

進入動態記憶體與資料結構

Dynamic storage allocation、Structure、Linked Lists 是 C 語言資料結構的核心，會大量使用 malloc、free、struct、next 指標。

13

最後用 Preprocessor 整合專案

Preprocessor 幫助你理解 #define、#include、header file、條件編譯與多檔案編譯。

四、線上 C 編譯器連結

每章教學頁面都有複製程式碼功能。複製後可以貼到以下任一線上 C 編譯器執行。若題目需要檔案讀寫或命令列參數，建議優先使用 OnlineGDB 或本機 gcc。

W3Schools C Compiler介面簡單，適合快速貼上程式並按 Run。 OnlineGDB支援 stdin、debug、部分命令列參數，適合練習作業。 Programiz C Compiler版面乾淨，適合初學者測試單檔 C 程式。 Godbolt Compiler Explorer可看 assembly，適合理解指標、陣列與編譯後結果。 JDoodle C Compiler可快速執行 C 程式，也可切換部分編譯環境。

五、如何使用這個主頁

把本主頁與 Practice06–Practice13 的 HTML 放在同一個資料夾。主頁使用相對路徑連結，不需要網路也可以打開章節頁。
