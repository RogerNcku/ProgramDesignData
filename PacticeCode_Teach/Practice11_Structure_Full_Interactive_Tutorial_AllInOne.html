一、完整投影片式教學

這一區把 Structure 講義整理成可切換的投影片。重點依序是：為什麼需要 struct、如何宣告與初始化、如何使用 . 與 ->、struct 傳入函式時的複製行為，以及結構陣列。

Slide 1：為什麼需要 Structure？

陣列只能把「同型態」資料放在一起，例如整數陣列、字元陣列。可是學生資料通常包含姓名、數學成績、CS 成績、英文成績，型態不同但邏輯上屬於同一個人。

struct 的目的：把相關資料包成同一筆資料，讓程式更容易管理。

Slide 2：struct 變數宣告

struct {
    char *studentName;
    int mathGrade;
    int csGrade;
    int englishGrade;
} s1, s2;

這種寫法會建立兩個結構變數 s1 與 s2，每個變數都有四個欄位。欄位的型態可以不同，這就是 struct 和 array 最大的差異之一。

Slide 3：Structure Initialization

struct student s1 = {"Tim", 60, 70, 70};
struct student s2 = {"Joe", 70, 50, 80};

初始化時，花括號中的值會依照欄位宣告順序填入。第一個值給 name，第二個值給 math，第三個值給 cs，第四個值給 english。

Slide 4：用 dot operator 存取欄位

s1.mathGrade = 80;
printf("%d", s1.mathGrade);

. 用在「結構變數本身」。如果你手上有的是 struct 變數，就用 s1.mathGrade。

Slide 5：struct 可以直接複製

time1 = time2;

這行會把 time2 的所有欄位複製到 time1。這和陣列不一樣；C 的陣列不能直接用 a = b 複製，但 struct 變數可以直接指定。

Slide 6：Structure Tag

struct time {
    int hours;
    int minutes;
    int seconds;
};

time 是 structure tag。有了 tag 之後，可以在不同地方宣告 struct time t1;，把這種結構當成一種自訂資料型態使用。

Slide 7：struct 傳入函式：傳值

void updateInfo(struct time t, int h, int m, int s) {
    t.hours = h;
}

這種寫法只會修改函式內部的副本，不會改到 main 裡原本的變數。

Slide 8：struct 傳入函式：傳址

void updateInfo(struct time *t, int h, int m, int s) {
    t->hours = h;
}

t->hours 等價於 (*t).hours。當函式拿到結構變數的位址，就可以修改原本的 struct。

Slide 9：巢狀結構 Nested Structure

struct name { char *firstName; char *lastName; };
struct student { struct name studentName; int mathGrade; };
printf("%s", s1.studentName.firstName);

struct 的欄位也可以是另一個 struct，所以可以做出更有層次的資料模型。

Slide 10：結構陣列與動態配置

struct student *s;
s = calloc(n, sizeof(struct student));
free(s);

如果學生人數執行時才知道，可以使用 calloc() 動態配置 n 筆 struct student 空間，最後記得 free()。

二、核心觀念總整理

1. struct 是資料集合

用來把相關資料放在一起，成為一筆完整資料，例如時間、學生、座標。

2. 欄位可以不同型態

陣列元素型態必須相同；struct 成員可以是 int、char array、pointer 或另一個 struct。

3. 使用 . 與 ->

變數本身用 .；指向 struct 的指標用 ->。

4. struct 可直接指定

s2 = s1 會複製所有欄位，但只限相容的結構型態。

5. 傳值會複製整包資料

函式參數若是 struct 本身，會產生副本；修改副本不會影響原本資料。

6. 傳址可修改原資料

傳入 &s1 並用 struct student *p 接收，可以修改原本資料。

四、第 1 題：宣告 time1/time2、初始化、複製並檢查

題目

(a) 宣告兩個結構變數 time1 與 time2，都有 hours、minutes、seconds 三個整數欄位。
(b) 初始化 time1 = 07:05:00，time2 = 20:59:00。
(c) 寫出 time1 = time2;。
(d) 用 main 檢查兩者內容。

解題重點

  • 先定義 struct timeStruct，把三個時間欄位包成一筆資料。
  • struct 可以用 {7,5,0} 依欄位順序初始化。
  • time1 = time2 會把三個欄位全部複製。
完整程式：practice11_1.c 
/*
 * 檔名：practice11_1.c
 * 主題：結構變數的指定與複製
 * 說明：示範 struct 變數可以直接使用指定運算子 =，將一個結構的所有欄位複製到另一個結構。
 */

#include <stdio.h>  /* 引入標準輸入輸出函式庫，提供 printf() */

/* 定義結構型別 timeStruct，用來表示時間資料 */
struct timeStruct
{
    int hours;    /* 小時欄位，例如 7 或 20 */
    int minutes;  /* 分鐘欄位，例如 5 或 59 */
    int seconds;  /* 秒數欄位，例如 0 */
};

int main(void)
{
    struct timeStruct time1 = {7, 5, 0};     /* 宣告 time1，並初始化為 07:05:00 */
    struct timeStruct time2 = {20, 59, 0};   /* 宣告 time2，並初始化為 20:59:00 */

    printf("Before copy:\n");  /* 印出複製前的標題 */
    printf("time1 = %02d:%02d:%02d\n", time1.hours, time1.minutes, time1.seconds);  /* 以兩位數格式印出 time1 */
    printf("time2 = %02d:%02d:%02d\n", time2.hours, time2.minutes, time2.seconds);  /* 以兩位數格式印出 time2 */

    time1 = time2;  /* 將 time2 的所有欄位值複製給 time1，包含 hours、minutes、seconds */

    printf("\nAfter copy:\n");  /* 印出複製後的標題，前面的 \n 用來換行 */
    printf("time1 = %02d:%02d:%02d\n", time1.hours, time1.minutes, time1.seconds);  /* 印出複製後的 time1，此時應與 time2 相同 */
    printf("time2 = %02d:%02d:%02d\n", time2.hours, time2.minutes, time2.seconds);  /* 印出 time2，確認原資料沒有被改變 */

    return 0;  /* 程式正常結束 */
}

程式執行結果

Before copy: time1 = 07:05:00 time2 = 20:59:00 After copy: time1 = 20:59:00 time2 = 20:59:00

結果說明

複製前 time1 是 07:05:00，time2 是 20:59:00。執行 time1 = time2; 後，time1 的 hours、minutes、seconds 全部變成與 time2 相同，因此兩者都顯示 20:59:00。

五、第 2 題：createTime、showInfo、updateInfo

題目

宣告 structure tag time，並完成三個函式：createTime 建立並回傳時間、showInfo 印出時間、updateInfo 更新時間內容。

解題重點

  • createTime() 回傳一個 struct time，適合用來建立資料。
  • showInfo(struct time t) 使用傳值，單純印出資料即可。
  • updateInfo(struct time *t,...) 使用傳址，因為要修改 main 裡的原本時間。
  • t->hours 是 (*t).hours 的簡寫。
完整程式：practice11_2.c 
/*
 * 檔名：practice11_2.c
 * 主題：結構函式、傳值與傳址修改
 * 說明：示範如何用函式建立 struct time、印出時間，以及透過指標修改結構內容。
 */

#include <stdio.h>  /* 引入標準輸入輸出函式庫，提供 printf() */

/* 定義 struct time，用來儲存一筆時間資料 */
struct time
{
    int hours;    /* 小時 */
    int minutes;  /* 分鐘 */
    int seconds;  /* 秒 */
};

/*
 * 函式名稱：createTime
 * 函式功能：根據傳入的小時、分鐘、秒數建立一個 struct time 並回傳。
 */
struct time createTime(int hours, int minutes, int seconds)
{
    struct time t;  /* 宣告區域變數 t，用來暫存要建立的時間 */

    t.hours = hours;      /* 將參數 hours 存入 t 的 hours 欄位 */
    t.minutes = minutes;  /* 將參數 minutes 存入 t 的 minutes 欄位 */
    t.seconds = seconds;  /* 將參數 seconds 存入 t 的 seconds 欄位 */

    return t;  /* 回傳建立好的 struct time */
}

/*
 * 函式名稱：showInfo
 * 函式功能：印出 struct time 的內容。
 * 注意：這裡使用傳值，所以函式內拿到的是 t 的副本，不會修改原本資料。
 */
void showInfo(struct time t)
{
    printf("%02d:%02d:%02d\n", t.hours, t.minutes, t.seconds);  /* 以 HH:MM:SS 格式印出時間 */
}

/*
 * 函式名稱：updateInfo
 * 函式功能：透過 struct time 指標修改原本的時間資料。
 * 注意：t 是指標，所以使用 t->hours 等語法存取結構欄位。
 */
void updateInfo(struct time *t, int hours, int minutes, int seconds)
{
    t->hours = hours;      /* 修改原結構的 hours 欄位 */
    t->minutes = minutes;  /* 修改原結構的 minutes 欄位 */
    t->seconds = seconds;  /* 修改原結構的 seconds 欄位 */
}

int main(void)
{
    struct time t1;  /* 宣告一個 struct time 變數 t1 */

    t1 = createTime(7, 5, 0);  /* 呼叫 createTime() 建立 07:05:00，並指定給 t1 */

    printf("Original time:\n");  /* 印出原始時間標題 */
    showInfo(t1);  /* 呼叫 showInfo() 顯示 t1 的目前內容 */

    updateInfo(&t1, 20, 59, 0);  /* 傳入 t1 的位址，將 t1 更新成 20:59:00 */

    printf("Updated time:\n");  /* 印出更新後時間標題 */
    showInfo(t1);  /* 再次顯示 t1，確認內容已被 updateInfo() 修改 */

    return 0;  /* 程式正常結束 */
}

程式執行結果

Original time: 07:05:00 Updated time: 20:59:00

結果說明

一開始 createTime(7,5,0) 建立 07:05:00。接著 updateInfo(&t1,20,59,0) 傳入 t1 位址，所以函式可以修改原本 t1，最後輸出 20:59:00。

六、第 3 題：deltaTime 計算兩個時間差

題目

延伸第 2 題，定義 deltaTime，輸入兩個 struct time，輸出兩者時間差的 struct time。

解題重點

  • 把 HH:MM:SS 轉成總秒數：hours*3600 + minutes*60 + seconds。
  • 兩個總秒數相減並取絕對值。
  • 再把秒數轉回小時、分鐘、秒。
完整程式：practice11_3.c 
/*
 * 檔名：practice11_3.c
 * 主題：計算兩個時間的差距
 * 說明：將時間轉換成總秒數後相減，再把秒數轉回小時、分鐘、秒。
 */

#include <stdio.h>   /* 引入標準輸入輸出函式庫，提供 printf() */
#include <stdlib.h>  /* 引入標準函式庫，提供 abs() 函式 */

/* 定義 struct time，用來表示一個時間 */
struct time
{
    int hours;    /* 小時欄位 */
    int minutes;  /* 分鐘欄位 */
    int seconds;  /* 秒數欄位 */
};

/* 建立並回傳一個 struct time */
struct time createTime(int h, int m, int s)
{
    struct time t;  /* 宣告時間結構變數 t */

    t.hours = h;    /* 將參數 h 指定給小時 */
    t.minutes = m;  /* 將參數 m 指定給分鐘 */
    t.seconds = s;  /* 將參數 s 指定給秒 */

    return t;  /* 回傳建立好的時間 */
}

/* 以 HH:MM:SS 格式印出時間 */
void showInfo(struct time t)
{
    printf("%02d:%02d:%02d\n", t.hours, t.minutes, t.seconds);  /* %02d 表示不足兩位數時補 0 */
}

/*
 * 函式名稱：deltaTime
 * 函式功能：計算 t1 與 t2 的絕對時間差。
 * 作法：先把兩個時間都換算成總秒數，再相減取絕對值，最後換回時分秒。
 */
struct time deltaTime(struct time t1, struct time t2)
{
    struct time result;      /* 宣告 result，用來存放最後的時間差 */
    int total1, total2, diff; /* total1/total2 存總秒數，diff 存秒數差 */

    total1 = t1.hours * 3600 + t1.minutes * 60 + t1.seconds;  /* 將 t1 轉換為總秒數 */
    total2 = t2.hours * 3600 + t2.minutes * 60 + t2.seconds;  /* 將 t2 轉換為總秒數 */

    diff = abs(total1 - total2);  /* 計算兩個總秒數的差，並取絕對值，避免出現負數 */

    result.hours = diff / 3600;  /* 由總秒數差計算相差幾小時 */
    diff %= 3600;                /* 取出扣掉完整小時後剩下的秒數 */

    result.minutes = diff / 60;  /* 用剩餘秒數計算相差幾分鐘 */
    result.seconds = diff % 60;  /* 剩下不足 60 秒的部分就是秒數 */

    return result;  /* 回傳計算完成的時間差 */
}

int main(void)
{
    struct time t1, t2, diff;  /* 宣告兩個時間 t1、t2，以及時間差 diff */

    t1 = createTime(20, 59, 0);  /* 建立第一個時間 20:59:00 */
    t2 = createTime(7, 5, 0);    /* 建立第二個時間 07:05:00 */

    printf("Time 1: ");  /* 印出 Time 1 標籤 */
    showInfo(t1);         /* 顯示第一個時間 */

    printf("Time 2: ");  /* 印出 Time 2 標籤 */
    showInfo(t2);         /* 顯示第二個時間 */

    diff = deltaTime(t1, t2);  /* 呼叫 deltaTime() 計算兩時間的差距 */

    printf("Difference: ");  /* 印出 Difference 標籤 */
    showInfo(diff);           /* 顯示時間差 */

    return 0;  /* 程式正常結束 */
}

程式執行結果

Time 1: 20:59:00 Time 2: 07:05:00 Difference: 13:54:00

結果說明

20:59:00 轉成 75540 秒，07:05:00 轉成 25500 秒，差距為 50040 秒。50040 秒等於 13 小時 54 分 0 秒，所以輸出 13:54:00。

七、第 4 題：C 的 Structure 與 Java 的 Class 比較

題目

比較 C 語言 structure 與 Java class 的相同與不同。

參考答案

Comparison between Structure in C and Class in Java

Similarities:
1. Both can store related data together.
2. Both can create variables containing multiple members.
3. Both support nested data structures.

Differences:
1. Structure in C does not contain methods, but Java class can contain methods.
2. Structure members are public by default, while Java class supports access control such as private and public.
3. Java class supports object-oriented programming features such as inheritance and polymorphism.
4. Structure is mainly used for grouping data, while Java class combines both data and behavior.

補充說明

比較項目C StructureJava Class
主要用途將相關資料欄位群組化將資料與行為包成物件
是否有 method沒有自己的 method可以有 method
封裝與權限沒有 private/public 這種 class access control支援 private、public、protected
物件導向特性主要是資料聚合支援繼承、多型、封裝

結果說明

C 的 struct 較像「資料包裝盒」；Java 的 class 則是「資料＋操作方法＋物件導向設計」。因此在 C 中常用函式操作 struct，而 Java 通常把操作寫成 class 的 method。

八、Advanced Training：用 calloc 重新實作 Struct_ary.c

題目

使用 dynamic memory allocation 重新實作結構陣列，也就是用 pointer 與 calloc() 取代固定大小陣列。

解題重點

  • struct student *s; 宣告指向學生資料的指標。
  • calloc(n, sizeof(struct student)) 配置 n 筆學生資料，並初始化為 0。
  • 用 s[i].firstName、s[i].mathGrade 存取第 i 筆學生資料。
  • 最後一定要 free(s)。
完整程式：practice11_advanced.c 
/*
 * 檔名：practice11_advanced.c
 * 主題：結構陣列與 calloc 動態配置
 * 說明：使用 struct student 儲存學生姓名與成績，並用 calloc() 配置多筆學生資料空間。
 */

#include <stdio.h>   /* 引入標準輸入輸出函式庫，提供 printf()、sprintf() */
#include <stdlib.h>  /* 引入標準函式庫，提供 calloc()、free() */

/* 定義學生資料結構 */
struct student
{
    char firstName[20];  /* 儲存學生名字，最多可存 19 個字元加上字串結尾 '\0' */
    char lastName[20];   /* 儲存學生姓氏，最多可存 19 個字元加上字串結尾 '\0' */
    int mathGrade;       /* 數學成績 */
    int csGrade;         /* 電腦科學成績 */
    int englishGrade;    /* 英文成績 */
};

int main(void)
{
    int n = 3;  /* 設定學生人數為 3 */
    int i;      /* 宣告迴圈變數 i */

    struct student *s;  /* 宣告 struct student 指標，用來指向動態配置出的學生陣列 */

    s = (struct student *)calloc(n, sizeof(struct student));  /* 配置 n 個 student 結構空間，並自動初始化為 0 */

    if (s == NULL)  /* 檢查 calloc() 是否配置失敗 */
    {
        printf("Memory allocation failed.\n");  /* 印出記憶體配置失敗訊息 */
        return 1;  /* 回傳 1，表示程式錯誤結束 */
    }

    sprintf(s[0].firstName, "Tim");     /* 將第一位學生的名字寫入 firstName */
    sprintf(s[0].lastName, "Robert");   /* 將第一位學生的姓氏寫入 lastName */
    s[0].mathGrade = 60;                 /* 設定第一位學生的數學成績 */
    s[0].csGrade = 45;                   /* 設定第一位學生的電腦科學成績 */
    s[0].englishGrade = 82;              /* 設定第一位學生的英文成績 */

    sprintf(s[1].firstName, "Mary");    /* 將第二位學生的名字寫入 firstName */
    sprintf(s[1].lastName, "Hunter");   /* 將第二位學生的姓氏寫入 lastName */
    s[1].mathGrade = 61;                 /* 設定第二位學生的數學成績 */
    s[1].csGrade = 82;                   /* 設定第二位學生的電腦科學成績 */
    s[1].englishGrade = 50;              /* 設定第二位學生的英文成績 */

    sprintf(s[2].firstName, "John");    /* 將第三位學生的名字寫入 firstName */
    sprintf(s[2].lastName, "Michael");  /* 將第三位學生的姓氏寫入 lastName */
    s[2].mathGrade = 70;                 /* 設定第三位學生的數學成績 */
    s[2].csGrade = 58;                   /* 設定第三位學生的電腦科學成績 */
    s[2].englishGrade = 85;              /* 設定第三位學生的英文成績 */

    for (i = 0; i < n; i++)  /* 從第 0 位到第 n-1 位，依序印出所有學生資料 */
    {
        printf("%s %s\n", s[i].firstName, s[i].lastName);  /* 印出學生完整姓名 */
        printf("Math: %d\n", s[i].mathGrade);              /* 印出數學成績 */
        printf("CS: %d\n", s[i].csGrade);                  /* 印出電腦科學成績 */
        printf("English: %d\n\n", s[i].englishGrade);      /* 印出英文成績，最後多換一行分隔資料 */
    }

    free(s);  /* 釋放 calloc() 配置的學生陣列記憶體 */

    return 0;  /* 程式正常結束 */
}

常見錯誤提醒

  • 使用 calloc() 與 free() 要 #include <stdlib.h>。
  • 若函式要修改原 struct，要傳入位址，例如 updateInfo(&t1,...)。
  • struct 指標存取欄位可用 p->field，不要誤寫成 p.field。
  • 用 calloc() 配置的記憶體，用完要 free()。
