一、教學目標

本教學依照 Pointer I 講義與 Practice 06 製作。重點是理解「變數的值」和「變數的位址」不同，以及指標變數如何儲存位址。

  • 理解 & address operator。
  • 理解 * indirection / dereference operator。
  • 判斷指標指定敘述是否合法。
  • 用指標修改原變數。
  • 用指標作為函式輸出參數，回傳多個結果。
最重要觀念：
一般變數存的是「值」，指標變數存的是「位址」。
p = &i; 表示 p 存 i 的位址。
*p 表示「到 p 存的位址那裡，把內容拿出來或改掉」。

二、完整投影片式教學

Slide 1 / 8
記憶體像置物櫃

講義用「行李、置物格、置物格編號、置物櫃」比喻 C 語言記憶體：

行李
Value
置物格
Byte
編號
Address
櫃子
Main memory

當你宣告 int i = 5;，可以想成把數值 5 放進某個置物格，而那個置物格有一個位址。

Slide 2 / 8
變數會佔用記憶體位址

每個變數會佔用一個或多個 bytes。每個 byte 都有唯一的 address。變數的 address 通常指它佔用的第一個 byte 的位址。

概念例子
int i可能佔 4 bytes
&i取得 i 的起始位址
i取得 i 裡面的值
Slide 3 / 8
什麼是 Pointer？

Pointer 是一種變數，但它裡面存的不是一般整數值，而是「記憶體位址」。

int i = 5;
int *p;
p = &i;

此時 p 指向 i；p 是 i 的位址，*p 是 i 的值。

Slide 4 / 8
宣告與初始化
int *p;      // 宣告 p 是 int pointer
p = &i;      // 讓 p 指向 i
int *q=&i;   // 宣告時直接初始化

只宣告 int *p; 但沒有讓它指向合法變數時，不能使用 *p 寫值。

Slide 5 / 8
*p：到 p 指向的位置取值或改值
int i = 5;
int *p = &i;
printf("%d", *p); // 印出 5
*p = 1;           // i 變成 1

*p 不是 p 自己，而是「p 指向的那個變數」。

Slide 6 / 8
q = p：改變指向對象

若 p=&i，q=&j，執行 q=p 後，q 不再指向 j，而是和 p 一樣指向 i。

q = p;
*p = 1;
// i 變 1，j 不變
// *p 和 *q 都是 i 的值
Slide 7 / 8
*q = *p：複製值，不改指向

*q = *p 是把 p 指向位置的內容複製到 q 指向的位置。p 與 q 仍然指向原本的變數。

*q = *p; // j = i
*p = 1;  // i = 1，j 保持剛剛複製到的值
Slide 8 / 8
危險錯誤：未初始化指標
int *p;
*p = 3;  // 危險：p 還不知道指到哪裡

這可能造成 Segmentation Fault，因為程式嘗試寫入不屬於它的記憶體位置。

四、第 1 題：判斷哪些 pointer assignment 合法

題目

假設 int i; 且 p、q 都是 int *，判斷 a 到 i 哪些指定合法。

敘述答案說明
p = i;illegalp 需要 int 位址，但 i 是 int 值。
*p = &i;illegal*p 是 int 變數內容，&i 是位址。
&p = q;illegal&p 不是可被指定的左值。
p = &q;illegal&q 型態是 int **，p 型態是 int *。
p = &*q;legal&*q 等同 q，型態為 int *。
p = q;legal兩者都是 int *。
p = *q;illegal*q 是 int 值，不是 int 位址。
*p = q;illegal*p 是 int，q 是 int *。
*p = *q;legal兩邊都是 int 值。

示範程式

practice06_1_demo.c
/* Practice 6-1: 判斷合法與非法 assignment */
#include <stdio.h>

int main(void)
{
    int i = 10;
    int j = 20;
    int *p = &i;
    int *q = &j;

    /* 以下三種是合法的 */
    p = &*q;     /* &*q 等同 q，所以 p 指向 j */
    p = q;       /* p 和 q 指向同一個 int 變數 */
    *p = *q;     /* 把 q 指向的值指定給 p 指向的位置 */

    printf("i = %d
", i);
    printf("j = %d
", j);
    printf("*p = %d
", *p);
    printf("*q = %d
", *q);

    return 0;
}

程式結果

i = 10 j = 20 *p = 20 *q = 20

程式說明

第 1 題不一定要執行程式才能判斷，核心是看左右兩邊型態是否相容。p 和 q 是位址；*p 和 *q 是整數值。

五、第 2 題：追蹤 *q = *p 與 *p = 1

題目

閱讀程式，判斷螢幕會輸出什麼，並說明原因。

完整程式

practice06_2_annotated.c
/*
 * 檔名：practice06_2_annotated.c
 * 主題：指標與變數位址
 * 功能：示範指標 p、q 分別指向 i、j 後，透過 *p、*q 間接修改變數內容。
 */
#include <stdio.h>  /* 匯入標準輸入輸出函式庫，提供 printf() 函式。 */

int main(void)  /* 程式進入點；void 表示 main 不接收命令列參數。 */
{
    int i, j, *p, *q;  /* 宣告整數 i、j；宣告整數指標 p、q，用來存放 int 變數的位址。 */

    i = 5;      /* 將 i 設為 5。 */
    j = 6;      /* 將 j 設為 6。 */
    p = &i;     /* &i 取得 i 的位址，讓 p 指向 i。 */
    q = &j;     /* &j 取得 j 的位址，讓 q 指向 j。 */

    *q = *p;    /* *p 代表 i 的值 5；*q 代表 j，因此這行會把 j 改成 5。 */
    *p = 1;     /* *p 代表 i，因此這行會把 i 改成 1；不會影響 j。 */

    printf("i = %d\n", i);    /* 輸出 i 的目前值，結果為 1。 */
    printf("j = %d\n", j);    /* 輸出 j 的目前值，結果為 5。 */
    printf("*p = %d\n", *p);  /* p 指向 i，所以 *p 等於 i 的值 1。 */
    printf("*q = %d\n", *q);  /* q 指向 j，所以 *q 等於 j 的值 5。 */

    return 0;   /* 回傳 0 表示程式正常結束。 */
}

程式結果

i = 1 j = 5 *p = 1 *q = 5

程式說明

  1. p=&i，所以 *p 是 i。
  2. q=&j，所以 *q 是 j。
  3. *q=*p 把 i 的值 5 複製給 j，因此 j 變成 5。
  4. *p=1 把 i 改成 1，因此最後 i=1、j=5。

六、第 3 題：swap(int *p, int *q)

題目

撰寫函式 void swap(int *p, int *q);。傳入兩個變數位址後，交換這兩個變數的值。

完整程式

practice06_3_annotated.c
/*
 * 檔名：practice06_3_annotated.c
 * 主題：使用指標進行 swap 交換
 * 功能：透過傳入兩個變數的位址，讓函式可以直接修改 main 裡的 i 與 j。
 */
#include <stdio.h>  /* 匯入標準輸入輸出函式庫，提供 printf()。 */

void swap(int *p, int *q)  /* swap 接收兩個 int 指標，也就是兩個整數變數的位址。 */
{
    int temp;  /* 暫存變數，用來保存其中一個值，避免交換過程資料遺失。 */

    temp = *p; /* 先把 p 指向的值，也就是第一個變數的值，存到 temp。 */
    *p = *q;   /* 把 q 指向的值放到 p 指向的位置。 */
    *q = temp; /* 把原本 p 指向的舊值放到 q 指向的位置，完成交換。 */
}

int main(void)  /* 主程式進入點。 */
{
    int i = 10; /* 宣告整數 i 並初始化為 10。 */
    int j = 20; /* 宣告整數 j 並初始化為 20。 */

    printf("Before swap: i = %d, j = %d\n", i, j); /* 顯示交換前的 i、j。 */

    swap(&i, &j); /* 傳入 i 與 j 的位址，讓 swap 可以修改原本的變數。 */

    printf("After swap: i = %d, j = %d\n", i, j);  /* 顯示交換後的 i、j。 */

    return 0; /* 正常結束程式。 */
}

程式結果

Before swap: i = 10, j = 20 After swap: i = 20, j = 10

程式說明

若函式寫成 swap(int p, int q)，只會交換副本；這題使用 int *p 和 int *q，函式拿到的是 main 裡 i、j 的位址，因此可以透過 *p、*q 修改原變數。

七、第 4 題：split_time(long total_sec, int *hr, int *min, int *sec)

題目

撰寫函式，把從午夜開始算起的總秒數轉換成小時、分鐘、秒，並用三個指標回傳結果。

完整程式

practice06_4_annotated.c
/*
 * 檔名：practice06_4_annotated.c
 * 主題：用指標回傳多個結果
 * 功能：把總秒數轉換成「時：分：秒」，並透過 hr、min、sec 三個指標回傳結果。
 */
#include <stdio.h>  /* 提供 printf() 與 scanf()。 */

void split_time(long total_sec, int *hr, int *min, int *sec) /* 將總秒數拆成小時、分鐘、秒。 */
{
    *hr = total_sec / 3600;      /* 1 小時 = 3600 秒；計算完整的小時數並寫入 *hr。 */
    total_sec = total_sec % 3600;/* 取除以 3600 後的餘數，留下不足 1 小時的秒數。 */

    *min = total_sec / 60;       /* 1 分鐘 = 60 秒；計算完整分鐘數並寫入 *min。 */
    *sec = total_sec % 60;       /* 剩下不足 1 分鐘的秒數寫入 *sec。 */
}

int main(void) /* 主程式。 */
{
    long total_sec;     /* 儲存使用者輸入的總秒數；long 可容納較大的秒數。 */
    int hr, min, sec;   /* 儲存轉換後的小時、分鐘、秒。 */

    printf("Enter total seconds: "); /* 提示使用者輸入總秒數。 */
    scanf("%ld", &total_sec);        /* 讀入 long 型態資料，必須傳入 total_sec 的位址。 */

    split_time(total_sec, &hr, &min, &sec); /* 傳入 hr、min、sec 位址，讓函式寫回結果。 */

    printf("%02d:%02d:%02d\n", hr, min, sec); /* 以兩位數格式輸出，例如 01:05:09。 */

    return 0; /* 正常結束。 */
}

程式結果

Input: 3661 Output: Enter total seconds: 01:01:01

程式說明

步驟計算結果
小時3661 / 36001
剩餘秒數3661 % 360061
分鐘61 / 601
秒61 % 601

因為 C 函式一次只能直接 return 一個值，所以這題用 hr、min、sec 三個指標把三個結果寫回 main。

八、第 5 題：find_two_largest

題目

撰寫函式 void find_two_largest(int a[], int n, int *largest, int *second_largest);，找出陣列最大值與第二大值，並透過指標回傳。

完整程式

practice06_5_annotated.c
/*
 * 檔名：practice06_5_annotated.c
 * 主題：陣列與指標輸出參數
 * 功能：找出陣列中最大值與第二大值，並用指標把結果回傳給 main。
 */
#include <stdio.h>  /* 提供 printf()。 */

void find_two_largest(int a[], int n, int *largest, int *second_largest) /* 找最大與第二大。 */
{
    int i; /* 迴圈索引。 */

    if (a[0] > a[1]) /* 先比較前兩個元素，建立初始最大值與第二大值。 */
    {
        *largest = a[0];        /* 若 a[0] 較大，最大值設為 a[0]。 */
        *second_largest = a[1]; /* 第二大值設為 a[1]。 */
    }
    else
    {
        *largest = a[1];        /* 若 a[1] 較大或相等，最大值設為 a[1]。 */
        *second_largest = a[0]; /* 第二大值設為 a[0]。 */
    }

    for (i = 2; i < n; i++) /* 從第三個元素開始逐一檢查。 */
    {
        if (a[i] > *largest) /* 若目前元素比最大值還大。 */
        {
            *second_largest = *largest; /* 原本最大值退到第二大。 */
            *largest = a[i];            /* 目前元素成為新的最大值。 */
        }
        else if (a[i] > *second_largest) /* 若沒有超過最大值，但超過第二大。 */
        {
            *second_largest = a[i];      /* 更新第二大值。 */
        }
    }
}

int main(void) /* 主程式。 */
{
    int a[] = {10, 5, 30, 20, 40, 15}; /* 測試用整數陣列。 */
    int largest, second_largest;       /* 儲存最大值與第二大值。 */
    int n = sizeof(a) / sizeof(a[0]);  /* 計算陣列元素個數。 */

    find_two_largest(a, n, &largest, &second_largest); /* 傳入結果變數位址。 */

    printf("Largest = %d\n", largest);               /* 輸出最大值。 */
    printf("Second largest = %d\n", second_largest); /* 輸出第二大值。 */

    return 0; /* 正常結束。 */
}

程式結果

Largest = 40 Second largest = 30

程式說明

  1. 先用前兩個元素建立最大值與第二大值。
  2. 從第三個元素開始掃描。
  3. 若目前元素大於最大值，原本最大值退到第二大，目前元素變成最大值。
  4. 若目前元素沒有超過最大值，但超過第二大，就只更新第二大。

這題同時練習陣列與指標輸出參數，是 Practice 06 最重要的應用題之一。
