二、Amdahl’s Law：多核心加速的限制

核心觀念 Amdahl’s Law 用來估計加入更多 processing cores 後，程式可以得到多少 speedup。重點是：程式不可能每一段都平行化，serial portion 會限制最大加速效果。

Amdahl’s Law

speedup ≤ 1 / ( S + (1 − S) / N )

S 代表 serial portion，N 代表 processing cores。當 N 增加時，平行部分可以變快，但 S 仍然存在。

S

序列部分

只能一步一步執行，不能被多核心分工。

1−S

平行部分

可以切給多個核心同時處理。

N

核心數

核心越多，平行部分越快，但整體不會無限加速。

Add Cores

三、為什麼 serial portion 影響很大？

投影片中的例子是：如果應用程式 75% 可以平行、25% 必須序列執行，從 1 個核心增加到 2 個核心時，speedup 約為 1.6 倍，而不是 2 倍。

理想想法

核心數變成 2 倍，速度也變成 2 倍。

實際情況

只有平行部分能分工，序列部分仍然要排隊執行，因此速度提升受限。

考試或報告可以這樣說：Amdahl’s Law 告訴我們，多核心效能提升不是只看核心數，也要看程式中有多少比例可以平行化。

四、CPU-I/O Burst Cycle

核心觀念 Process execution 不是一直使用 CPU。它通常會先進行一段 CPU burst，接著等待 I/O burst，然後再回到 CPU burst，如此反覆循環。

Process Execution Cycle

CPU burst：計算、load、store
I/O burst：等待讀檔或寫檔
CPU burst：繼續執行
I/O burst：再次等待
⇄

排程意義

當某個 process 進入 I/O wait，CPU 不應該空著，可以切給 ready queue 中其他 process 使用，以提高 CPU utilization。

一、程式題目講解

用 Amdahl’s Law 計算多核心平行化後的理論加速比。

核心觀念是可平行化比例 P 與核心數 N：不是所有程式都能完全平行化，所以加速比會受到非平行部分限制。

二、完整程式碼

以下程式碼可直接複製到 C 語言線上編譯器執行。程式中已加入中文註解，說明主要變數、判斷流程與輸出目的。

#include <stdio.h>

/*
  主題 13：Amdahl's Law
  功能：計算理論加速比 Speedup = 1 / ((1-P) + P/N)
*/

int main(void) {
    double P = 0.80;   // 可平行化比例
    int N = 4;         // 核心數
    double speedup;

    speedup = 1.0 / ((1.0 - P) + P / N);

    printf("Parallel Portion P = %.2f\n", P);
    printf("Number of Cores N = %d\n", N);
    printf("Speedup = %.2f\n", speedup);

    return 0;
}
