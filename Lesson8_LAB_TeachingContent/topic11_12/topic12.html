投影片 45｜Parallelism vs Concurrency

（一）這張投影片在說什麼？

這張比較 parallelism 與 concurrency。Parallelism 是同一時間真的有多個工作同時執行；concurrency 是系統能處理多個工作進行中，但不一定同時在不同核心上執行。

（二）核心觀念

  • Concurrency：多工作交錯推進。
  • Parallelism：多工作同時執行。

（三）學習與考試重點

單核心可有 concurrency；多核心才容易有真正 parallelism。

一句話記憶：單核心可有 concurrency；多核心才容易有真正 parallelism。

一、程式題目講解

用分段加總模擬多執行緒把工作切開，再把結果合併。

重點是工作分割與結果合併：Thread 1 負責前半段資料，Thread 2 負責後半段資料，最後相加。

二、完整程式碼

以下程式碼可直接複製到 C 語言線上編譯器執行。程式中已加入中文註解，說明主要變數、判斷流程與輸出目的。

#include <stdio.h>

/*
  主題 12：多執行緒概念
  功能：用分段加總模擬多執行緒的工作分割與合併。
*/

int main(void) {
    int data[] = {1,2,3,4,5,6,7,8};
    int sum1 = 0, sum2 = 0;
    int i;

    for (i = 0; i < 4; i++) sum1 += data[i];      // Thread 1 的工作
    for (i = 4; i < 8; i++) sum2 += data[i];      // Thread 2 的工作

    printf("Thread 1 partial sum = %d\n", sum1);
    printf("Thread 2 partial sum = %d\n", sum2);
    printf("Total sum = %d\n", sum1 + sum2);

    return 0;
}
