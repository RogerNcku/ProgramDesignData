二、Monoprogramming：單一程式記憶體管理

核心觀念 在 Monoprogramming 中，記憶體大部分只保留給作業系統與一個正在執行的 program。當這個程式執行時，其他程式不能同時留在記憶體中一起執行。

優點

概念簡單，管理容易，適合早期或非常簡化的系統。

缺點

CPU 利用率可能很低。如果程式等待 I/O，CPU 可能會空等，無法有效利用系統資源。

三、Multiprogramming：多程式記憶體管理

Multiprogramming 中，記憶體同時放入多個 program。只要其中一個程式因為 I/O 等原因暫停，CPU 就可以切換到另一個程式，提升 CPU 使用率。

一、程式題目講解

示範多個程式共享主記憶體時，OS 如何根據剩餘容量決定是否載入。

重點是 remain 剩餘記憶體與多程式配置：程式可載入時扣除容量，否則等待。

二、完整程式碼

以下程式碼可直接複製到 C 語言線上編譯器執行。程式中已加入中文註解，說明主要變數、判斷流程與輸出目的。

#include <stdio.h>

/*
  主題 6：單一程式與多程式記憶體管理
  功能：示範多程式如何共享主記憶體。
*/

int main(void) {
    int memory = 120;
    int programSize[] = {40, 35, 60, 20};
    int remain = memory;
    int i;

    for (i = 0; i < 4; i++) {
        printf("Program %d 需要 %d MB：", i + 1, programSize[i]);
        if (programSize[i] <= remain) {
            remain -= programSize[i];
            printf("載入成功，剩餘 %d MB\n", remain);
        } else {
            printf("空間不足，暫時等待。\n");
        }
    }
    return 0;
}

Program 3 需要 60 MB：空間不足，暫時等待。
Program 4 需要 20 MB：載入成功，剩餘 25 MB

結果說明：重點是 remain 剩餘記憶體與多程式配置：程式可載入時扣除容量，否則等待。 程式依照設定的資料與控制流程逐步輸出，因此可以從結果看到每個步驟的執行順序與狀態變化。
