Sorting and Searching Using Binary Search Tree

Binary Search Tree 不只可以拿來插入與刪除資料，也可以用來排序與搜尋。排序的重點是 inorder traversal；搜尋的重點是每次比較後只往左子樹或右子樹走。

（一）這張投影片在說什麼？

這張投影片說明 BST 可以用來排序。先把資料逐一插入 BST，再做 inorder traversal，就會得到由小到大的結果。

（二）核心觀念

  • 插入時建立左小右大的結構。
  • Inorder 順序是 left-root-right。
  • 因此輸出會由小到大。
  • 這就是 tree sort 的基本想法。

（三）學習與考試重點

BST sort 的效率取決於樹的高度；平衡時較快，歪斜時可能退化。

一句話記憶：BST + inorder = sorted order。
投影片 29：使用 BST 搜尋
投影片 29：使用 BST 搜尋

（一）這張投影片在說什麼？

這張投影片說明 BST 搜尋不需要檢查所有節點。每次只比較目前節點的 key，然後決定往左或往右。

（二）核心觀念

  • 目標等於目前節點：找到。
  • 目標較小：往左子樹。
  • 目標較大：往右子樹。
  • 走到 NULL：代表找不到。

（三）學習與考試重點

搜尋時間是 O(h)，h 是樹高；不是固定 O(log n)，除非樹保持平衡。

一句話記憶：BST 搜尋每一步都丟掉一邊。

（一）這張投影片在說什麼？

這張投影片把 BST search 寫成演算法或程式流程。從 root 開始，用 while 或 recursive function 不斷比較 key，直到找到或遇到空指標。

（二）核心觀念

  • current pointer 初始為 root。
  • while current != NULL 時持續比較。
  • 小於 current 就 current = left。
  • 大於 current 就 current = right。

（三）學習與考試重點

程式要注意 NULL 判斷，否則在找不到資料時會存取空指標造成錯誤。

一句話記憶：比較、移動、再比較；直到找到或 NULL。

（一）這張投影片在說什麼？

這張投影片用具體數字示範 BST 搜尋。搜尋 8 時會根據大小比較一路走到目標；搜尋 1 時如果走到空位置仍沒找到，就回傳失敗。

  • 路徑長度與 tree height 有關。

找不到不是錯誤，而是走到應該存在的位置卻沒有節點。

一句話記憶：找到節點就成功；走到空位就失敗。

投影片 33：字母 BST 範例

（一）這張投影片在說什麼？

這張投影片把 BST 的 key 換成字母。字母同樣可以比較大小，通常依照字典序或 ASCII/字元順序建立搜尋樹。

（二）核心觀念

  • BST 不只可存整數，也可存可比較的 key。
  • 字母依照排序規則決定左右。
  • 小於目前字母往左，大於目前字母往右。
  • 資料型態不同，但搜尋邏輯相同。

（三）學習與考試重點

BST 的核心要求是 key 可以比較大小，不限於數字。

一句話記憶：只要 key 能比大小，就能放進 BST。

六、C 程式碼：BST 排序與搜尋

bst_sort_search.c
/*
  中文註解版程式：bst_sort_search.c
  說明：主題 9：BST Sorting and Searching。利用 inorder traversal 得到排序結果，並示範搜尋路徑。
  閱讀方式：先看資料結構定義，再看操作函式，最後看 main() 如何測試。
*/

// 匯入標準輸入輸出函式庫，提供 printf / scanf 等功能。
#include <stdio.h>
// 匯入標準函式庫，提供 malloc / free / exit 等記憶體與程式控制功能。
#include <stdlib.h>

// 定義節點結構：資料欄位存節點內容，指標欄位負責連到其他節點。
typedef struct Node {
    int key;
    struct Node *left;
    struct Node *right;
} Node;

// 建立新節點：配置記憶體、填入資料，並把左右指標初始化為 NULL。
Node* createNode(int key) {
    Node* node = (Node*)malloc(sizeof(Node));
    if (node == NULL) {
        printf("Memory allocation failed.\n");
        exit(1);
    }
    node->key = key;
    node->left = NULL;
    node->right = NULL;
    return node;
}

// BST 插入：比目前節點小往左，大往右；空位置就是新節點位置。
Node* insert(Node* root, int key) {
    if (root == NULL) return createNode(key);  // 空位置就是插入點
    if (key < root->key) root->left = insert(root->left, key);
    else if (key > root->key) root->right = insert(root->right, key);
    return root;
}

// BST 搜尋：從 root 開始比較，小往左、大往右，走到 NULL 表示找不到。
Node* search(Node* root, int key) {
    Node* current = root;
    while (current != NULL) {
        printf("Compare with %d\n", current->key);
        if (key == current->key) return current;
        if (key < current->key) current = current->left;
        else current = current->right;
    }
    return NULL;
}

// Inorder 走訪：Left → Visit → Right；套用在 BST 會得到由小到大的排序。
void inorder(Node* root) {
    if (root == NULL) return;  // 遞迴終止條件：空節點不需要處理
    inorder(root->left);   // 先走左子樹
    printf("%d ", root->key);  // 再拜訪目前節點
    inorder(root->right);  // 最後走右子樹
}

// 釋放整棵樹：先釋放左右子樹，再釋放目前節點，避免記憶體洩漏。
void freeTree(Node* root) {
    if (root == NULL) return;  // 遞迴終止條件：空節點不需要處理
    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

// 主程式：建立測試資料，呼叫上方函式，觀察輸出結果。
int main(void) {
    int data[] = {7, 14, 10, 8, 16, 9, 3, 2, 4, 1};
    int n = sizeof(data) / sizeof(data[0]);
    Node* root = NULL;

    for (int i = 0; i < n; i++) {
        root = insert(root, data[i]);
    }

    printf("BST sort by inorder traversal:\n");
    inorder(root);
    printf("\n\n");

    int targets[] = {8, 1, 15};
    for (int i = 0; i < 3; i++) {
        printf("Search %d:\n", targets[i]);
        Node* result = search(root, targets[i]);
        if (result != NULL) printf("Found %d.\n\n", targets[i]);
        else printf("%d NOT FOUND.\n\n", targets[i]);
    }

    freeTree(root);
    return 0;
}
