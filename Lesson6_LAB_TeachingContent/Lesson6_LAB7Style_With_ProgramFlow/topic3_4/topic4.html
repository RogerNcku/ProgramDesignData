投影片 12：Array 中 parent / child 公式
投影片 12：Array 中 parent / child 公式

（一）這張投影片在說什麼？

這張投影片整理 array representation 的索引公式。若某節點位置為 i，parent 在 floor(i/2)，left child 在 2i，right child 在 2i+1。

（二）核心觀念

  • parent(i) = floor(i/2)，i=1 時沒有 parent。
  • leftChild(i) = 2i，若 2i > n 則不存在。
  • rightChild(i) = 2i+1，若 2i+1 > n 則不存在。
  • 這些公式建立在 index 從 1 開始的表示法。

（三）學習與考試重點

考試很常直接問 index 之間的 parent-child 關係，記得先確認陣列是否從 1 開始。

一句話記憶：父親除以 2，左小孩乘 2，右小孩乘 2 再加 1。
投影片 13：不平衡樹使用 Array 的空間浪費
投影片 13：不平衡樹用 array 可能浪費空間

（一）這張投影片在說什麼？

這張投影片用 skewed tree 和 complete tree 對比，說明 array representation 對不完整二元樹可能很浪費空間。

（二）核心觀念

  • Complete tree 的節點位置緊密，array 很有效率。
  • Skewed tree 會留下大量空陣列位置。
  • 樹越不平衡，array 表示越可能浪費。
  • 此時 linked representation 較彈性。

（三）學習與考試重點

選資料結構時要看樹的形狀。若樹不是 complete，array 的位置公式雖然存在，但空間成本可能太高。

一句話記憶：樹越歪，陣列越浪費。

投影片 14：Binary tree node 的結構

（一）這張投影片在說什麼？

這張投影片介紹 linked representation 的節點設計。每個 TreeNode 通常包含 data、leftChild、rightChild 三個欄位。

（二）核心觀念

  • data 儲存節點資料。
  • leftChild 指向左子節點。
  • rightChild 指向右子節點。
  • 沒有子節點時指標為 NULL 或 0。

（三）學習與考試重點

這是二元樹程式實作的核心結構。後面的 traversal、BST、heap 概念若用 linked tree 都會用到這種 node。

一句話記憶：一個二元樹節點 = data + 左指標 + 右指標。
投影片 15：Linked Representation 範例
投影片 15：Linked Representation 範例

（一）這張投影片在說什麼？

這張投影片把實際二元樹畫成節點與指標。Root 指向第一個節點，每個節點再分別連到 leftChild 與 rightChild。

（二）核心觀念

  • root 是整棵 linked tree 的入口。
  • 每個 node 用指標連到左右子樹。
  • NULL 表示該方向沒有子節點。
  • Linked representation 適合不完整或動態變化的樹。

（三）學習與考試重點

插入與刪除時，真正改變的是指標連結，不是把整棵樹搬來搬去。

一句話記憶：Linked tree 靠指標找到下一個節點。

二、Array Representation 陣列表示法

Array representation 是把二元樹依照層級順序放進陣列。投影片通常讓 index 0 空著，從 index 1 開始放 root，這樣 parent 與 child 的位置可以用簡單公式計算。

位置公式

Parent：index i 的 parent 在 floor(i / 2)

Left child：index i 的左孩子在 2i

Right child：index i 的右孩子在 2i + 1

適合情況

Array representation 特別適合 complete binary tree 或 heap，因為節點排列很緊密，不需要存 left/right pointer。

三、Array Representation 的優點與缺點

優點：容易實作

因為 parent 和 child 都能用 index 算出來，所以不需要額外儲存指標。對 heap 這種 complete binary tree 很方便。

優點：存取規則固定

節點位置按照 level order 放入陣列，規則明確，適合快速找 parent 或 child。

缺點：不平衡時浪費空間

投影片 13 顯示，如果樹很歪或節點分布不連續，中間會出現很多空格，陣列中必須保留不存在的節點位置，造成記憶體浪費。

缺點：插入與刪除不一定方便

若不是 complete binary tree，節點位置可能跳很遠，插入與刪除時要維持位置關係，處理起來會較麻煩。

簡單判斷：如果樹很完整、很接近滿的形狀，用 array 通常很適合；如果樹很歪、很稀疏，用 array 可能浪費很多空間。

Linked representation 是讓每個節點自己保存三個部分：data、left child pointer、right child pointer。投影片 14 的 node structure 就是這個觀念。

如果某個節點沒有左孩子，left child pointer 就是空；如果沒有右孩子，right child pointer 就是空。這種方式不需要為不存在的節點保留陣列位置，因此很適合一般形狀、不規則或不平衡的二元樹。
