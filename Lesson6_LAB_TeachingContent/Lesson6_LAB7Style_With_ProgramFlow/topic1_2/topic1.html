（一）這張投影片在說什麼？

這張投影片正式定義 tree：一棵樹由一個 root 加上零個或多個互不重疊的 subtrees 組成。每一個 subtree 本身也還是一棵 tree。

（二）核心觀念

  • Tree 的定義具有 recursive 性質。
  • root 是整棵樹的起點。
  • 扣掉 root 後，剩下的部分可以分成多棵互不相交的子樹。

（三）學習與考試重點

因為 tree 本身是遞迴定義，所以很多 tree 演算法也會用遞迴處理，例如 traversal、search、height 計算。

一句話記憶：Tree = root + subtrees；subtree 仍然是 tree。
投影片 4：Terminology：node、root、degree、leaf
投影片 4：Terminology

（一）這張投影片在說什麼？

這張投影片介紹樹的基本術語。Node 是資料單位，root 是最上面的節點，degree 是一個節點有幾棵子樹，leaf 是 degree 為 0 的節點。

（二）核心觀念

  • Node：樹中的一個資料單位。
  • Root：沒有 parent 的最上層節點。
  • Degree：節點的子樹數量。
  • Leaf：沒有孩子的節點，也稱 terminal node。

（三）學習與考試重點

考題常要求你根據圖判斷某節點的 degree、哪些是 leaf、哪些是 nonterminal node。

一句話記憶：沒有小孩就是 leaf；有幾個小孩，degree 就是多少。

投影片 5：Terminology 補充

（一）這張投影片在說什麼？

這張投影片補充更多關係名詞。Children 是某節點直接往下連的節點，parent 是其上一層節點，siblings 是同一個 parent 的節點，ancestors 是從 root 到該節點路徑上的上層節點。

（二）核心觀念

  • Parent/Children 是直接上下層關係。
  • Siblings 是同父節點的平行關係。
  • Ancestors 是一路往上追溯到 root 的節點。
  • Level 表示節點所在層數，height/depth 表示樹的最大層數。

（三）學習與考試重點

要注意有些課本把 root level 定為 0，有些定為 1；本投影片採用 root level = 1 的表示。

一句話記憶：往上是 ancestor，往下是 descendant，同層同父是 sibling。

一、Tree 是什麼？

核心概念

Tree 可以翻成「樹」或「樹狀結構」。它不是一般線性的資料排列，而是一種有上下層關係的階層式結構。投影片用組織圖當例子：最上面是 President，下面分成不同 Vice-President，再往下分成 Manager。這種「一個上層節點往下分出多個下層節點」的形式，就是樹的基本樣子。

Root根節點
→
Subtrees多個子樹
→
Nodes節點彼此連結

從定義來看，一棵樹是由有限個節點組成，而且一定有一個特別指定的節點叫做 root。root 以外的節點會被分成若干個互不重疊的集合，每一個集合本身也可以看成一棵樹，所以 tree 的定義具有遞迴性。

三、重要術語完整說明

Node 節點：樹中的每一個資料單位都叫做 node。投影片中的 A、B、C、D、E、F 都是節點。

Root 根節點：位於最上方的節點，是整棵樹的起點。沒有 parent。

Degree 分支度：一個節點有幾棵子樹，它的 degree 就是多少。例如 A 有 B、C 兩個孩子，degree 就是 2；D 沒有孩子，degree 是 0。

Leaf 葉節點：degree 為 0 的節點，也就是沒有任何孩子的節點。

Height 高度：從 root 到 leaf 的最長路徑長度。投影片說明 height 會和最長路徑上的節點數有關。

Parent / Children：如果某節點下面接出其他節點，這個節點就是 parent；下面被接出的節點就是 children。

Siblings 兄弟節點：具有相同 parent 的節點。例如 B 和 C 若都由 A 連出，它們就是 siblings。

Ancestors 祖先節點：從 root 到某節點路徑上經過的所有上層節點。

Descendants 後代節點：某節點底下所有子樹中的節點，都可以視為它的 descendants。

五、Trees 的應用

投影片列出 Trees 的應用包含：computer systems directory structures、decision trees、game trees。這些例子共同點是「資料本身具有層級或分支選擇」。

Directory Structure 目錄結構

電腦資料夾常常是一層包一層，例如根目錄底下有多個資料夾，每個資料夾底下又有檔案或子資料夾。

Decision Tree 決策樹

從一個問題開始，依照不同答案往不同方向走，最後得到結果。很適合表示分類與判斷流程。

Game Tree 遊戲樹

每一步棋或每個選項都會產生新的可能狀態，因此可以用樹來表示所有可能發展。

主題 1 程式流程圖：Tree 基本概念判斷流程

流程講解

  1. 先找出整棵樹的 root，因為所有 parent、child、subtree 的判斷都從 root 開始。
  2. 再依照節點之間的上下層關係建立 parent 與 children。
  3. 沒有 child 的節點標記為 leaf，有 child 的節點標記為 internal node。
  4. 最後計算 degree、level、height，讓程式能用數字描述 tree 結構。
