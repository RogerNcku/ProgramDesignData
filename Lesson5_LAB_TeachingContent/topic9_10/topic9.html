一、主題核心概念

Doubly Linked List 的每個節點包含 llink、data、rlink。llink 指向前一個節點，rlink 指向下一個節點，讓串列可以雙向走訪。

Doubly Linked List 雙向鏈結串列基本概念

詳細說明與講解

1、這張投影片介紹 Doubly Linked List。它的每個節點除了 data 之外，還有兩個 link：一個指向前一個節點，另一個指向下一個節點。

2、相較於 Singly Linked List，雙向鏈結串列可以往前也可以往後走，因此刪除某個節點時比較方便，不一定需要從 head 開始找前一個節點。

3、投影片提到單向鏈結串列刪除效率不高，是因為要刪除節點時常常需要知道前一個節點。雙向串列透過 left link 或 prev link 解決這個問題。

4、代價是每個節點需要多存一個 pointer，因此空間成本比單向鏈結串列高，而且插入刪除時要更新的 pointer 數量也比較多。

一句話記憶：Doubly Linked List 用 prev 與 next 支援雙向移動。

Doubly Linked List 的結構與 Head Node

詳細說明與講解

1、這張投影片展示雙向鏈結串列的圖形結構。每個節點左右都有箭頭，左箭頭指回前一個節點，右箭頭指向下一個節點。

2、圖中也出現 head node 或 header node 的概念。Header node 可以作為固定的起點，讓空串列、頭端插入、尾端刪除等情況比較容易處理。

3、在雙向串列中，若使用 header node，常可以避免很多 if-else 特殊判斷，因為即使沒有真正資料節點，也仍然有一個 head 作為連結基準。

4、學這張時要確認自己看得懂兩種方向：從左到右是 next，從右到左是 prev。任何一個方向接錯，都可能讓串列一邊能走、另一邊壞掉。

一句話記憶：Header node 是用來簡化雙向串列邊界情況的假節點。

一、程式題目講解

本題示範雙向鏈結串列的基本建立與往前、往後連接概念。學生需要理解每個節點同時保存 prev 與 next，因此可以記錄前一個與下一個節點。

二、完整程式碼

以下為本頁程式題目的完整可執行 C 程式碼，已在重要程式區塊加入中文註解，方便初學者理解程式功能與流程。

#include <stdio.h>
#include <stdlib.h>

/*
    Doubly Linked List
    每個節點都有 prev 與 next，因此可以往前也可以往後走。
*/

typedef struct DNode {
    int data;
    struct DNode *prev;
    struct DNode *next;
} DNode;

DNode* createNode(int data) {
    DNode *n = (DNode*)malloc(sizeof(DNode));
    if (!n) exit(1);
    n->data = data;
    n->prev = NULL;
    n->next = NULL;
    return n;
}

void insertEnd(DNode **head, int data) {
    DNode *newNode = createNode(data);
    if (*head == NULL) { *head = newNode; return; }
    DNode *tail = *head;
    while (tail->next != NULL) tail = tail->next;
    tail->next = newNode;
    newNode->prev = tail;
}

void printForward(DNode *head) {
    while (head != NULL) {
        printf("%d <-> ", head->data);
        head = head->next;
    }
    printf("NULL\n");
}

int main(void) {
    DNode *head = NULL;
    insertEnd(&head, 10);
    insertEnd(&head, 20);
    insertEnd(&head, 30);
    printForward(head);
    return 0;
}

三、程式執行結果

程式執行後會得到以下輸出：

10 <-> 20 <-> 30 <-> NULL

程式依序在尾端插入 10、20、30。每次新增節點時，原本尾端的 next 指向新節點，新節點的 prev 指回原本尾端。printForward 從 head 往 next 方向輸出，所以得到 10 <-> 20 <-> 30 <-> NULL。

五、重要函數與語法說明

  1. DNode：雙向鏈結串列節點。
  2. prev：指向前一個節點。
  3. next：指向下一個節點。
  4. insertEnd：把節點加入尾端並維護雙向連結。
  5. printForward：由前往後輸出雙向串列。

六、整體說明

本題重點是雙向連結。和單向串列相比，雙向串列多了 prev，因此刪除或反向走訪更方便，但插入與刪除時也必須同時維護兩個方向的指標。

流程講解

  1. 雙向鏈結串列的節點比單向多一個 prev 指標。
  2. next 指向後一個節點，prev 指向前一個節點。
  3. 建立節點時要同時初始化 prev 與 next，通常先設為 NULL。
  4. 往前或往後走訪都可以，因此刪除某個節點時更方便。
  5. 但每次插入或刪除，都要注意兩邊指標是否同步更新。
