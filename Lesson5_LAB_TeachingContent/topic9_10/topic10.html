一、主題核心概念

雙向鏈結串列插入與刪除時，必須同時處理 llink 與 rlink。插入新節點要讓新節點接前後，也要讓前後節點接回新節點；刪除則讓前後節點直接互相連接。

投影片 21

Insertion in Doubly Linked List 雙向串列插入

詳細說明與講解

1、這張投影片說明在雙向鏈結串列中插入一個新節點。因為每個節點有 left link 與 right link，所以插入時要更新四個連結。

2、假設要把 node 插入 current 前面或某兩個節點中間，必須先讓 node 的左連結接到前一個節點，node 的右連結接到 current。

3、接著要讓前一個節點的右連結指向 node，並讓 current 的左連結指向 node。這樣左右兩個方向才都能正常走訪。

4、投影片列出的步驟可以當作寫程式的順序參考。雙向串列比單向串列更容易回頭找節點，但插入時 pointer 更新較多，順序更要小心。

一句話記憶：雙向串列插入通常要改四條 link。
投影片 22｜Deletion in Doubly Linked List 雙向串列刪除
投影片 22

Deletion in Doubly Linked List 雙向串列刪除

詳細說明與講解

1、這張投影片說明雙向鏈結串列的刪除。刪除 node 時，要讓 node 左邊的節點直接接到 node 右邊的節點，並且兩個方向都要接好。

2、核心操作通常是 node.left.link = node.link，以及 node.link.left = node.left。意思是左邊節點的 next 跳過 node，右邊節點的 prev 也跳過 node。

3、和單向串列相比，雙向串列刪除時不一定需要額外保存 previous，因為 node 本身就有 left 或 prev 可以找到前一個節點。

4、不過如果刪除的是特殊位置，例如第一個資料節點、最後一個資料節點或空串列，仍然要依照是否有 header node 或 NULL 來處理。

一句話記憶：雙向串列刪除要讓左右鄰居互相接起來。

（一）本主題要學會什麼？

雙向鏈結串列插入與刪除時，必須同時處理 llink 與 rlink。插入新節點要讓新節點接前後，也要讓前後節點接回新節點；刪除則讓前後節點直接互相連接。

（二）實作時最重要的觀念

資料結構
先看清楚資料是用 Array、Node、Singly List、Circular List 或 Doubly List 表示。
指標方向
Linked List 題目幾乎都在考指標怎麼接、怎麼斷、怎麼重新連起來。
特殊情況
空串列、頭節點、尾節點、找不到資料，都是程式容易錯的地方。

一、程式題目講解

本題示範雙向鏈結串列的插入與刪除。學生需要理解插入時要接好左右兩邊指標，刪除時要讓被刪節點的前後節點重新連接。

二、完整程式碼

以下為本頁程式題目的完整可執行 C 程式碼，已在重要程式區塊加入中文註解，方便初學者理解程式功能與流程。

#include <stdio.h>
#include <stdlib.h>

/*
    Doubly Linked List：插入與刪除
    插入要接四條線；刪除要讓前後節點互相接回。
*/

typedef struct DNode {
    int data;
    struct DNode *llink; // 左指標：前一個節點
    struct DNode *rlink; // 右指標：下一個節點
} DNode;

DNode* createNode(int data) {
    DNode *n = (DNode*)malloc(sizeof(DNode));
    if (!n) exit(1);
    n->data = data;
    n->llink = NULL;
    n->rlink = NULL;
    return n;
}

void insertAfter(DNode *A, int data) {
    DNode *B = createNode(data);
    DNode *C = A->rlink;

    B->rlink = C;     // B 接右邊 C
    B->llink = A;     // B 接左邊 A
    A->rlink = B;     // A 接到 B
    if (C != NULL) C->llink = B; // C 接回 B
}

void deleteNode(DNode **head, DNode *node) {
    if (node == NULL) return;
    if (node->llink != NULL) node->llink->rlink = node->rlink;
    else *head = node->rlink; // 刪除第一個節點
    if (node->rlink != NULL) node->rlink->llink = node->llink;
    free(node);
}

void printList(DNode *head) {
    while (head) { printf("%d <-> ", head->data); head = head->rlink; }
    printf("NULL\n");
}

int main(void) {
    DNode *A = createNode(10);
    DNode *C = createNode(30);
    A->rlink = C;
    C->llink = A;

    insertAfter(A, 20); // 插入 B=20
    printList(A);
    deleteNode(&A, A->rlink); // 刪除 20
    printList(A);
    return 0;
}

三、程式執行結果

程式執行後會得到以下輸出：

10 <-> 20 <-> 30 <-> NULL
10 <-> 30 <-> NULL

程式先建立 10 與 30，再用 insertAfter(A, 20) 把 20 插到 10 後面，所以第一次輸出為 10 <-> 20 <-> 30 <-> NULL。接著 deleteNode 刪除 20，10 的 rlink 改接 30，30 的 llink 改接 10，所以第二次輸出為 10 <-> 30 <-> NULL。

流程先建立 A 與 C 並形成 10 <-> 30。插入 B 時，B 的 rlink 接 C、llink 接 A，A 的 rlink 接 B，C 的 llink 接 B。刪除時則把 node 左邊的 rlink 接到 node 右邊，並把右邊的 llink 接回左邊，最後 free node。

五、重要函數與語法說明

  1. insertAfter(DNode *A, int data)：在指定節點 A 後插入新節點。
  2. llink：指向左邊或前一個節點。
  3. rlink：指向右邊或下一個節點。
  4. deleteNode：刪除指定節點並重新連接左右指標。
  5. if (node->llink != NULL)：判斷被刪除節點是否為第一個節點。

六、整體說明

本題重點是雙向串列操作要同時處理兩個方向。插入通常要改四條線，刪除則要讓左右節點越過被刪除節點重新接起來。

流程講解

  1. 雙向串列插入時，新節點必須同時接住前方與後方。
  2. 先設定 newNode->prev 與 newNode->next，再更新相鄰節點。
  3. 刪除時要讓前一個節點的 next 指向後一個節點。
  4. 同時也要讓後一個節點的 prev 指回前一個節點。
  5. 如果刪除的是 head 或 tail，要另外更新 head 或 tail 指標。
