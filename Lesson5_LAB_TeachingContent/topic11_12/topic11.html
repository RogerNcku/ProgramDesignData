list.c：Node 結構與 createNode

詳細說明與講解

1、這張投影片進入 C 語言實作。程式使用 struct Node 定義節點，通常包含 int data 與 struct Node* next，分別代表資料與下一個節點位置。

2、createNode 函式的工作是配置一個新節點，將輸入資料放入 data，並把 next 初始化為 NULL。初始化 next 很重要，因為新節點剛建立時還沒有接到任何節點後面。

3、程式中使用 malloc 配置記憶體時，要確認是否成功。如果 malloc 回傳 NULL，代表配置失敗，程式應該處理錯誤而不是繼續使用。

4、這張投影片是所有後續 insert、delete、print 的基礎。只要 Node 結構定義錯，後面的串列操作都會受影響。

一句話記憶：Node 保存 data 與 next，createNode 負責建立並初始化節點。

insert 函式：排序插入節點

詳細說明與講解

1、這張投影片展示 insert 函式。它會把 newData 放入新節點，並依照資料大小把節點插入到正確位置，讓串列保持排序。

2、程式會先檢查 head 是否為 NULL，若串列是空的，新節點直接成為 head。若 newData 比 head 的 data 還小，也可能需要插在最前面，並更新 head。

3、若要插入中間位置，程式通常用 curr 走訪串列，尋找第一個大於或等於 newData 的位置，同時用 prev 記錄前一個節點。

4、找到位置後，newNode->next 指向 curr，prev->next 指向 newNode。這樣就完成排序插入，而且不需要搬移其他節點資料。

一句話記憶：排序插入要找到位置，再用 prev 與 curr 把新節點接進去。

一、程式題目講解

本題聚焦 list.c 中 Node 建立與排序插入 insert 函式。學生需要理解 createNode 如何負責記憶體配置，insert 如何透過 prev 與 curr 找到正確插入位置。

二、完整程式碼

以下為本頁程式題目的完整可執行 C 程式碼，已在重要程式區塊加入中文註解，方便初學者理解程式功能與流程。

#include <stdio.h>
#include <stdlib.h>

/*
    Sorted Singly Linked List
    功能：插入資料時，自動保持由小到大的順序。
*/

typedef struct Node {
    int data;
    struct Node *next;
} Node;

Node* createNode(int data) {
    Node *newNode = (Node*)malloc(sizeof(Node));
    if (newNode == NULL) {
        printf("malloc 失敗\n");
        exit(1);
    }
    newNode->data = data;
    newNode->next = NULL;
    return newNode;
}

void insert(Node **head, int data) {
    Node *newNode = createNode(data);
    Node *curr = *head;
    Node *prev = NULL;

    // 找到第一個大於等於 data 的節點位置
    while (curr != NULL && curr->data < data) {
        prev = curr;
        curr = curr->next;
    }

    // 插在最前面或空串列
    if (prev == NULL) {
        newNode->next = *head;
        *head = newNode;
    } else {
        newNode->next = curr;
        prev->next = newNode;
    }
}

void printList(Node *head) {
    Node *temp = head;
    while (temp != NULL) {
        printf("%d -> ", temp->data);
        temp = temp->next;
    }
    printf("NULL\n");
}

int main(void) {
    Node *head = NULL;
    insert(&head, 30);
    insert(&head, 10);
    insert(&head, 20);
    insert(&head, 5);
    printList(head); // 5 -> 10 -> 20 -> 30 -> NULL
    return 0;
}

三、程式執行結果

程式執行後會得到以下輸出：

5 -> 10 -> 20 -> 30 -> NULL

程式插入 30、10、20、5。每次插入前都會比較目前節點資料，找到第一個大於等於新資料的位置後插入。因此最後串列會自動排序成 5 -> 10 -> 20 -> 30 -> NULL。

流程講解
