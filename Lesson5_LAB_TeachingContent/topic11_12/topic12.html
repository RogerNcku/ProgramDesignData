delete 函式：刪除指定資料

詳細說明與講解

1、這張投影片展示 delete 函式。它會從 head 開始尋找 delData，找到後把該節點從串列中移除。

2、程式通常先處理空串列，若 head == NULL 就代表沒有資料可刪。接著使用 curr 指向目前節點，prev 指向前一個節點，一邊走訪一邊比較 data。

3、如果 curr->data 等於 delData，就依照 prev 是否為 NULL 判斷是否刪除 head。若 prev == NULL，表示目標在第一個節點，head 要改成 curr->next；否則 prev->next 改成 curr->next。

4、刪除後應該釋放 curr 的記憶體，避免 memory leak。若走到 curr == NULL 還沒找到，表示資料不存在，串列保持不變。

一句話記憶：delete 用 curr 找目標，用 prev 重新接指標。

一、程式題目講解

二、完整程式碼

以下為本頁程式題目的完整可執行 C 程式碼，已在重要程式區塊加入中文註解，方便初學者理解程式功能與流程。

#include <stdio.h>
#include <stdlib.h>

/*
    Delete、Print 與 main 測試流程
    功能：排序插入、刪除指定資料、列印串列。
*/

typedef struct Node {
    int data;
    struct Node *next;
} Node;

Node* createNode(int data) {
    Node *n = (Node*)malloc(sizeof(Node));
    if (!n) exit(1);
    n->data = data;
    n->next = NULL;
    return n;
}

void insert(Node **head, int data) {
    Node *newNode = createNode(data);
    Node *curr = *head, *prev = NULL;
    while (curr != NULL && curr->data < data) {
        prev = curr;
        curr = curr->next;
    }
    if (prev == NULL) {
        newNode->next = *head;
        *head = newNode;
    } else {
        newNode->next = curr;
        prev->next = newNode;
    }
}

void deleteData(Node **head, int delData) {
    Node *curr = *head, *prev = NULL;
    while (curr != NULL && curr->data != delData) {
        prev = curr;
        curr = curr->next;
    }
    if (curr == NULL) {
        printf("%d 不在串列中\n", delData);
        return;
    }
    if (prev == NULL) *head = curr->next;
    else prev->next = curr->next;
    free(curr);
}

void printList(Node *head) {
    if (head == NULL) { printf("Empty\n"); return; }
    while (head != NULL) {
        printf("%d ", head->data);
        head = head->next;
    }
    printf("\n");
}

int main(void) {
    Node *head = NULL;
    insert(&head, 30);
    insert(&head, 10);
    insert(&head, 20);
    printf("插入後："); printList(head);
    deleteData(&head, 20);
    printf("刪除 20 後："); printList(head);
    deleteData(&head, 99);
    return 0;
}

五、重要函數與語法說明

  1. deleteData：刪除指定資料節點。
  2. curr == NULL：判斷資料不存在。
  3. prev == NULL：判斷刪除的是頭節點。
  4. free(curr)：釋放已刪除節點記憶體。
  5. printList：檢查每次操作後串列內容是否正確。

流程講解

  1. main 先建立測試資料，方便觀察 delete 前後的變化。
  2. print 函式負責逐一印出串列內容，是除錯最重要的輔助工具。
