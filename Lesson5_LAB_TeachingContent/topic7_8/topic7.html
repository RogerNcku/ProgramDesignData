一、主題核心概念

多項式相加可以視為兩條已排序 linked list 的合併。若兩項 exponent 相同，就把 coefficient 相加；若 exponent 不同，就先複製 exponent 較大的項目到結果 C(x)。

詳細說明與講解

1、這張投影片開始示範多項式相加。每個節點代表一個項目，通常包含係數與指數，例如 9x^20、-1x^10 或 -12x^0。

2、多項式相加的基本規則是：指數相同的項才能合併，係數相加；指數不同的項不能合併，只能照順序放入結果多項式。

3、圖中 A(x)、B(x)、C(x) 分別代表兩個輸入多項式與相加結果。操作時會同時比較 A 與 B 目前節點的 exponent，決定要合併、取 A 的項，或取 B 的項。

4、這個流程很像 merge。因為兩條 Linked List 已經依照 exponent 排好，所以只要從前往後掃描一次，就可以產生結果。

一句話記憶：多項式相加就是依 exponent 合併兩條有序串列。

Adding Polynomials：多項式相加（二）

詳細說明與講解

1、這張投影片延續多項式相加，展示比較與合併過程中的中間狀態。當 A 與 B 的目前項指數相同時，就把係數相加並放入 C。

2、如果係數相加後變成 0，通常不需要把該項放入結果，因為多項式表示法只保存非零項。這點對節省空間很重要。

3、若某一邊的指數較大，代表那一項目前沒有對應項可以合併，就直接複製到 C，然後該串列的指標往下一個節點移動。

4、這張圖的學習重點是 current pointer 的移動：合併時兩邊都移動；只複製 A 時 A 移動；只複製 B 時 B 移動。

一句話記憶：指數相同就合併，不同就複製指數較大的那一項。

1、這張投影片展示多項式相加接近完成時的結果。當其中一條串列已經走完，另一條串列剩下的項目就可以直接接到結果後面。

一句話記憶：一邊走完後，另一邊剩下的項直接接到結果。

五、完整中文講解

（一）本主題要學會什麼？

多項式相加可以視為兩條已排序 linked list 的合併。若兩項 exponent 相同，就把 coefficient 相加；若 exponent 不同，就先複製 exponent 較大的項目到結果 C(x)。

（二）實作時最重要的觀念

資料結構
先看清楚資料是用 Array、Node、Singly List、Circular List 或 Doubly List 表示。
指標方向
Linked List 題目幾乎都在考指標怎麼接、怎麼斷、怎麼重新連起來。
特殊情況
空串列、頭節點、尾節點、找不到資料，都是程式容易錯的地方。
測試方式
每做完 insert/delete，都用 print 檢查目前串列是否符合預期。
多項式相加的想法很像 merge two sorted lists。排序依據不是係數大小，而是指數 exponent 的大小。

一、程式題目講解

本題示範用 Linked List 進行多項式相加。學生需要理解兩個已排序多項式可以用雙指標同時走訪，依照 exponent 大小決定要合併或直接保留項目。

二、完整程式碼

以下為本頁程式題目的完整可執行 C 程式碼，已在重要程式區塊加入中文註解，方便初學者理解程式功能與流程。

#include <stdio.h>
#include <stdlib.h>

/*
    Adding Polynomials：用 Linked List 做多項式相加
    假設兩個多項式都已經依 exponent 由大到小排序。
*/

typedef struct Term {
    int coef;
    int exp;
    struct Term *next;
} Term;

Term* createTerm(int coef, int exp) {
    Term *t = (Term*)malloc(sizeof(Term));
    if (!t) exit(1);
    t->coef = coef;
    t->exp = exp;
    t->next = NULL;
    return t;
}

void appendTerm(Term **poly, int coef, int exp) {
    if (coef == 0) return;
    Term *newTerm = createTerm(coef, exp);
    if (*poly == NULL) { *poly = newTerm; return; }
    Term *p = *poly;
    while (p->next) p = p->next;
    p->next = newTerm;
}

Term* addPoly(Term *A, Term *B) {
    Term *C = NULL;
    while (A != NULL && B != NULL) {
        if (A->exp == B->exp) {
            appendTerm(&C, A->coef + B->coef, A->exp);
            A = A->next;
            B = B->next;
        } else if (A->exp > B->exp) {
            appendTerm(&C, A->coef, A->exp);
            A = A->next;
        } else {
            appendTerm(&C, B->coef, B->exp);
            B = B->next;
        }
    }
    while (A != NULL) { appendTerm(&C, A->coef, A->exp); A = A->next; }
    while (B != NULL) { appendTerm(&C, B->coef, B->exp); B = B->next; }
    return C;
}

void printPoly(Term *p) {
    if (!p) { printf("0\n"); return; }
    while (p) {
        printf("%dx^%d", p->coef, p->exp);
        if (p->next) printf(" + ");
        p = p->next;
    }
    printf("\n");
}

int main(void) {
    Term *A = NULL, *B = NULL;
    appendTerm(&A, 9, 20); appendTerm(&A, -1, 10); appendTerm(&A, 12, 0);
    appendTerm(&B, 3, 10); appendTerm(&B, -7, 2); appendTerm(&B, 2, 1); appendTerm(&B, -1, 0);
    Term *C = addPoly(A, B);
    printf("A(x) = "); printPoly(A);
    printf("B(x) = "); printPoly(B);
    printf("C(x) = "); printPoly(C);
    return 0;
}

三、程式執行結果

程式執行後會得到以下輸出：

A(x) = 9x^20 + -1x^10 + 12x^0
B(x) = 3x^10 + -7x^2 + 2x^1 + -1x^0
C(x) = 9x^20 + 2x^10 + -7x^2 + 2x^1 + 11x^0

A 與 B 都依照指數由大到小排列。addPoly 比較 A 與 B 的 exp：相同指數就係數相加，不同指數則保留指數較大的那一項。-1x^10 與 3x^10 合併成 2x^10，12x^0 與 -1x^0 合併成 11x^0，所以 C(x) 會得到輸出中的結果。

流程先建立 A、B 兩個多項式，再讓 addPoly 同時比較兩條串列。若指數相同就合併係數；若 A 的指數較大，先放 A 的項；若 B 的指數較大，先放 B 的項。最後把剩餘項目接到結果 C。

五、重要函數與語法說明

  1. addPoly(Term *A, Term *B)：多項式相加的主函式。
  2. appendTerm：將結果項目加入 C 多項式。
  3. A->exp == B->exp：判斷同類項。
  4. while (A != NULL && B != NULL)：同時走訪兩個多項式。
  5. if (coef == 0) return：避免把係數為 0 的項放入結果。

六、整體說明

本題核心是同類項合併。只要兩個多項式已經排序，就能像合併兩條有序串列一樣完成相加，這也是 Linked List 在資料合併問題中的典型應用。

流程講解

  1. 兩個多項式都用 termArray 表示，因此可以像 merge 一樣從前往後比較。
  2. 若兩邊 exponent 相同，就把 coefficient 相加。
  3. 若相加結果不是 0，才加入結果多項式。
  4. 若 exponent 不同，先複製 exponent 較大的那一項。
  5. 其中一邊掃完後，再把另一邊剩下的項目全部接到結果後面。
