一、主題核心概念

Circularly Linked List 和一般單向鏈結串列最大的差別是尾端不指向 NULL，而是指回 head。它適合循環處理，例如排程、輪流執行或遊戲角色輪替。

Circularly Linked List 環狀鏈結串列

詳細說明與講解

1、這張投影片介紹 Circularly Linked List。它和一般單向鏈結串列最大的不同是：最後一個節點不是指向 NULL，而是指回第一個節點。

2、因為最後節點會連回 head，所以整條串列形成一個環。這種結構適合需要循環處理的問題，例如輪流排程、循環播放、遊戲中的輪流回合等。

3、走訪環狀串列時不能用 current != NULL 作為停止條件，因為永遠不會遇到 NULL。通常要記住起點，走回起點時就停止。

4、插入與刪除時，也要特別注意最後節點的 link 必須維持指向 head，否則環狀結構會被破壞。

一句話記憶：Circular List 的尾端不是 NULL，而是接回開頭。

（一）本主題要學會什麼？

資料結構

一、程式題目講解

本題示範環狀鏈結串列。學生需要理解環狀串列的最後一個節點不指向 NULL，而是指回 head，因此走訪時不能用 NULL 當停止條件。

二、完整程式碼

以下為本頁程式題目的完整可執行 C 程式碼，已在重要程式區塊加入中文註解，方便初學者理解程式功能與流程。

#include <stdio.h>
#include <stdlib.h>

/*
    Circularly Linked List
    重點：最後一個節點的 next 不是 NULL，而是指回 head。
*/

typedef struct Node {
    int data;
    struct Node *next;
} Node;

Node* createNode(int data) {
    Node *n = (Node*)malloc(sizeof(Node));
    if (!n) exit(1);
    n->data = data;
    n->next = NULL;
    return n;
}

void insertEnd(Node **head, int data) {
    Node *newNode = createNode(data);
    if (*head == NULL) {
        *head = newNode;
        newNode->next = newNode; // 單一節點時，自己指回自己
        return;
    }
    Node *tail = *head;
    while (tail->next != *head) tail = tail->next;
    tail->next = newNode;
    newNode->next = *head; // 尾端指回 head
}

void printOneRound(Node *head) {
    if (head == NULL) return;
    Node *p = head;
    do {
        printf("%d -> ", p->data);
        p = p->next;
    } while (p != head); // 回到 head 代表走完一圈
    printf("回到 head\n");
}

int main(void) {
    Node *head = NULL;
    insertEnd(&head, 10);
    insertEnd(&head, 20);
    insertEnd(&head, 30);
    printOneRound(head);
    return 0;
}

三、程式執行結果

程式執行後會得到以下輸出：

10 -> 20 -> 30 -> 回到 head

程式依序在尾端插入 10、20、30。insertEnd 會讓最後一個節點的 next 指回 head，因此 printOneRound 從 head 出發，印完 30 後會回到 head，輸出最後用「回到 head」表示已走完一圈。

流程先建立空串列。第一個節點建立後讓 newNode->next 指向自己。後續插入時，先找到目前尾端，也就是 tail->next == head 的節點，再讓 tail 指向新節點，新節點指回 head。輸出使用 do-while，確保至少印出一次並在回到 head 時停止。

五、重要函數與語法說明

  1. insertEnd：將新節點加入環狀串列尾端。
  2. tail->next != *head：尋找環狀串列尾端。
  3. newNode->next = newNode：單一節點時自己形成一個環。
  4. do-while：適合至少要執行一次的環狀走訪。
  5. p != head：用是否回到起點判斷一圈結束。

六、整體說明

本題重點是停止條件改變。一般單向串列走到 NULL 停止，但環狀串列沒有 NULL 尾端，因此要用「是否回到 head」判斷是否完成一圈。

流程講解

  1. 環狀鏈結串列的最後一個節點不指向 NULL，而是指回第一個節點。
  2. 如果串列是空的，新節點的 next 要指向自己。
  3. 如果串列非空，新節點要插入既有環狀連線中。
  4. 常用 last 指標管理環狀串列，因為 last->next 就是 head。
  5. 走訪時不能用 current != NULL 當停止條件，而要判斷是否回到起點。
