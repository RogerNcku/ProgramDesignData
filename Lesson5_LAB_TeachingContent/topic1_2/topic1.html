一、主題核心概念

Linked List 是用節點 node 與指標 pointer 把資料串起來的資料結構。和 Array 不同，Linked List 的資料不需要放在連續記憶體位置，因此更適合資料量會變動、插入與刪除頻繁的情境。

詳細說明與講解

1、這張投影片是本單元的封面，表示 Lesson 5 的主題是 Linked Lists，也就是鏈結串列。它提醒我們這一章會從 Array 的限制開始，逐步進入單向鏈結串列、環狀鏈結串列、雙向鏈結串列，以及用 C 程式實作節點操作。

2、Linked List 的核心觀念是：資料不一定要連續放在記憶體中，而是每一筆資料用一個節點保存，再利用 pointer 把節點一個一個串起來。這和 Array 最大的差異，就是 Array 依靠連續位置與 index，而 Linked List 依靠節點之間的連結。

3、學這章時不要只背名詞，要特別注意圖上的箭頭方向。每一個箭頭都代表一個 pointer 欄位，例如 next、link、prev 或 right link。只要箭頭接錯，串列就會斷掉，或造成節點遺失。

4、考試或作業常見重點是：能不能畫出插入、刪除前後的節點變化；能不能分辨 head、current、previous 的角色；能不能寫出基本的 insert、delete、print 程式。

一句話記憶：Linked List 是用 pointer 把一個個節點串起來的動態資料結構。

一、程式題目講解

本題透過建立三個節點，讓學生理解 Linked List 不是用連續記憶體保存資料，而是靠每個節點的 next 指標連接下一個節點。核心概念包含 struct 節點、malloc 動態配置、head 入口指標，以及從 head 開始走訪到 NULL 的方式。

二、完整程式碼

以下為本頁程式題目的完整可執行 C 程式碼，已在重要程式區塊加入中文註解，方便初學者理解程式功能與流程。

#include <stdio.h>
#include <stdlib.h>

/*
    Lesson 5：Linked List 基本節點示範
    功能：建立三個節點，並用 next pointer 串成一條 linked list。
*/

typedef struct Node {
    int data;              // data：節點中保存的資料
    struct Node *next;     // next：指向下一個節點的指標
} Node;

Node* createNode(int value) {
    Node *newNode = (Node*)malloc(sizeof(Node));
    if (newNode == NULL) {
        printf("記憶體配置失敗\n");
        exit(1);
    }
    newNode->data = value; // 設定資料
    newNode->next = NULL;  // 一開始還沒有接到下一個節點
    return newNode;
}

void printList(Node *head) {
    Node *current = head;  // 從 head 開始走訪
    while (current != NULL) {
        printf("%d -> ", current->data);
        current = current->next;
    }
    printf("NULL\n");
}

int main(void) {
    Node *head = createNode(10);
    head->next = createNode(20);
    head->next->next = createNode(30);

    printf("Linked List 內容：");
    printList(head);
    return 0;
}

三、程式執行結果

程式執行後會得到以下輸出：

Linked List 內容：10 -> 20 -> 30 -> NULL

程式先建立 10、20、30 三個節點，並用 head->next 與 head->next->next 串接起來。printList 從 head 開始依序輸出節點資料，走到最後一個節點後遇到 NULL，因此結果會顯示 10 -> 20 -> 30 -> NULL。

流程先宣告 head，再呼叫 createNode 建立第一個節點，接著用 next 指標連接第二與第三個節點。輸出時 current 從 head 出發，每印出一個 data 就移動到下一個節點，直到 current 等於 NULL 才停止。

五、重要函數與語法說明

  1. typedef struct Node：定義節點格式，包含 data 與 next。
  2. malloc(sizeof(Node))：在執行期間配置一個節點大小的記憶體。
  3. createNode(value)：建立新節點並初始化 data 與 next。
  4. printList(head)：從 head 開始走訪串列並輸出內容。
  5. while (current != NULL)：控制走訪流程，確保走到串列尾端才停止。

六、整體說明

本題重點是理解 Linked List 的基本組成：head 是入口，Node 保存資料，next 負責連接下一個節點。只要掌握「節點建立、指標連接、走訪輸出」三個步驟，就能看懂後續插入、刪除與進階串列操作。

流程講解

  1. 程式先宣告 head 作為整條 linked list 的入口。
  2. 每次建立節點時使用 malloc 配置記憶體，並把 data 放入節點。
  3. 新節點的 next 先設定為 NULL，避免指標指到不確定的位置。
  4. 透過 head->next、next->next 把節點串起來。
  5. 最後從 head 開始用 while 走訪，直到 current == NULL 為止。
