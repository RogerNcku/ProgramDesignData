一、主題核心概念

Array 的大小通常在建立時就決定，若要在中間插入或刪除資料，後面的元素常常必須搬移。List 則是一種 dynamic structure，可以隨資料增減改變長度。

Array 的限制：插入與刪除成本

詳細說明與講解

1、這張投影片說明使用 Array 儲存資料時的主要缺點。Array 的大小在建立時通常已經固定，若資料量超過原本容量，就不能直接增加空間；此外，如果要在中間插入或刪除資料，後面的元素常常都必須搬移。

2、左邊的插入例子中，若要把新資料 Gina 插入到中間位置，原本在後面的元素必須往後移，才有空位可以放入 Gina。這代表插入不是只放一筆資料，而是可能牽動後面很多筆資料。

3、右邊的刪除例子中，若刪除中間某筆資料，後面的元素又必須往前補位，否則 Array 中間會留下空洞。這也是為什麼 Array 在中間插入與中間刪除時，時間成本通常是 O(n)。

4、這張圖是導入 Linked List 的理由：如果資料經常需要插入與刪除，Array 的搬移成本會很高，因此需要一種更彈性的結構，也就是 List 或 Linked List。

一句話記憶：Array 查詢快，但中間插入與刪除常常要搬移資料。
投影片 3｜List 的基本概念：動態大小與節點結構
投影片 3

List 的基本概念：動態大小與節點結構

詳細說明與講解

1、這張投影片介紹 List 的基本定義。List 是一種 dynamic structure，也就是它的大小可以隨著資料增加或刪除而改變，不像 Array 一開始就固定容量。

2、投影片中把 List 描述成由 nodes 組成。每個 node 通常包含兩個部分：一個是 data，用來保存真正的資料；另一個是 pointer 或 link，用來指出下一個節點在哪裡。

3、Head 是非常重要的起點，它指向串列的第一個節點。程式要走訪整個 List 時，通常從 head 開始，沿著每個節點的 next pointer 一直往後走。

4、最後一個節點的 pointer 通常指向 NIL 或 NULL，表示後面沒有下一個節點。這個 NULL 是走訪串列的停止條件，若忘記判斷 NULL，就可能造成程式錯誤。

一句話記憶：List 用 head 找到第一個節點，再靠 pointer 一路走到 NULL。

List 的操作與應用

詳細說明與講解

1、這張投影片整理 List 常見操作，包括 Add、Insert、Delete、Search 等。Add 通常是把新節點加到串列尾端；Insert 是插入到指定位置；Delete 是刪除某個節點；Search 是沿著串列尋找指定資料。

2、投影片中特別提到 Insert 和 Delete 時，指標的順序很重要。插入節點不是移動資料，而是改變節點之間的連結；刪除節點也不是把資料往前搬，而是讓前一個節點跳過目標節點。

3、下方圖示中的 free space 與 file 可以幫助理解 List 的用途。List 常被用來管理資料集合、記憶體空間、檔案區塊或其他需要動態增減的項目。

4、學習這張時要記得：List 的優點不是所有操作都比 Array 快，而是在資料需要頻繁插入、刪除或大小不固定時更彈性。

一句話記憶：List 操作的本質是改 pointer，不是搬資料。

一、程式題目講解

本題用 Linked List 程式對照 Array 的限制，讓學生了解資料不一定要放在連續位置，也可以透過節點與指標動態連接。核心概念是動態配置節點、用 next 串接資料，以及走訪串列輸出內容。

二、完整程式碼

以下為本頁程式題目的完整可執行 C 程式碼，已在重要程式區塊加入中文註解，方便初學者理解程式功能與流程。

#include <stdio.h>
#include <stdlib.h>

/*
    Lesson 5：Linked List 基本節點示範
    功能：建立三個節點，並用 next pointer 串成一條 linked list。
*/

typedef struct Node {
    int data;              // data：節點中保存的資料
    struct Node *next;     // next：指向下一個節點的指標
} Node;

Node* createNode(int value) {
    Node *newNode = (Node*)malloc(sizeof(Node));
    if (newNode == NULL) {
        printf("記憶體配置失敗\n");
        exit(1);
    }
    newNode->data = value; // 設定資料
    newNode->next = NULL;  // 一開始還沒有接到下一個節點
    return newNode;
}

void printList(Node *head) {
    Node *current = head;  // 從 head 開始走訪
    while (current != NULL) {
        printf("%d -> ", current->data);
        current = current->next;
    }
    printf("NULL\n");
}

int main(void) {
    Node *head = createNode(10);
    head->next = createNode(20);
    head->next->next = createNode(30);

    printf("Linked List 內容：");
    printList(head);
    return 0;
}

三、程式執行結果

程式執行後會得到以下輸出：

Linked List 內容：10 -> 20 -> 30 -> NULL

程式建立三個節點 10、20、30，再用 next 指標把節點接成一條串列。因為 printList 會從第一個節點一路走到 NULL，所以輸出結果會依照連接順序顯示 10、20、30。

  1. struct Node：表示一個串列節點。
