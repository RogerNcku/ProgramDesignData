詳細說明與講解

1、這張投影片說明如何用資料結構表示多項式。多項式可以用 Array 表示，也可以用 Linked List 表示，兩者適合的情況不同。

2、若使用 Array，通常用指數當作 index，係數放在對應位置。這種方法查詢特定次方的係數很直接，但如果多項式很稀疏，例如只有少數幾項非零，會浪費大量空間。

3、若使用 Linked List，每個節點可以保存一個非零項，例如 coefficient 與 exponent。這樣只儲存真正出現的項，對稀疏多項式比較節省空間。

4、圖中 A(x)、B(x) 同時用 Array 與 Linked List 表示，目的是讓學生比較：Array 是固定位置表示法，Linked List 是逐項串接表示法。

一句話記憶：稀疏多項式適合用 Linked List 儲存非零項。

一、程式題目講解

本題示範用 Linked List 表示多項式。學生需要理解一個節點可以代表一個非零項，節點中保存係數 coef、指數 exp 與下一項 next。

二、完整程式碼

以下為本頁程式題目的完整可執行 C 程式碼，已在重要程式區塊加入中文註解，方便初學者理解程式功能與流程。

#include <stdio.h>
#include <stdlib.h>

/*
    Polynomial Representation：用 Linked List 表示多項式
    每一個節點代表一個非零項：coef * x^exp
*/

typedef struct Term {
    int coef;              // 係數 coefficient
    int exp;               // 指數 exponent
    struct Term *next;     // 下一個非零項
} Term;

Term* createTerm(int coef, int exp) {
    Term *t = (Term*)malloc(sizeof(Term));
    if (!t) exit(1);
    t->coef = coef;
    t->exp = exp;
    t->next = NULL;
    return t;
}

void appendTerm(Term **poly, int coef, int exp) {
    if (coef == 0) return; // 係數為 0 的項通常不存
    Term *newTerm = createTerm(coef, exp);
    if (*poly == NULL) {
        *poly = newTerm;
        return;
    }
    Term *p = *poly;
    while (p->next != NULL) p = p->next;
    p->next = newTerm;
}

void printPoly(Term *poly) {
    while (poly != NULL) {
        printf("%dx^%d", poly->coef, poly->exp);
        if (poly->next != NULL) printf(" + ");
        poly = poly->next;
    }
    printf("\n");
}

int main(void) {
    Term *A = NULL;
    appendTerm(&A, 9, 20);
    appendTerm(&A, -1, 10);
    appendTerm(&A, 12, 0);
    printf("A(x) = ");
    printPoly(A);
    return 0;
}

三、程式執行結果

程式執行後會得到以下輸出：

A(x) = 9x^20 + -1x^10 + 12x^0

程式建立多項式 A(x)，依序加入 9x^20、-1x^10、12x^0 三個非零項。printPoly 依照節點順序輸出每一項，所以結果顯示 A(x) = 9x^20 + -1x^10 + 12x^0。

五、重要函數與語法說明

  1. typedef struct Term：定義多項式項目節點。
  2. coef：保存係數。
  3. exp：保存指數。
  4. appendTerm：把新的非零項加到多項式尾端。
  5. printPoly：依序輸出多項式每一項。

六、整體說明

本題讓學生知道 Linked List 不只可以存一般數字，也可以存複合資料。多項式只需要保存非零項，因此用鏈結串列比固定陣列更節省空間。

流程講解

  1. 多項式可用一個一個 term 表示，每個 term 包含係數 coef 與指數 exp。
  2. 程式讀入非零項後，依序存入 termArray。

  4. 輸出時逐項顯示，例如 3x^2、2x、-4。
  5. 這種表示法適合 sparse polynomial，因為只儲存非零項。
