一、主題核心概念

這個主題把 linked list 概念轉成程式。重點是用一個管理者保存 head，再讓每個 node 保存 data 與 next，透過 insert、delete、print 完成操作。

詳細說明與講解

1、這張投影片開始把前面的圖轉成程式。可以看到類別或結構中通常會有 head，代表串列開頭；也會有內部節點類別或 struct，用來表示每一個節點。

2、節點中通常包含 data 與 next。data 保存資料，next 指向下一個節點。對 Linked List 來說，真正重要的不是單一節點，而是每個節點之間透過 next 串起來的關係。

3、右側的 toString 或 print 類似走訪函式。它從 head 開始，用 current 一個節點一個節點往後走，把每個節點的資料串成輸出結果。

4、這張投影片的學習重點是把概念圖和程式變數對起來：head 是入口，current 是走訪用指標，current.next 或 current->next 是前進到下一個節點的動作。

一句話記憶：程式中的 head、current、next 對應到圖上的起點、目前節點與箭頭。

Insert 程式邏輯：插入新節點

詳細說明與講解

1、這張投影片展示 insert 函式的核心流程。程式會先建立一個新節點 node，並把要插入的資料放進 node 的 data 欄位。

2、若串列是空的，head == null，代表目前沒有任何節點，因此新節點會直接成為 head。這是插入時最基本的特殊情況。

3、若不是空串列，程式會用 current 與 prev 或類似變數尋找插入位置。找到位置後，必須把新節點插到 prev 與 current 中間。

4、最容易錯的是 pointer 更新順序。通常要先讓新節點指向 current，再讓 prev 指向新節點。這樣才不會弄丟 current 後面的串列。

一句話記憶：Insert 要先處理空串列，再處理中間插入的 pointer 順序。
投影片 11｜Delete 程式邏輯：尋找並刪除資料
投影片 11

Delete 程式邏輯：尋找並刪除資料

詳細說明與講解

1、這張投影片接續說明 delete 函式。刪除時通常從 head 開始找目標資料，並使用 current 代表目前檢查的節點，prev 代表 current 的前一個節點。

2、如果 head 是 null，表示串列是空的，程式不能繼續存取 head 的內容，應該直接輸出空串列或停止操作。

3、若找到目標資料，要分成刪除 head 與刪除非 head 兩種情況。刪除 head 時，head 要改成 head->next；刪除中間或尾端時，prev->next 要改成 current->next。

4、若走到 current == null 還沒找到資料，代表目標不在串列中，這時串列不應該被改變。

一句話記憶：Delete 需要 current 找目標，也需要 prev 重新接回串列。

一、程式題目講解

本題實作排序單向鏈結串列。學生需要理解如何在插入資料時尋找正確位置，使串列永遠維持由小到大的順序。

二、完整程式碼

以下為本頁程式題目的完整可執行 C 程式碼，已在重要程式區塊加入中文註解，方便初學者理解程式功能與流程。

#include <stdio.h>
#include <stdlib.h>

/*
    Sorted Singly Linked List
    功能：插入資料時，自動保持由小到大的順序。
*/

typedef struct Node {
    int data;
    struct Node *next;
} Node;

Node* createNode(int data) {
    Node *newNode = (Node*)malloc(sizeof(Node));
    if (newNode == NULL) {
        printf("malloc 失敗\n");
        exit(1);
    }
    newNode->data = data;
    newNode->next = NULL;
    return newNode;
}

void insert(Node **head, int data) {
    Node *newNode = createNode(data);
    Node *curr = *head;
    Node *prev = NULL;

    // 找到第一個大於等於 data 的節點位置
    while (curr != NULL && curr->data < data) {
        prev = curr;
        curr = curr->next;
    }

    // 插在最前面或空串列
    if (prev == NULL) {
        newNode->next = *head;
        *head = newNode;
    } else {
        newNode->next = curr;
        prev->next = newNode;
    }
}

void printList(Node *head) {
    Node *temp = head;
    while (temp != NULL) {
        printf("%d -> ", temp->data);
        temp = temp->next;
    }
    printf("NULL\n");
}

int main(void) {
    Node *head = NULL;
    insert(&head, 30);
    insert(&head, 10);
    insert(&head, 20);
    insert(&head, 5);
    printList(head); // 5 -> 10 -> 20 -> 30 -> NULL
    return 0;
}

三、程式執行結果

程式執行後會得到以下輸出：

5 -> 10 -> 20 -> 30 -> NULL

main 依序插入 30、10、20、5。insert 會用 curr 與 prev 找到第一個大於等於新資料的位置，再把新節點插入該位置之前。因此雖然插入順序不是排序好的，最後輸出仍是 5 -> 10 -> 20 -> 30 -> NULL。

流程先建立新節點，再從 head 開始比較。只要 curr 還沒走到 NULL 且 curr->data 小於新資料，就繼續往後移動。找到位置後，如果 prev 是 NULL，代表插在頭部；否則讓新節點接 curr，prev 接新節點。

五、重要函數與語法說明

  1. createNode(data)：建立並初始化新節點。
  2. insert(Node **head, int data)：依照大小排序插入節點。
  3. while (curr != NULL && curr->data < data)：尋找插入位置。
  4. Node **head：讓函式可以修改 main 裡面的 head。
  5. printList：檢查排序插入是否正確。

六、整體說明

本題重點是排序插入。學生要分清楚 prev、curr、newNode 的角色：curr 找位置，prev 記住前一個節點，newNode 是準備插入的資料。
