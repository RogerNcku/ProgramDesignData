一、主題核心概念

單向鏈結串列插入與刪除的核心不是搬動資料，而是重新接 pointer。插入時把新節點接進兩個節點之間；刪除時讓前一個節點跳過目標節點。

投影片 6

從單向鏈結串列刪除節點

詳細說明與講解

1、這張投影片用圖示說明如何從 Singly Linked List 中刪除一個節點。刪除的重點不是把節點內容擦掉，而是讓前一個節點的 pointer 改指向被刪節點的下一個節點。

2、圖中 old pointer 指向被刪除節點前面的節點，deleted entry 是要被刪除的節點。刪除後，old pointer 的 next 會改成指向 deleted entry 的 next，這樣串列就會跳過被刪除的節點。

3、這裡必須注意順序：在釋放或丟掉被刪節點之前，要先保存它後面的節點位置。否則一旦失去指標，就可能找不到後面的串列，造成資料遺失。

4、若刪除的是 head 節點，情況會不同，因為沒有前一個節點可以幫忙跳過它。這時要直接把 head 改成 head->next。

一句話記憶：刪除節點就是讓前一個節點跳過它。
投影片 7｜在單向鏈結串列中插入節點
投影片 7

在單向鏈結串列中插入節點

詳細說明與講解

1、這張投影片說明如何把新節點插入 Singly Linked List 的中間。插入時通常需要知道插入位置前面的節點，因為要把新節點接在它後面。

2、操作順序非常重要。第一步應該讓新節點的 next 指向原本的下一個節點；第二步才讓前一個節點的 next 指向新節點。若順序反過來，原本後面的節點可能會失去連結。

3、圖中可以看到 new entry 被插入到 old pointer 後面，原本 old pointer 指向的下一個節點被保留下來，並改由 new entry 連過去。

4、這張是 Linked List 程式設計中最重要的圖之一，因為很多錯誤都來自 pointer 更新順序不正確。

一句話記憶：插入節點先接新節點的 next，再改前一個節點的 next。

五、完整中文講解

（一）本主題要學會什麼？

單向鏈結串列插入與刪除的核心不是搬動資料，而是重新接 pointer。插入時把新節點接進兩個節點之間；刪除時讓前一個節點跳過目標節點。

（二）實作時最重要的觀念

資料結構
先看清楚資料是用 Array、Node、Singly List、Circular List 或 Doubly List 表示。
指標方向
Linked List 題目幾乎都在考指標怎麼接、怎麼斷、怎麼重新連起來。
特殊情況
空串列、頭節點、尾節點、找不到資料，都是程式容易錯的地方。
測試方式
每做完 insert/delete，都用 print 檢查目前串列是否符合預期。
插入時最重要的是順序：先讓新節點接住後方，再讓前方節點接新節點。刪除時則是讓前方節點直接接到目標後方。

一、程式題目講解

本題示範單向鏈結串列的前端插入與刪除指定節點。學生需要理解 Linked List 操作不是搬動整批資料，而是改變節點之間的 next 指標。

二、完整程式碼

以下為本頁程式題目的完整可執行 C 程式碼，已在重要程式區塊加入中文註解，方便初學者理解程式功能與流程。

#include <stdio.h>
#include <stdlib.h>

/*
    Singly Linked List：插入與刪除
    重點：Linked List 操作主要不是搬動資料，而是修改 next pointer。
*/

typedef struct Node {
    int data;
    struct Node *next;
} Node;

Node* createNode(int value) {
    Node *node = (Node*)malloc(sizeof(Node));
    if (!node) exit(1);
    node->data = value;
    node->next = NULL;
    return node;
}

void insertFront(Node **head, int value) {
    Node *newNode = createNode(value);
    newNode->next = *head; // 新節點先接住原本的第一個節點
    *head = newNode;       // head 改指向新節點
}

void deleteValue(Node **head, int value) {
    Node *curr = *head;
    Node *prev = NULL;

    while (curr != NULL && curr->data != value) {
        prev = curr;
        curr = curr->next;
    }

    if (curr == NULL) {
        printf("找不到 %d\n", value);
        return;
    }

    if (prev == NULL) {
        *head = curr->next;        // 刪除頭節點
    } else {
        prev->next = curr->next;   // 刪除中間或尾端節點
    }
    free(curr);                    // 釋放被刪除節點
}

void printList(Node *head) {
    for (Node *p = head; p != NULL; p = p->next) {
        printf("%d -> ", p->data);
    }
    printf("NULL\n");
}

int main(void) {
    Node *head = NULL;
    insertFront(&head, 30);
    insertFront(&head, 20);
    insertFront(&head, 10);
    printList(head);

    deleteValue(&head, 20);
    printList(head);
    return 0;
}

三、程式執行結果

程式執行後會得到以下輸出：

10 -> 20 -> 30 -> NULL
10 -> 30 -> NULL

程式依序使用 insertFront 插入 30、20、10。因為每次都插在最前面，所以串列變成 10 -> 20 -> 30。接著 deleteValue 刪除資料 20，前一個節點 10 的 next 會改接到 30，因此第二次輸出為 10 -> 30 -> NULL。

流程先建立空串列，再多次呼叫 insertFront。每次插入時，新節點先指向原本 head，再把 head 改成新節點。刪除時用 curr 尋找目標節點，prev 保存前一個節點；找到後重新連接 prev->next，最後 free 被刪除節點。

五、重要函數與語法說明

  1. insertFront(Node **head, int value)：把新節點插到串列最前面。
  2. deleteValue(Node **head, int value)：尋找指定資料並刪除該節點。
  3. prev 與 curr：prev 保存前一個節點，curr 保存目前檢查節點。
  4. free(curr)：釋放不再使用的節點記憶體。
  5. for 迴圈走訪：用 p = p->next 依序印出節點。

六、整體說明

本題讓學生練習插入與刪除的基本指標變化。插入要先接住原本 head，刪除要先找到目標，再讓前後節點重新連接，這是 Linked List 最常考的邏輯。

流程講解

  1. 程式會先從 head 開始尋找欲插入或刪除的位置。
  2. 插入時先建立 newNode，再讓 newNode->next 指向原本的下一個節點。
  3. 接著把前一個節點的 next 改成 newNode，完成插入。
  4. 刪除時先保存 delNode，讓前一個節點跳過 delNode 接到下一個節點。
  5. 最後用 free(delNode) 釋放記憶體，避免 memory leak。
