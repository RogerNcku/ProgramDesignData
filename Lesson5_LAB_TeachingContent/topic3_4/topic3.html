一、主題核心概念

Singly Linked List 是只能順著一個方向走的串列。每個節點通常包含 data 與 next，next 指向下一個節點，最後一個節點指向 NULL。

詳細說明與講解

1、這張投影片開始進入 Singly Linked List。單向鏈結串列中的每個節點通常有兩個欄位：一個保存資料，例如 Name；另一個保存 pointer，指向下一個節點。

2、Head pointer 是整條串列的入口。程式只能從 head 開始，沿著每個節點的 pointer 往下一個節點前進。因為是單向，所以不能直接從後面的節點回到前面的節點。

3、圖中最後一個節點指向 NIL，代表串列結束。這個結束標記在程式中通常是 NULL。走訪時只要 current != NULL 就繼續，current == NULL 就停止。

4、單向鏈結串列的限制是刪除某個節點時，如果只知道該節點本身，通常還需要知道它的前一個節點，因為前一個節點的 next 必須改成指向目標節點的下一個。

一句話記憶：Singly Linked List 只能從 head 往後走，不能往前退。

一、程式題目講解

本題說明單向鏈結串列的基本結構。學生需要理解每個節點只有一個 next 指標，因此只能由前往後走訪，不能直接反向移動。

二、完整程式碼

以下為本頁程式題目的完整可執行 C 程式碼，已在重要程式區塊加入中文註解，方便初學者理解程式功能與流程。

#include <stdio.h>
#include <stdlib.h>

/*
    Lesson 5：Linked List 基本節點示範
    功能：建立三個節點，並用 next pointer 串成一條 linked list。
*/

typedef struct Node {
    int data;              // data：節點中保存的資料
    struct Node *next;     // next：指向下一個節點的指標
} Node;

Node* createNode(int value) {
    Node *newNode = (Node*)malloc(sizeof(Node));
    if (newNode == NULL) {
        printf("記憶體配置失敗\n");
        exit(1);
    }
    newNode->data = value; // 設定資料
    newNode->next = NULL;  // 一開始還沒有接到下一個節點
    return newNode;
}

void printList(Node *head) {
    Node *current = head;  // 從 head 開始走訪
    while (current != NULL) {
        printf("%d -> ", current->data);
        current = current->next;
    }
    printf("NULL\n");
}

int main(void) {
    Node *head = createNode(10);
    head->next = createNode(20);
    head->next->next = createNode(30);

    printf("Linked List 內容：");
    printList(head);
    return 0;
}

三、程式執行結果

程式執行後會得到以下輸出：

Linked List 內容：10 -> 20 -> 30 -> NULL

main 建立 10、20、30 三個節點，並依序用 next 連接。printList 從 head 開始印出每個節點的 data，最後遇到 NULL 代表串列結束，所以輸出為 10 -> 20 -> 30 -> NULL。

流程先建立節點，再把 head 指向第一個節點。每個節點的 next 指向下一個節點，最後一個節點的 next 保持 NULL。走訪時 current 一直往 next 移動，因此形成單向流程。

五、重要函數與語法說明

  1. Node：單向串列的基本節點。
  2. next 指標：只指向下一個節點，形成單向連結。
  3. createNode：負責配置與初始化節點。
  4. printList：示範由 head 到 NULL 的單向走訪。
  5. NULL：表示串列尾端或沒有下一個節點。

六、整體說明

本題核心是「單向」概念。單向鏈結串列只能順著 next 往後走，因此插入或刪除時常需要保存前一個節點的位置，這會在後面的題目中用到。

流程講解

  1. 單向鏈結串列的每個節點只需要 data 與 next。
  2. head 保存第一個節點的位置，是進入串列的入口。
  3. 走訪時不能直接跳到任意位置，而是從 head 一個一個往後走。
  4. 每次印出 current->data 後，執行 current = current->next。
  5. 當 current 變成 NULL，代表已經走到串列尾端。
