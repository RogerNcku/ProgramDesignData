編輯與執行總說明

適用 Practice 06–12 所有 C 程式

首頁

Windows / PowerShell

  1. 解壓縮 ZIP。
  2. 進入 source_codes 資料夾。
  3. 用 VS Code 或其他編輯器開啟 .c 檔。
  4. 編譯：
    gcc 檔名.c -o 檔名.exe
  5. 執行：
    .\檔名.exe

Linux / Yellow Server

  1. 進入程式所在資料夾。
  2. 編譯：
    gcc 檔名.c -o 檔名.out
  3. 執行：
    ./檔名.out

常見問題

如果出現找不到 gcc，代表尚未安裝 gcc 或沒有設定環境變數。

如果程式需要命令列參數，例如檔案名稱，執行時要把參數放在後面。
